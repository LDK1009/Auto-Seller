## 2. 방문자 정의 (누가 이 페이지를 보는가)

| 유형 | 비중 추정 | 상태 | 필요한 것 |
|---|---|---|---|
| **A. 콘텐츠 유입 신규** | 다수 (쓰레드·유튜브·블로그) | 이미 셀러다. "이게 뭐 하는 건데?" | **결과물 즉시 확인** → 체험 |

**설계 우선순위: A.** 첫 3초에 "무엇을 얻는지" 보이지 않으면 나간다.

## 3. 메시지 구조 (무엇을 말하는가)

**한 문장:** 도매꾹 상품 링크 하나 넣으면, 스마트스토어 등록에 필요한 게 전부 준비된다.

말하는 것 (3대 약속 기반):
1. **시간** — 상품 하나에 몇 시간 → 몇 분
2. **실수 방지** — MOQ·이미지 사용권·금지어·품절을 등록 전에 걸러줌
3. **판단 근거** — 검색량·마진 숫자로 고르게 함

**말하지 않는 것 (삭제 확정):**
- ~~무료·가입 없음~~ → 획득 조건이지 가치가 아님. CTA 밑 각주 한 줄로만 ("지금은 무료로 쓸 수 있어요")
- ~~이미지가 서버로 안 감~~ → 셀러 관심사 아님. FAQ에서 물어보면 답하는 수준
- ~~"평생 무료"~~ → 영구 약속 금지 (MARKETING 금지 목록)

## 4. 섹션 구성 (확정)

| # | 섹션 | 목적 | 내용 |
|---|---|---|---|
| 1 | **히어로** | 3초 안에 이해 | 슬로건 + 한 줄 설명 + **결과물 목업(상품→시트 좌우 대비)** + CTA 1개 |
| 2 | **베스트 상품** | 즉시 체험 | 도매꾹 인기 상품 8개 — 클릭하면 원링크가 실제로 돌아감 (시연) |
| 3 | **문제 공감** | "내 얘기다" | pain 3개 (이미지 노가다 · 등록 폼 반복 · 도매처 품절) |
| 4 | **결과 3가지** | 무엇이 달라지나 | 3대 약속을 셀러 언어로 (시간·실수·판단) |
| 5 | **여정 3단계** | 어떻게 쓰나 | 링크 → 편집 → 붙여넣기 |
| 6 | **도구 목록** | 부분 사용자 수용 | 기존 그리드 유지 |
| 7 | **FAQ** | 마지막 저항 제거 | 아래 5문 |
| 8 | **CTA** | 전환 | 버튼 1개 + 무료 각주 |
| 9 | 푸터 | 법적 요건 | 사업자 정보·약관 |

**삭제:** "오토셀러의 약속" 섹션(무료·무가입·프라이버시 3장) → 4번 결과 섹션이 대체

## 5. FAQ (셀러가 진짜 궁금해하는 것)

선정 기준: ① 등록 전 결정 장벽 ② 실제 커뮤니티 질문 유형 ③ 우리가 사실로 답할 수 있는 것

1. **등록까지 자동으로 해주나요?** — 기대 관리 (가장 중요한 오해)
2. **도매꾹 상품 이미지 그대로 써도 되나요?** — 실제 셀러 최다 질문 유형 (키워드 리서치 "공급사 이미지 그대로 써도 되나" = 빈틈 키워드로 확인됨)
3. **상품명·태그는 어떤 기준으로 만들어지나요?** — 자동 생성물 신뢰 문제
4. **도매꾹 말고 다른 도매처도 되나요?** — 범위 확인
5. **쿠팡·11번가에도 쓸 수 있나요?** — 범위 확인
6. **얼마예요? / 계정이 필요한가요?** — 마지막에, 각주처럼

> 프라이버시 질문은 넣지 않는다. 물어보는 사람이 없다.
