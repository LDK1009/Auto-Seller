# 가격 정책

> 유료 1호 = **품절감시 + AI썸네일 동시 출시**. 두 기능은 성격이 달라 과금 구조도 다르다.
> 목표: 첫 결제 장벽 최소화(타겟 = 0~6개월 저지불의사 셀러) + [매출 역산](매출-역산.md) ARPU 시나리오 연결.

작성: 2026-07-29 · 경쟁가 출처: 웹 리서치(하단)

---

## 1. 원칙

- **타겟 = 0~6개월 셀러, 저지불의사** → 무료 훅 + 저가 진입
- **무료 범위가 경쟁사 유료 = 입구** (배경제거 = 제디터 55원/장을 무료로)
- 첫 결제 장벽 최소화, 재방문이 증명된 뒤 구독 강화

## 3. 두 기능 과금 구조

| 기능 | 과금 방식 | 근거 |
|---|---|---|
| **품절감시** | **월 9,900 정액 구독** (07-29 확정) | 지속 감시 = 구독이 자연. **알림 받으러 다시 옴 → 재방문 유발 기능** (역산의 "재방문 0" 약점을 이 기능이 해소) |
| **누끼(배경제거)** | **완전 무료** (07-29 확정) | 입구 훅 — 제디터 55원/장을 무료로 |
| **AI 생성물** (썸네일·배경생성·상세페이지) | **종량 크레딧 — 공유 풀** | 셋 다 AI 생성물이라 하나의 크레딧으로 소모(무게별 차등). 구독에 월 N크레딧 포함 |

> **07-29 첫 유료 = 3종 동시 출시**: 품절감시(구독) + 썸네일 + 상세페이지(둘 다 크레딧). 누끼는 무료 입구.
> ARPU = 품절감시 구독료 + 크레딧 소진액의 유료 1인 평균. 역산 시나리오(9,900/19,900/29,900)는 이 합산 ARPU.

## 4-5. 크레딧 정책 (07-29 확정 · 원가 확인 후 미세조정)

**단위**: 1크레딧 = 200원 기준 (배경생성 앵커)

| 소모 | 크레딧 | 근거 |
|---|---|---|
| AI 배경생성 | 1 | 200원, 제디터 220 대비 |
| AI 썸네일 | 1 | 배경생성+텍스트 조합 |
| 상세페이지 | 5 | 다중 이미지·긴 생성, 무거움 |
| 누끼(배경제거) | **0 (무료)** | 크레딧 미소모 = 완전 무료 입구 |

- **구독 포함**: 월 9,900 구독에 **월 30크레딧 포함** (배경생성/썸네일 30장 or 상세 6개). 소진 시 충전
- **체험**: 신규 가입 시 **10크레딧 무료** (구독 전 맛보기 훅)
- **충전팩** (종량, 대량 할인):

| 팩 | 가격 | 크레딧당 |
|---|---|---|
| 30 | 5,900원 | 197원 |
| 100 | 18,000원 | 180원 (10%↓) |
| 300 | 48,000원 | 160원 (20%↓) |

> 원가(생성 API 실비) 확인 후 단가·포함 크레딧 미세조정. ARPU = 9,900 + 충전액.

## 5. 미확정 (대표 판단 + 원가 데이터)

**확정 (07-29):** 품절감시 월 9,900 정액 · 누끼 완전 무료 · 첫 유료 = 품절감시+썸네일+상세페이지 3종 동시

**확정 (07-29):** 크레딧 단가 200원 · 구독 포함 30크레딧 · 충전팩 3종 · 상세페이지 5크레딧 (§4-5) · **품절감시 감시 50개 상한**

> 감시 50개 상한 근거: 타겟(0~6개월 셀러)은 상품 수십 개 → 50개 충분. 무제한은 알림톡 원가 예측 불가(상품 200개×품절/재입고 ≈ 월 6,000원, 9,900 마진 압박). 상한 = 원가 예측 가능. 헤비유저는 후속 상위 티어.

**원가 확인 (개발):**
- 알림톡 발송 단가 (알리고 ~8~15원) → 무제한 감시 시 원가 리스크
- ✅ **AI 생성 원가 실측 완료 (2026-07-29):** Gemini `3.1-flash-image` 채택 — 17.9s·이미지 1,120토큰·**장당 약 30-55원 → 크레딧 200원 대비 마진 73-85%**. (`3-pro-image`는 27.8s·장당 약 190원으로 마진 5% → 기각. 품질은 양쪽 다 한글 문구 렌더 정상)
  - **크레딧 단가 200원 유지 확정.** 상세페이지 5크레딧(1,000원)은 섹션 5장 생성 시 원가 150-275원 → 마진 충분
- ✅ **누끼 모델 = C안 교체 확정 (07-29):** @imgly(AGPL-3.0) → **ormbg-ONNX(Apache-2.0)**. transformers.js 브라우저 실행 유지 = 서버비 0·호스팅 부담 없음. 개발 세션 교체 작업. [대표-액션](../대표-액션.md)

> 원가 확정 전엔 시장가 앵커로 잡고, 원가 나오면 마진 역산으로 조정.
