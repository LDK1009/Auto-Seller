## 1. 미션 · 비전 · 범위

### 미션

> **사용자가 단 한 건이라도, 우리 서비스를 통해 순이익을 남기게 한다.**

- 고객 성공의 최종 판정 기준. 모든 기능은 이 문장에 기여해야 한다.
- NSM(3장)은 이 미션의 운영 대리지표다.

### 장기 비전 — "위탁 셀러의 올인원 OS"

김진우 한 사람의 **전 여정**을 하나의 툴로:

```
소싱 실행 → 등록 준비 → 등록 → 운영(발주) → 마케팅 보조
```

- **전 단계 커버 ≠ 전 셀러 커버.**
  모든 셀러의 범용 OMS가 아니라, 한 페르소나의 풀사이클.
  이것이 1인 운영 제약(7장)과 비전을 양립시키는 프레임이다.

### 여정 커버리지 3스텝

서비스 범위는 셀러 여정 기준으로 단계 확장한다:

| 스텝 | 커버 여정 | 만족 기준 |
|------|----------|----------|
| **스텝 1 ← 현재** | ①조사 + ②등록 | 조사(키워드·시장·상품 발굴·수익성 검증)와 등록 준비를 우리 안에서 해결. 자동 등록(②b)은 법인 후 |
| 스텝 2 | + ③노출·마케팅 | 광고 세팅 보조·콘텐츠 (어뷰징 영구 금지 유지) |
| 스텝 3 | + ④주문 ⑤CS ⑥정산 | 신호 기반 확장 |

- **방법의 제약은 스텝과 무관하게 유지**: 공식 API·클라이언트 처리만 — 순위 추적·매출 추정(크롤링+누적 DB)은 계속 비목표
- 8장 게이트는 그대로 유효 — 스텝은 "어디까지 갈 것인가", 게이트는 "언제 넘어갈 것인가"

### 현 단계 정의

> **뭘 팔지 찾는 것부터 등록 직전까지 — 셀러 앞단 전부를 해결한다.** (스텝 1)

- 아이템 선정의 **최종 판단**은 여전히 셀러 몫 — 우리는 데이터(키워드·시장·후보·마진)로 결정 마찰을 줄인다 (추천·큐레이션 금지 유지)
- ①의 무기: 키워드 분석 + 도매꾹 소싱 브리지(키워드→상품 후보→마진→원링크) — 아이템스카우트가 안 하는 "발굴→등록 연결"이 차별점

### 셀러 워크플로 (범위의 좌표계)

```
①아이템 조사 → ②a 등록 준비(이미지·텍스트) → ②b 등록 실행(계정 연동·전송)
→ ③마케팅 → ④주문/배송 → ⑤CS → ⑥정산
```

- **②는 교두보다.** 최종 정체성이 아니라 시장에 이기고 들어가는 자리. 확장은 게이트(8장) 순서로만.

### 소싱 미결정자 수용 원칙

셀러인데 **다음에 뭘 팔지 못 정한 상태**를 말한다. (셀러가 아닌 사람은 타겟이 아니다 — 2장)

> **결정을 대신하지 않되, 결정까지의 마찰은 줄인다.**

- 수용 수단 (미결정자가 이탈하지 않고 머물 이유): 가이드 콘텐츠 · 마진/역산 계산기(소싱 검증 도구) · 도매꾹 인기검색어 위젯(소싱 동선의 시작점)
- 위계 원칙: 소싱 해결의 본체는 원링크(링크→파이프라인). 인기검색어는 보조 힌트 — "소싱 정보 툴"로 포지션이 밀리면 안 됨
- 하지 않는 것: 상품 추천·큐레이션.
  이유: 모두에게 같은 상품을 추천 → 가격 경쟁 → 고객 순이익 파괴 = 미션 위배.

## 2. 타겟 (2026-07-24 전면 재정의)

### 한 문장

> **도매꾹에서 소싱해 스마트스토어에 위탁판매 중인, 0-6개월 차 국내 1인 셀러.**

### 왜 좁혔나

**제품이 해결하는 범위와 타겟이 어긋나 있었다.** 우리 도구는 도매꾹 링크 → 스마트스토어 등록 준비를 잇는 파이프라인이다. 그런데 타겟은 "위탁 셀러 전체 + 예비 부업러"로 훨씬 넓게 잡혀 있었다.

**도움을 줄 수 없는 사람을 타겟에 넣지 않는다.** 그들은 우리 서비스에서 효용을 못 느끼고, 아무리 설득해도 쓸 이유가 생기지 않는다. 설득 비용만 든다.

### 포함 / 제외

| | 대상 |
|---|---|
| ✅ **포함** | 도매꾹 소싱 · 스마트스토어 판매 · **이미 셀러 활동 중** · 0-6개월 차 · 1인 운영 |
| ❌ **제외** | **셀러가 아닌 사람** (예비 부업러·창업 고민 단계) — 셀러로 만드는 비용 + 우리 서비스로 데려오는 비용, 이중 부담 |
| ❌ 제외 | 해외 구매대행 · 사입 위주 · 쿠팡 등 타 마켓 전용 · 브랜드(자사 제품) 셀러 |
| ⚪ 부수 유입 | 도매매 사용자(API 통합돼 자동 지원) · 6개월 이상 경력자 — 조준하지 않되 오면 받는다 |

> **핵심 판정:** "지금 도매꾹에서 물건 떼다 스마트스토어에 올리고 있는가?" 아니면 타겟이 아니다.

### 핵심 pain

등록 개수가 매출과 직결되는데, 업로드 전 **이미지 가공**(대량 누끼·규격·워터마크)이 시간을 다 먹는다.
→ 외부 검증: 쓰레드 설문에서 "가장 오래 걸리는 작업" 1위 **이미지편집 71%** ([고객-인사이트.md](./고객-인사이트.md))

부차적으로 **모르고 당하는 것들** — MOQ·이미지 사용권·금지어·KC 인증.

### 페르소나 — "밤 10시의 김진우"

- 32세 직장인. **퇴근 후 밤 10시-새벽 1시가 부업 시간의 전부.**
- **도매꾹 소싱, 스마트스토어 4개월차.** 지금 팔고 있다.
- pain: 그 2-3시간이 전부 이미지 편집·등록 복붙에 사라진다.

> *"부업하려고 잠을 줄였는데, 사업이 아니라 야근을 하나 더 하는 기분이다."*

- 우리가 파는 변화: **반복 노동 → 기획·소싱에 쓰는 시간, 그리고 잠.**

### 조준 원칙

- **이미 셀러인 사람에게만 말 건다.** "부업 시작하는 법" 류 콘텐츠는 만들지 않는다 — 그건 우리 고객이 아니다
- 소재는 **셀러가 실제로 겪는 작업**에서 나온다 (등록·이미지·소싱·규정)
- **제품 게이트는 좁히지 않는다** — 무료 툴이 전업자를 거부할 이유는 없다. 좁히는 건 카피 조준점이지 사용자 필터가 아니다
- ⚠️ 페르소나 수치는 내부 설정 — 공개 카피에 사용 금지

## 3. 문제 정의와 고객 경험

### ②단계의 pain 3개

1. **이미지 작업** — 누끼(장당 과금 툴뿐)·마켓 규격·워터마크·상세 분할을 낱장 수작업
2. **상품명·태그** — SEO 조합 + 글자수 제한 + 금지어 회피 노가다
3. **등록 입력** — 판매자센터 복붙 반복 × 상품 수십 개

### 고객 경험 여정

```
발견(커뮤니티 링크) → 30초 내 첫 처리(무가입) → [아하 모먼트] → [습관 모먼트] → 추천 → 결제(S2~)
```

CX 원칙 4가지:

| 원칙 | 내용 |
|------|------|
| 마찰 제로 | 가입·설치 없음 |
| 즉각 결과 | 수 분 내 결과물을 손에 쥔다 |
| 신뢰 | 내가 올린 이미지는 서버로 가지 않는다 |
| 흐름 | 도구 간 핸드오프 (파이프라인) |

### 아하 모먼트 (가설 — 출시 후 데이터로 보정)

- **아하: "첫 세션에서 이미지 10장+ 일괄 처리 → ZIP 다운로드"**
  "2시간 노가다가 5분이 됐다"는 체감. 1장 처리는 remove.bg급 경험이라 아하가 아니다.
- **최종 아하 (원링크): "도매꾹 링크 붙여넣기 → 등록용 이미지 세트 다운로드"**
  소싱 루틴에 편입되는 순간 = 습관 모먼트.
- 보조 가설: 핸드오프 1회 경험(누끼→규격). 파이프라인은 경쟁사가 못 주는 경험.

### 노스스타 지표 (NSM)

> **주간 ZIP 다운로드 수** — 방문이 아니라 "가치가 반출된 횟수"

- S1 게이트(WAU·재방문)의 선행지표.
- 미션의 최종 판정("첫 순이익 1건")은 직접 측정이 어려움 → NSM이 운영 대리. S2 이후 인터뷰·후기로 정성 검증.

> 셀러 전체 여정 9단계의 문제 분해·기능 매핑 지도 → [../마케팅/MARKETING.md](../마케팅/MARKETING.md) B 유형 (콘텐츠용으로 작성됐지만 온보딩·기능 갭 판단에도 사용)

## 4. 가치 제안과 제품 원칙

### 3대 약속 (2026-07-21 개정 — 마케팅 카피 축과 일치)

> **시간을 줄인다 · 실수를 막는다 · 숫자로 고르게 한다**

| 약속 | 내용 |
|---|---|
| **시간** | 상품 하나 올리는 데 걸리던 몇 시간을 몇 분으로. 등록 준비 전 구간을 잇는다 |
| **실수 방지** | MOQ·이미지 사용권·금지어·KC를 등록 **전에** 걸러준다. 초보가 몰라서 당하는 걸 막는다 |
| **판단 근거** | 감이 아니라 검색량·마진 숫자로 고르게 한다 |

> **가격·가입 조건은 약속이 아니다.** 무료·무가입은 **획득 전략**이지 제품이 주는 가치가 아니다. 유료화·가입 도입 시 바뀌므로 약속의 자리에 두지 않는다. 카피 원칙은 [../마케팅/MARKETING.md](../마케팅/MARKETING.md) 참조.

**기술 원칙 (약속과 별개로 유지):**

- 사용자가 올린 이미지는 서버로 전송되지 않는다. 모든 가공은 브라우저에서.
- 진입 마찰 최소화 = 확산 전략의 기반.
- 예외 경계: 공개 상품 데이터 수집(도매꾹 API)과 외부 API 중계는 서버 프록시(`app/api`)를 거친다 (CORS·키 은닉). 사용자 본인 이미지가 아니므로 충돌하지 않는다.
- 언급이 필요할 때 문구는 정확하게: **"내가 올린 이미지는 서버로 가지 않습니다."** (단, 이건 카피 축이 아니라 문의 대응용)

### 차별화 축

> **파이프라인이 유일한 차별화 축이다.**

- 소싱 → 누끼 → 규격 → 워터마크 → (상품명 → 상세 → 등록 → 발주)
- 개별 기능은 전부 경쟁자가 있다. 끝까지 잇는 툴은 없다.

### 아키텍처 원칙

- 클라이언트 처리 우선.
- 서버·AI·계정연동은 해당 단계가 요구할 때만 도입.

## 5. 경쟁 지형과 우리 좌표

### 지형 지도

```
①조사   아이템스카우트·판다랭크 (포화)        → 공식 API 조사로 진출 — 추정·랭킹은 금지, 차별점 = 발굴→등록 연결
②등록   [통합형]  ★윈들리(국내위탁, 3만~) · 퍼센티(해외, 20만) · 스토어봇
        [개별기능] 드랩아트(누끼) · 스토어부스터(상품명) · 스피드고전송기(무료 전송) · 매드스마트
④운영   플레이오토(15만)·사방넷 (범용 OMS)     → 진출 금지 (위탁 특화 발주만 S5 예외)
⑤CS     약한 영역                            → 문구 생성기로 수요 정찰만
⑥손익   셀러보드                             → 진출 금지, 계산기는 유입용만
```

### 경쟁사 순위 (타겟 × 기능 겹침)

1. **윈들리** — 두 축 모두 최고 겹침
2. **스피드고전송기** — 도매매 공식·무료. 우리 타겟의 기본값. 소싱·등록 기능 기획 시 필수 비교 대상
3. **드랩아트** — 현 이미지 제품과 정면
4. 유플랫·쿠대·매드스마트·스토어봇
5. 퍼센티 — 기능 유사하나 타겟 어긋남 (해외 구매대행)

- S2 진입 시 스토어부스터·상세AI군이 순위 상승.

### 우리 좌표

> **윈들리(유료 완성형)와 스피드고(무료 전송기) 사이.**
> "무료인데 스피드고보다 품질, 윈들리보다 마찰 없음(무가입)"

차별화 3축:

1. **무료·무가입** — 윈들리 깔때기의 앞단 선점
2. **이미지 가공 깊이** — 수집→등록형 툴들의 공백
3. **브라우저 프라이버시** — 구조적 차별화

### 시장 신호

- 퍼센티·윈들리 성립 = ② 자동화의 지불의사 증명.
- 윈들리·퍼센티·플레이오토(셀핏AI)가 모두 ②로 수렴 중 = **선점 시급.**
- 교훈: "국내 위탁 소싱→등록은 빈자리"라는 초기 판단은 윈들리 발견으로 정정됨. 경쟁 조사는 상시 갱신.

## 6. 제품 체계 — 스테이션 맵

> 무엇이 제품인가의 구조만 정의한다. 각 기능의 진행 상태·순서는 [로드맵](../개발/ROADMAP.md), **현재 화면에 실제로 있는 기능 상세는 [FEATURES.md](../개발/FEATURES.md)** 소관.

```
[조사]    키워드 분석(차트·비교) · 도매꾹 소싱 브리지(키워드→상품 후보→마진→원링크)
[소싱]    원링크(링크→파이프라인) · 엑셀 대량 매칭
[이미지]  누끼·규격·규정검사·워터마크·상세분할               ← 무료 코어
[등록준비] 등록 정보 시트 ①~⑫ (스스 폼 1:1 — API 불필요)
[텍스트]  AI 상품명(+검색량 embed)·태그 검증·AI 상세         ← 첫 비용·과금 시작 (S2)
[등록]    이미지 업로드·원클릭 등록 (스마트스토어 단일)       ← 법인 전환 후 (정식 솔루션)
[운영]    스스 주문 → 도매꾹 자동 발주                       ← S5
[마케팅]  정보 콘텐츠·광고 세팅 보조·체험단 정보 연결         ← S6 (비전 최종)
──────────────────────────────────────────
[유입]    계산기 허브: 마진 · 역산 · ROAS · 부가세 · 글자수
          → 포지셔닝 아님, 집객용 현관
```

★ **킬러 시나리오 = 원링크**: "도매꾹 URL 하나로 네이버 상품등록까지"

```
링크 → 이미지 편집 → 등록 정보 시트 ①~⑫ → +원클릭 등록 (법인 후)
```

- vs 스피드고전송기(무료 복사·전송): **제작 품질**로 승부
- vs 윈들리·퍼센티(유료): **무료 진입 + 이미지 가공 깊이 + 무가입**

## 7. 사업 목표·제약과 수익화

### 목표와 제약 (모든 판단의 상위 필터)

| 항목 | 내용 |
|------|------|
| 운영 형태 | **1인 개발·운영 유지.** 직원 채용·대규모 확장 지향 안 함 |
| 판단 필터 | "1인 운영 상한(유지보수·CS)"이 매출 잠재력보다 **우선** |
| 목표 | **월 순이익 500만+** ≈ 월 매출 약 600만 (PG ~3.3% + 서버/AI 비용) |
| 타겟 근거 | 구매대행(B)은 ARPU 높지만 서버 자동화·연동 유지보수·CS가 1인 상한 초과 → A타겟 확정 |

### 가격 사다리 (초안 — S2 진입 시 확정)

| 티어 | 내용 | 가격(안) |
|------|------|---------|
| 무료 | 이미지 파이프라인 전체 — 한계비용 0, 무료 유지 방침 (단 "평생 무료" 대외 약속은 금지 — 9.5) | 0원 |
| 라이트 | AI 상품명·태그 (무료 횟수 제한 해제) | 월 9,900~19,900원 |
| 프로 | 도매매 링크→등록 패키지 (스마트스토어 단일 = 1인 생존 설계) | 월 39,000원선 |
| (미결) | S5 발주 자동화의 티어 배치 | S5 설계 시 결정 |
| 목표점 | 프로 150명 ± 라이트 혼합 = 월 매출 600만 | — |

- **윈들리와 가격전 금지.** "이미지 품질 + 무가입 입구"라는 다른 가치축으로 싸운다.
- **등록 자동화 경로 (네이버 공식 [#1564](https://github.com/commerce-api-naver/commerce-api/discussions/1564)·[#3463](https://github.com/commerce-api-naver/commerce-api/discussions/3463)):**
  - 제3자 API 호출 = 커머스솔루션마켓 or API대행사 — **둘 다 국내 법인 요건**
  - 사용자의 내스토어 앱 키 수취·위탁 = **약관 위반 명시 → 영구 배제**
  - 따라서: S0~S2 = 등록 준비 패키지(API 불필요) → **S2 도달 시 법인 전환 + 정식 솔루션 등록** → 원클릭 등록. 이 장벽은 통과 후 후발 주자를 막는 해자.

### 9.4 마케팅 원칙

> 남의 이론을 따라가지 않는다. **우리 고객이 무엇을 궁금해하는지**에서 출발해, 그 답을 주고 그 과정에서 우리 서비스를 알린다.

1. **고객을 좁게 본다** — "모든 셀러" 금지. 우리가 말 거는 사람은 부업으로 시작한 초보 위탁 셀러다 (2장). 이 사람이 겪는 문제만 다룬다
2. **궁금한 것에 답한다** — 소재는 우리가 하고 싶은 말이 아니라 **고객이 실제로 검색하는 질문**에서 나온다. 답을 먼저 주고, 그 과정에 우리 도구가 등장한다
3. **변화를 말한다** — 기능(누끼)이 아니라 결과("반복 노동 → 기획하는 시간, 그리고 잠")를 말한다. 단, 사실 기반 안에서
4. **끼어들지 않는다** — 커뮤니티 도배·스팸 금지. 도움이 되는 정보를 먼저 두고, 필요한 사람이 찾아오게 한다
5. **말하고 싶어지는 지점을 만든다** — 광고비 대신: 링크 하나로 끝나는 여정, 등록 전 함정 자동 차단, 숫자 기반 선별
6. **가격 조건은 카피 축이 아니다** — 무료·무가입은 **획득 전략**이지 메시지 축이 아니다. 유료화·가입 도입 시 바뀌므로 카피는 **제품이 주는 결과**(시간·실수 방지·판단 근거) 위에 세운다 (카피 재료: [../마케팅/MARKETING.md](../마케팅/MARKETING.md))
7. **약속하고 지킨다** — 마케팅 스토리가 제품보다 앞서면 스토리를 낮춘다 (서브카피 갭 관리)

### 9.5 금지 목록 (냉철 체크리스트)

- ❌ 검증 안 된 수치 ("등록 시간 90% 단축")
- ❌ 최상급·과장 ("국내 최초", "업계 최고")
- ❌ 아직 없는 기능을 현재형으로 (원클릭 등록은 ②b 출시 전까지 금지)
- ❌ 수익 보장 뉘앙스 ("매출이 오릅니다" — 미션은 돕는 것이지 보장이 아님)
- ❌ 경쟁사 이름 직접 비교
- ❌ 공급사 워터마크 제거 용도 언급 (11장)
- ❌ 영구 무료 약속 ("평생 무료") — 유료화 여지 보존, "지금 무료·무가입" 현재형 사실 서술만
- ❌ 페르소나 내부 수치의 카피 사용
- ❌ **경쟁사** 룩앤필 복제 (토스 등 이업종 노하우 차용은 허용 — design/README 디자인 원칙)
