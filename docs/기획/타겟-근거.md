# 타겟 근거 — 왜 도매꾹 소싱 1인 셀러인가 (재론 방지)

> **이 고민이 또 들면 여기부터 읽는다.** "어필리에이트로 피벗할까" "직장인 부업층이 더 크지 않나" "1인 온라인 사업자 중 어디가 풀이 크지" — 전부 아래에서 이미 답했다.
> **결론: 피벗 안 한다. 지금 타겟이 데이터상 최적이다.** 타겟 정의 자체는 [PLAN 2장](PLAN.md).

---

## 1. 반복되는 오류 패턴 — "큰 풀" 함정

고민은 항상 같은 모양으로 온다: **"저기가 사람이 더 많아 보인다 → 저기를 타겟하자."**

**이게 함정이다. 풀 크기 ≠ 지불의사.** 오히려 반비례한다:

- 진입 쉬운 시장(어필리에이트·블로그 부업) = **무자본으로 시작하려는 사람** = 도구에 돈 안 씀.
- "리스크 없는 부업 원하는 층" = 지갑 닫힌 층. **많은 사람이 원하는 것 ≠ 돈 내는 것.**
- 진입장벽은 지불의사의 **필터**다. 장벽 넘은 사람이 돈을 쓴다.

**봐야 할 건 "큰 풀"이 아니라 "돈 쓰는 풀"이다.** 아래 2번이 그 답.

## 2. 1인 온라인 사업자 분포 — 어디가 크고, 누가 SaaS에 돈 쓰나

| 세그먼트 | 규모 | SaaS 지출 | 근거 |
|---|---|---|---|
| **이커머스 셀러 (통신판매업)** | **60.7만** · 100대 생활업종 **1위** | **◎ 증명됨** | 국세청 2023 |
| 블로그·SNS 부업 | ~8.4만 (추정, 어필 단독 아님) | △ 무료 지향 | 인크루트×공식통계 역산 |
| 디지털 크리에이터 사업체 | 1.1만 (5인 미만 85.7%) | △ | 정보통신정책연 2024 |
| 1인미디어 소득 신고자 | 2.5만 | △ | 국세청 2023 |
| **어필리에이트 단독** | **데이터 없음** | ✗ | 어떤 설문·공식에도 없음 |

**두 가지가 결정적이다:**

**① 이커머스 셀러가 최대 풀 중 하나다.** 통신판매업 60.7만 = 100대 생활업종 사업체 수 **1위**. 크리에이터(1.1만)·1인미디어(2.5만)의 **20~55배**. "다른 데 풀이 더 클 것"이라는 직감은 틀렸다.

**② 이커머스 셀러가 SaaS 지출이 증명된 유일한 세그먼트다.** 아이템스카우트·셀러오션·셀러차트·사입삼촌 — 셀러 대상 **유료 SaaS 생태계가 이미 형성**돼 있다. 키워드 분석·순위 추적·주문 관리에 셀러가 월 구독을 낸다. **경쟁 유료 툴이 돈을 번다는 사실 자체가 "이 시장은 SaaS에 지불한다"의 증거다.**

반면 어필리에이트·블로거는 무투자가 매력인 시장이라 유료 SaaS 생태계가 없다.

## 3. 왜 온라인 셀러를 골랐나 (대표 선택 이유 + 데이터 검증)

| 대표 선택 이유 | 데이터 검증 |
|---|---|
| 온라인으로 마케팅 도달 가능 | ✅ 쓰레드로 유입·전환 확인 (발행량=유입량 양방향 검증) |
| 온라인 사업자가 SaaS 학습 잘함 | ✅ 도구 실사용 확인 (도매꾹 검색 94회 등) |
| (추가) **지불의사가 검증된 시장** | ✅ 경쟁 유료 SaaS 생태계 존재 = 이미 돈 쓰는 층 |

**대표는 없는 수요를 만드는 게 아니라, 이미 있는 수요를 다른 각도로 파는 것이다.** 우리 각도 = **"무가입·무료 입구 + 원링크(도매꾹 소싱 → 등록 준비 통합)"**. 기존 툴이 키워드·순위를 파편적으로 파는 걸, 소싱부터 등록까지 한 흐름으로 묶는다.

## 4. 왜 어필리에이트·부업층이 아닌가 (피벗 기각 요약)

> 상세 전수 조사(판례·통계·약관 원문)는 07-27에 완료. 핵심만 남긴다.

| 검증 가설 | 판정 |
|---|---|
| 직장인 부업 중 스스 비중 낮다 | **사실** (6.1%, 6종 최하위) — 풀 직감은 맞음 |
| 스마트스토어는 돈이 든다 | **틀림** — 위탁은 현금 리스크 실질 0원, 정산 D+1 |
| 어필리에이트는 무투자·저리스크다 | **하위 참여자만** — 상위는 광고대행사(매체비 선지급) |
| 어필리에이트가 더 유리하다 | **아니오** — 수수료 1~3%, 실측 3개월 매출 120만 → 실수익 **3.7만원** |
| 노출 병목이 스스보다 낫다 | **아니오** — Google 스팸정책으로 어필 섹션 **−67%**, 네이버 AI브리핑이 방문 자체를 죽임 |
| 합법적 어필 도구가 팔린다 | **미검증** — 계획 가능 기능 5종 전부 법적 리스크. 도구 제공자가 사업 잃은 전례(Instagress, 2017) |

**핵심 판정:** 어필리에이트는 풀만 크고 단가·노출·합법성 전부 스스보다 나쁘다. 실수요가 규정 위반 자동화라, 정직한 도구의 지불의사는 데이터가 없다.

## 5. 자신감이 흔들릴 때 — 원인은 타겟이 아니다

"제품에 자신이 안 생긴다"가 들 때, 원인을 타겟으로 오진하지 않는다. 실제 원인은 둘:

1. **침체 타이밍** — 발행이 끊기면 유입 신호가 끊기고, 그때 회의가 든다. 제품이 나쁜 게 아니라 안 돌려본 것. **발행 재개하면 신호는 돌아온다** (인과 확인됨).
2. **타겟 혼동** — "직장인 부업할 것"을 생각하는 순간 **예비층**(아직 셀러 아님)으로 눈이 흘러간다. 우리 타겟은 **이미 하는 셀러**. 진입장벽 고민은 예비층 얘기지 우리 타겟 얘기가 아니다.
