# 매출 역산 (퍼널 백워드 플래닝)

> 목표 월매출을 꼭짓점에 두고 **결제 → 진입 → 조회** 순으로 거꾸로 필요 수량을 계산한다.
> 각 단계 전환율을 알면 "월 얼마 찍으려면 조회가 몇 필요한가"가 숫자로 나온다. 격차가 곧 할 일이다.

작성: 2026-07-29 · 출처: GA4(속성 544305521) + 쓰레드 주간 요약(7/21~28)

---

## 1. 전제 (2026-07-29 대표 확정)

**단계 목표** (금액은 확정, 기간은 §6에서 실측으로 산정)

| 단계 | 월매출 | 의미 |
|---|---|---|
| 1단계 | **200만원** | 최저시급 수준 |
| 2단계 | **300만원** | 직장인 급여 대체 |
| 3단계 | **500만원** | 사업 수익 |

| 항목 | 값 |
|---|---|
| 매출 정의 | **전 유료기능 합산** (품절감시 + AI썸네일 동시 출시 가정) → **1인당 월평균 결제액(ARPU)** 하나로 통합 |
| 객단가(ARPU) | **미정 → 시나리오 3개 병렬** (9,900 / 19,900 / 29,900원) |
| 기간 | **지금 못 정함** — 유료 붙여 월 신규 구독 실측 후 산정 (§6) |

## 2. 퍼널 단계

```
조회        쓰레드 글을 본 수 (주간 요약의 '조회')
 ↓ [조회→진입]  ← 0.267% 실측 (프로필·링크 통과 전부 포함)
서비스 진입  원링크 눌러 서비스 도착
 ↓ [진입→결제]  ← 3% 가정 (유료 미출시라 실측 불가)
유료 결제
```

> 노출·프로필 방문은 쓰레드 주간 요약에 안 나온다. **조회부터** 실측으로 잡는다. 조회→진입 0.267%에 프로필·링크 이탈이 이미 다 녹아 있다.

## 3. 현재 실측

**쓰레드 (7/21~28 주간 요약)**

| 지표 | 이번 주 | 이전 주 | 증감 |
|---|---|---|---|

| 지표 | 값 |
|---|---|

| **조회→진입 전환** | **22 / 8,224 = 0.267%** ← 실측 |

**월 환산** (×4.3): 조회 ≈ 35,400/월 · 진입 ≈ 95/월

| 구간 | 값 | 실측 여부 |
|---|---|---|
| 조회→진입 | **0.267%** | ✅ 실측 (GA×쓰레드 교차) |
| 진입→결제 | **3%** (보수) | ❌ 유료 미출시 = 가정. 무료 SaaS→유료 벤치 2~5% |

**통합**: 조회→결제 = 0.267% × 3% = **0.008%** (조회 1만당 결제 0.8명)

## 6. 기간은 어떻게 정하나 (← 대표 질문 1)

**지금은 못 정한다. 정하려고 추측하면 안 된다.** 이유: 기간 계산의 핵심 입력 = "월 신규 구독 수(M)"인데, 유료가 안 붙어 M=0이다.

**바텀업 산정법** (유료 붙인 뒤):
```
목표 개월 = (목표매출 ÷ ARPU) ÷ 월 신규 구독 M
```
유료 출시 후 2~4주 M을 재면 세 목표 기간이 전부 자동으로 나온다.

**현재 속도로 추정하면** (진입 95/월 × 진입→결제 3% = 월 신규 결제 ≈ 2.85명):

| 목표·ARPU | 필요 활성 | ÷2.85/월 = 기간 |
|---|---|---|
| 200만 / 9,900 | 202 | **71개월** (약 6년) |
| 200만 / 29,900 | 67 | **24개월** (2년) |

> 즉 **현재 유입·전환으론 1단계(200만)도 최소 2년.** 이건 "기간을 정하는 문제"가 아니라 "레버를 몇 배 당길지 정하는 문제"다. 6개월/1년 목표는 레버 없이는 산수상 불가.

**레버 4개** (곱으로 작동):
1. **조회→진입 0.267% ↑** — 프로필 문구·원링크 배치·랜딩 최적화. 최대 병목이자 최대 기회. 2배면 기간 절반
2. **진입→결제 ↑** — 온보딩·무료 훅. 3%→6%면 기간 절반
3. **ARPU ↑** — 크레딧 종량 얹어 2만원대. 9,900→29,900이면 기간 1/3
4. **조회 규모 ↑** — 발행 5개(8월)·유튜브·블로그. 단 §3대로 발행만으론 체감 한계

> 예: 조회→진입 2배 × ARPU 3배 = 필요치 1/6. 71개월이 12개월로. **복합이 유일한 경로.**

## 7. 유료 광고, 지금 할 시기인가 (← 대표 질문 2)

**아니다. 명확히 아니다.** 근거 3개:

1. **유료 기능 0 = LTV 계산 불가.** 광고비를 얼마 써도 되는지(회수되는지) 계산할 근거가 없다. 이 상태 광고 = 밑 빠진 독.
2. **조회→진입 0.267% = 랜딩·프로필이 아직 안 잡혔다.** 광고로 유입을 부어도 99.7%가 샌다. 새는 독에 물 붓기.
3. **광고 게이트 3조건 전부 미충족** ([대표-액션 광고게이트](../대표-액션.md)): 완주율 두자릿수 ❌ / 유료 1개 라이브 ❌ / 재방문 측정 ❌.

**올바른 순서:**
```
① 유료 기능 붙이기 (품절감시+썸네일)
② 2~4주 전환·M 실측 → LTV 계산
③ LTV > CAC 확인
④ 그때 유료 광고
```

> 예외(진단 목적 하루 5천원 소액)도 지금은 약하다 — 완주=유료전환이 없어 "무엇을 측정할지"가 불명확하다. 유료 붙은 뒤 진단 광고가 의미 있다.

**두 질문의 공통 답 = 유료 붙이는 게 먼저다.** 기간도 광고 시기도 전부 유료 출시가 잠금해제 키다.
