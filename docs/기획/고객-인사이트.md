### ⑤ 우리 GA4 데이터는 아직 pain의 근거가 될 수 없다 (2026-07-27 · 코드 실측)

**코드베이스 전체 `trackEvent` 호출 = 17개.** 플래그십 원링크(2,466줄)에 3개뿐이고, 등록 정보 시트(`RegistrationSheet.tsx`, 1,427줄, 섹션 ①~⑫)에는 **0개**다.

원링크 시트의 핵심 사용법은 "위에서 아래로 복사해 붙여넣기"인데, **12개 섹션 중 복사 이벤트가 달린 것은 ⑦상세HTML 하나뿐**이다. 상품명·카테고리·태그 복사, 옵션 엑셀 다운로드는 전부 집계되지 않는다.

> **따라서 "완주율 2.1%(search 94 → zip_download 2)"는 실제 완주율이 아니라 *측정 가능한* 완주율이다.**
> 사용자가 상품명을 복사해 스마트스토어에 붙여넣고 만족했더라도 우리는 알 수 없다.
> 계측 보강 전까지 **행동 데이터를 pain 근거로 인용하지 않는다.** 스펙: [ROADMAP 계측 섹션](../개발/ROADMAP.md)

## 외부 통계 (고객 목소리는 아니지만 판단 근거가 되는 것)

> 이 섹션은 "우리가 들은 것"이 아니라 "공개 조사에서 확인한 것"이다. 위 ①~⑤와 성격이 다르므로 분리한다.
> 어필리에이트 피벗 기각·타겟 근거는 [타겟-근거.md](./타겟-근거.md) 참조.

### 직장인 부업에서 이커머스는 소수다

**인크루트 뉴워커 / 2025-11-01~16 / n=728 / 95% 신뢰수준**

| 순위 | 부업 종류 | 비율 | 성격 |
|---|---|---|---|
| 1 | 행사·이벤트 진행 | 37.2% | 오프라인 |
| 2 | 개인 역량 기반(디자인·번역·강의) | 27.5% | 주로 온라인 |
| 3 | 당일 급구 아르바이트 | 27.2% | 오프라인 |
| 4 | **블로그·SNS 운영** | **20.8%** | 온라인 |
| 5 | 배달 | 12.2% | 오프라인 |
| 6 | **이커머스 운영(스마트스토어 등)** | **6.1%** | 온라인 — **최하위** |

- 부업 선택 기준: **시간 55.3%** > 수입 25.8%
- **부업 소득이 본업의 10% 미만인 사람: 48.6%** / 본업 이상: 1.9%

**해석 시 주의 3가지**
1. 온라인 부업만 놓고 봐도 **블로그·SNS가 이커머스의 3.4배**다. 다만 "개인 역량 기반"에 오프라인 강의가 섞여 있어 온/오프 구분이 깔끔하지 않다.
2. **설문 부업률(직장인 48.4%)과 공식통계 부업률(약 2%)이 20배 차이 난다.** 설문의 자기선택 편향 때문. **시장 규모 추정에 설문 비율을 쓰면 20배 과대추정한다.**
3. **"온라인 부업만" 조준한 조사는 존재하지 않는다.** 검색 결과 상위는 전부 방법론 없는 SEO 블로그다.

**우리 판단에 미치는 영향 — 제한적이다.** 우리 타겟은 "부업을 시작하려는 사람"이 아니라 [PLAN 2장](./PLAN.md)이 정의한 **"이미 도매꾹에서 떼다 스마트스토어에 올리고 있는 사람"**이다. 부업 인기 순위는 *신규 유입 경로의 크기*지 *타겟의 크기*가 아니다. 오히려 이커머스 부업 비중이 낮다는 것은 **경쟁 툴도 적다**는 뜻일 수 있다.

### 위탁판매의 실제 현금 리스크는 거의 0이다

## 확인이 필요한 것 (다음 검증 후보)

### 🔬 진행 예정: 대표 직접 셀러 체험 (2026-07-27 착수 결정)

**왜 하는가**: 지금 검증된 pain은 **설문 7표 + 쓰레드 2건**이 전부다. 이 표본으로 제품 우선순위와 유료 1호를 정하고 있다. [ROADMAP 이월 후보 #4 (R-10 시험구매)](../개발/ROADMAP.md)가 미실행 상태로 남아 있던 것도 같은 공백이다.

**설계·기록**: [셀러-체험기록.md](./셀러-체험기록.md) — 상품 3개(#1 맨손 / #2·#3 오토셀러), 2주, 단계별 실측

**검증할 가설 3개**
- **H1** 이미지 가공이 최대 시간이다 (설문 71%) → 단계별 실측 시간으로 검증
- **H2** 오토셀러가 실제로 시간을 줄인다 → #1 vs #2 소요 시간 차
- **H3** 셀러 입장에서 이 도구에 돈을 낼 것인가 → 유료 1호 선정의 1차 근거

⚠️ **N=1이고 대표는 일반 초보가 아니다** (개발자 + 도메인 수개월 학습). 대표가 안 막히는 곳에서 초보는 막힌다. **이 기록은 설문 71%를 대체하지 않고, 가설 생성용으로만 쓴다.**

### 설문·인터뷰 후보

- 상품 하나 등록에 실제 몇 분 걸리나 (H1의 외부 교차검증)
- 이미지 작업 중 제일 귀찮은 단계 (누끼 / 규격 / 워터마크 / 상세분할)
- 지금 가장 막혀 있는 단계 (소재선정 / 소싱 / 가격 / 등록 / 노출)
- 한도제 이후 등록 전략이 바뀌었나 (④가 실제 셀러에게 미친 영향)
- **AI 썸네일에 장당 얼마까지 낼 수 있나** (시장가 앵커 200원 대비) — 유료 1호 지불의사 측정

## 기록 원칙

1. **출처·표본 크기 필수** — 없으면 적지 않는다
2. **말(설문·인터뷰)과 행동(GA4)을 구분**하고, 일치하면 명시
3. 표본 1-2건은 "정성 참고"로 표기, 단정하지 않는다
4. 범위 밖 의견도 기록 — 나중 단계의 근거가 된다
5. **(07-27 추가) 우리가 들은 것 / 외부 공개 통계를 섹션으로 분리한다** — 성격이 다르므로 같은 무게로 쓰지 않는다
6. **(07-27 추가) 계측이 없는 구간의 GA4 수치를 "안 쓴다"의 근거로 쓰지 않는다** — 없는 것과 안 보이는 것은 다르다
