> **C 재논의 앵커 (07-24 논의분 — 확정 아님)**
> - 구조 방향: 무료 + 단일 구독(크레딧 포함) + 크레딧 종량. **세션·토큰 제외** (토큰은 초보가 못 셈 / 세션은 어뷰징 방어 부담 → 몰아쓰기 데이터 확인 후 재검토)
> - 시장가 앵커: AI 생성 **200원/장** (경쟁 = 가비아 제디터 배경생성 220원, 토큰 방식)
> - 무료 범위가 이미 경쟁사 유료 (제디터 배경제거 55원) → 무료 유지가 곧 입구
> - 썸네일 잠정 2층: 무료(텍스트·뱃지·배경교체) + 유료(AI 배경 연출). **대표가 기능 재정의 중이라 확정 보류**
> - 미확정 4항목: 구독가(잠정 9,900) · 포함 크레딧(잠정 20장) · 크레딧 단가(잠정 200원) · 충전 단위
> - 500만은 첫 목표 아님 → 30명 전환 검증 후 재산정. 유료보다 **활성 셀러 유입이 선행**
