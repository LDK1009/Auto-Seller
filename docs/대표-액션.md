## 광고 게이트 (07-27 신설)

구글·네이버 광고는 아래 **3개가 동시에** 만족될 때까지 집행하지 않는다.

1. 측정 가능한 완주율(진입 → 산출)이 **두 자릿수**
2. 유료 기능 **1개 이상** 라이브 → LTV 계산 가능
3. 주간 재방문 사용자 측정 가능 (현재 `first_visit` 89 / `session_start` 101 = **신규 88%**)

**예외 — 진단 목적은 허용**: 하루 5,000원 이하로 "어떤 검색어로 온 사람이 완주하는가"를 사는 것은 규모 획득이 아니라 정보 구매이므로 지금 해도 된다.

**근거**: 7/17~24 주간 기준 외부 유입은 쓰레드가 사실상 전부(26세션)이고, 쓰레드는 발행 2→38개에서 조회 56→9,578(171배)로 **아직 선형 구간**이다. 한계비용 0인 채널이 꺾이기 전에 유료 채널로 넘어가는 것은 순서가 틀렸다.
