## 1. 브랜드 코어

| 항목 | 내용 |
|------|------|
| 미션 (SERVICE 1장) | 사용자가 단 한 건이라도 우리 서비스를 통해 순이익을 남기게 한다 |
| 브랜드 약속 | 무료로 시작하고, 가입을 요구하지 않고, 내가 올린 이미지를 서버로 가져가지 않는다 |
| 성격 | **실용적인 동료.** 화려하지 않지만 확실하게 일을 끝내주는 툴. 전문용어 자랑 ❌, 과장 ❌ |
| 말 거는 사람 | "밤 10시의 김진우" — 직장인 부업 위탁 셀러 (SERVICE 2장) |

비전 표현의 번역:

- 내부 문서: "위탁 셀러의 올인원 OS"
- **대외 카피: "소싱부터 등록까지, 한 곳에서"** — 고객에겐 OS라는 말을 쓰지 않는다

## 3. 슬로건 (확정)

```
온라인셀러를
반복작업에서
해방시킵니다
```

사용 규칙:

- **6·6·6 음절 3행 운율** — 공식 노출은 3행 줄바꿈 그대로 (임의 개행 변경 금지)
- 한 줄 표기: "온라인셀러를 반복작업에서 해방시킵니다"
- "온라인셀러" 붙여쓰기는 슬로건 안에서만 (본문은 "온라인 셀러")
- 우산형 슬로건 — 비전 확장(운영·마케팅 보조)에도 유지. **현재 제공 범위는 서브카피가 명시**

### 서브카피 원칙 (갭 관리)

슬로건은 비전을 말하되, 서브카피는 **지금 제공하는 것만 사실대로.** 검증 불가한 수치 금지.

> 기본형: *"도매매 링크 하나로 — 이미지 가공부터 다운로드까지. 무료 · 가입 없음 · 내 이미지는 서버로 가지 않습니다."*
> 부업 조준형: *"퇴근 후 몇 시간이 전부라면 — 이미지 작업은 오토셀러가 끝냅니다."*

- Phase 진행 시 서브카피만 갱신 (슬로건 유지)

## 4. 톤앤매너 (보이스)

1. **사실 기반** — 근거 없는 수치·최상급 금지. 기능이 하는 일을 그대로 말한다
2. **셀러의 언어** — "리사이징" 대신 "규격 맞추기", "세그멘테이션" 대신 "누끼"
3. **쉬운 한국어** — 한 문장 하나의 뜻, 사용자 행동 중심으로 쓴다 (예: "이미지를 올려주세요" ⭕ / "이미지 업로드가 요구됩니다" ❌)
4. **간결한 존댓말** — "~하세요", "~했습니다". 느낌표 안내당 최대 1개, UI 문구에 이모지 금지
5. **프라이버시는 능동태·정확하게** — "내가 올린 이미지는 서버로 가지 않습니다" (모호한 "안전하게 처리" ❌)
6. **경쟁사 언급 금지** — 비교 대신 우리 사실만

## 6. 핵심 메시지 블록 (카피 재료 — 전부 사실)

1. **무료** — 장당 과금 없음, 무제한
2. **무가입** — 열면 바로 사용
3. **내 이미지는 브라우저에서** — 서버로 전송되지 않음 (상품 유출 걱정 없음)
4. **여정 메시지** — "도매매 링크 하나 → 등록용 이미지 세트" (도구 나열이 아니라 흐름으로 말한다)

## 7. 디자인 원칙 (2026-07-06 확정 — 토스 디자인 시스템 적용)

> **경쟁사(윈들리·드랩아트 등) 디자인은 참고하지 않는다.** 대신 이업종 선진 사례인 **토스의 UI/UX 노하우를 적극 차용**한다 — 단, 브랜드 얼굴(인디고·체커보드)은 우리 것 유지.
> 실행 기반: [docs/design/](./design/README.md) — 토스 공식 TDS 문서(1차 소스) + 벤더링 규칙집(`DESIGN-LANGUAGE.md`)·Toss 토큰. **별도 스킬 없이 UI 작업 시 이 규칙을 기본 준수한다.**

### 원칙 6개

1. **화면당 핵심 행동 1개** — 각 화면에서 사용자가 다음에 할 일이 하나로 보여야 한다 (주 CTA 1개, 나머지는 조용히)
2. **타이포 위계로 말한다** — 제목은 크고 무겁게(Pretendard 700~800), 부가정보는 작고 연하게. 균질한 밀도 금지
3. **여백·라운드·보더 중심** — 그림자 최소화, 얇은 보더 + 큰 라운드(토큰 2단계로 통일). 도구 화면은 밀도 있게, 안내 화면은 여백 크게
4. **모션은 기능 피드백만** — 상태 변화(완료·전환·진행)에만 스프링/이즈 모션 150~300ms. 장식 모션 금지 (과한 모션 = 싸구려)
5. **쉬운 한국어 UX 라이팅** — 4장 톤앤매너를 UI에 그대로 적용
6. **시그니처 모티프: 투명 체커보드** — 누끼의 상징이자 제품에서 나온 우리 것. 로고·빈 화면·히어로 패턴에 재사용

### 구현 방식

- 디자인 시스템 = **코드** (MUI 중앙 테마 토큰 + `shared/components`) — 별도 Figma 없이 테마가 단일 진실
- **Toss 스킨 토큰 이식**: `docs/design/toss-skin-tokens.css`의 텍스트 위계·서피스·그림자·라운드 체계를 MUI 테마로 번역 (Tailwind 변수 직접 사용 ❌, 브랜드 컬러는 인디고 유지 — Toss 퍼플 ❌)
- 토큰 수술 대상: 그림자 스케일(card/hover/elevated/modal), 라운드 통일(0.625rem 기준), 텍스트 3위계(primary/secondary/tertiary), 인디고 틴트(`brand-tint` 상당), 숫자 tabular figure
- 품질 관리: UI 작업 시 DESIGN-LANGUAGE 규칙(특히 §3 위계·§12 그림자·§18 금지 규칙) 기본 준수 — 별도 스킬 없음

## 8. 마케팅 원칙 (세스 고딘 『이것이 마케팅이다』)

1. **최소유효시장** — "모든 셀러" 금지. 조준점은 부업 위탁 셀러 (SERVICE 2장)
2. **변화를 판다** — 기능(누끼)이 아니라 변화("반복 노동 → 기획하는 시간, 그리고 잠")를 말한다. 단, 사실 기반 안에서
3. **부족 만들기** — "우리 같은 부업 셀러는 이걸 쓴다"는 소속감. 도구가 아니라 문화로
4. **허락 마케팅** — 관심을 훔치지 않는다. 커뮤니티 도배·스팸 금지, 가치(가이드 콘텐츠·규격표) 선제공 후 자연 노출
5. **리마커블** — 광고비 대신 말하고 싶어지는 지점: 도매매 링크→ZIP 여정, 프라이버시, 무가입
6. **약속하고 지킨다** — 마케팅 스토리가 제품보다 앞서면 스토리를 낮춘다 (서브카피 갭 관리)

콘텐츠 소재 우선순위 (SERVICE 9장):

1. "도매매 전문셀러 가입법 (사업자등록부터)" — 초보의 진짜 첫 관문
2. 마켓별 이미지 규격표 → 규정 검사기 연결
3. 소싱한 상품의 마진 보는 법 → 계산기 연결

## 9. 금지 목록 (냉철 체크리스트)

- ❌ 검증 안 된 수치 ("등록 시간 90% 단축")
- ❌ 최상급·과장 ("국내 최초", "업계 최고")
- ❌ 아직 없는 기능을 현재형으로 (원클릭 등록은 ②b 출시 전까지 금지)
- ❌ 수익 보장 뉘앙스 ("매출이 오릅니다" — 미션은 돕는 것이지 보장이 아님)
- ❌ 경쟁사 이름 직접 비교
- ❌ 공급사 워터마크 제거 용도 언급 (SERVICE 11장)
- ❌ 페르소나 내부 수치의 카피 사용
- ❌ **경쟁사** 룩앤필 복제 (토스 등 이업종 노하우 차용은 허용 — 7장)
