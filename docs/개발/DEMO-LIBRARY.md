# 데모 영상 라이브러리 (2026-07-23 신설)

기존 숏츠(타이머 실측 챌린지)는 **광고처럼 읽혀 폐기**. 쓰레드 등 소셜에 붙일 **기능 시연 영상**을 기능별·케이스별로 나눠 만든다.

## 숏츠와 무엇이 다른가

| | 구 숏츠 (폐기) | 데모 영상 |
|---|---|---|
| 목적 | "몇 초 만에!" 임팩트 | **뭘 하는 건지 이해시키기** |
| 연출 | 타이머·결과 카드·BGM | 없음. 화면 + 자막 + 강조만 |
| 훅 | 광고 카피 | **씬 제목** (좌상단 상시) |
| 길이 | 25-30초 고정 | 기능에 맞게 (15-60초) |
| 단위 | 하루치 소재 | **기능·케이스별 재사용 자산** |

**핵심: 광고가 아니라 설명서.** 담백하게, 대신 어디를 봐야 하는지 확실하게.

## 화면 구성 (고정)

```
┌─────────────────────────────┐
│ [씬 제목]        ← 좌상단 상시  │
│                             │
│      실제 서비스 화면          │
│   (부드러운 커서 + 강조 링)     │
│                             │
│        [자막]     ← 하단      │
└─────────────────────────────┘
```

- **씬 제목**: 지금 뭘 하는 단계인지. 화면 바뀔 때마다 교체
- **강조 링**: 조작 대상 영역을 감싼다 (`showSection` 좌표 자동)
- **자막**: 한 동작 = 한 줄. 전문장
- **커서**: 곡선 이동 + 감속 (기존 `humanize.ts`)
- **녹화**: **모바일 뷰 414×896** (2026-07-24 확정 — PC뷰는 세로 프레임에서 축소돼 안 읽힌다)
- **출력**: 세로 1080×1920 (쓰레드·릴스 기준). 모바일 녹화가 그대로 꽉 찬다
- **줌**: 강조 구간에만 스프링 줌인 (기본 1.0배). 등속 금지
- **로딩 구간**: `waitLoaded()`로 표시 → 빌드에서 **자동 삭제** (시청자는 기다려주지 않는다)
- **오프닝 훅 3초**: 결과 장면 + 큰 문구. 그 뒤 본편, 끝에 CTA 2초

## 대본 형식

시나리오 파일 안에 씬 제목·자막을 함께 정의한다 (별도 md 불필요 — 짧고 조작과 1:1).

```ts
export const demo: DemoScenario = {
  id: "nukki-basic",
  title: "이미지 여러 장 배경 제거",
  url: "/background-removal",
  hookText: "상품 20개 올리는데\n누끼만 두 시간",   // 첫 3초 — 시청자를 붙잡는 한 줄
  ctaText: "누끼 여러 장\n한 번에",                 // 엔딩 2초
  scenes: [
    { title: "이미지 올리기", caption: "가공할 상품 사진을 한 번에 올립니다" },
    { title: "배경 제거", caption: "여러 장을 한 번에 처리합니다" },
    { title: "ZIP으로 받기", caption: "등록에 바로 쓸 수 있게 묶어서 받습니다" },
  ],
  run: async (p) => {
    p.markScene();               // 씬 경계 — scenes 순서와 1:1
    // ... 조작
    await p.waitLoaded(locator); // 로딩 구간 표시 → 빌드에서 삭제
    await p.showSection(target); // 정차역 = 강조 링 + 줌인
  },
};
```

**문구 규칙 ([MARKETING.md](../마케팅/MARKETING.md) 톤앤매너):** 읽는 사람은 **이미 파는 셀러**다.
- 업계 용어 그대로 — 누끼·MOQ·상세·대표이미지
- 설명 금지 — "위탁판매란", "상세페이지란"
- 훅은 겪는 상황으로 — "상품 20개 올리는데 누끼만 두 시간" ⭕ / "배경 제거가 힘드신가요?" ❌
