# 도매꾹 기술지원 문의 메일 (최종본 — 복붙 발송용)

> 발송: 대표 계정(API 키 소유자 명의) → **techsupport@ggook.com**
> 목적: R-3(이미지 약관) 서면 확인 + L-6b(인기검색어) 가능 여부. 배포 전까지 발송 권장.

---

**제목:** [오픈API] 상품 이미지 사용권 필드 및 셀러 지원 도구 활용 문의

안녕하세요.

도매꾹 오픈API 키를 발급받아 사용 중인 개발자입니다. 도매매 전문셀러들이 상품 등록 준비(이미지 가공 등)에 쓰는 웹 도구를 개발하고 있어, 아래 네 가지를 문의드립니다.

**1. 이미지사용권 판별 필드**
상품리스트(getItemList) 응답의 `lwp` 필드와, 상품상세(getItemView) 응답의 `desc.license.usable` 필드의 정확한 의미가 궁금합니다. 상품별 "이미지 사용 허용 여부"를 판별하는 공식 필드는 무엇인가요? (일부 상품에서 `desc.license.msg`의 문구와 두 필드 값이 서로 달라 확인차 여쭙습니다.)

**2. 제3자 도구에서의 이미지 활용 범위**
도매매 전문셀러가 본인 판매 목적으로 사용하는 웹 도구에서, 오픈API로 조회한 상품 이미지를 셀러의 브라우저에서 가공(배경 제거, 규격 변환 등)하도록 제공하는 것이 오픈API 이용정책상 허용되는지 확인 부탁드립니다. 이미지는 서버에 저장하지 않고 셀러에게 전달·가공 용도로만 사용합니다.

**3. 사용 조건 고지 방식**
저희 도구는 이미지 수집 전에 공급사의 이미지 사용 조건(`desc.license.msg` 원문)을 화면에 그대로 표시하고, 셀러가 확인해야 진행되도록 만들었습니다. 이 방식으로 충분한지, 권장하시는 절차가 따로 있는지 궁금합니다.

**4. 인기검색어 API**
인기검색어(검색어 랭킹) 조회 API가 제공된다면, 오픈API 키로 이용 가능한지 또는 별도 권한 신청이 필요한지 문의드립니다.

감사합니다.
