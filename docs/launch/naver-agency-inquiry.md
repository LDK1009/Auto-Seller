# 네이버 커머스API 대행사 자격 문의 (원클릭 등록 경로 확인)

> 등록 채널: https://github.com/commerce-api-naver/commerce-api/discussions (Q&A)
> 배경: 공지 #1564 — 제3자는 솔루션마켓·API대행사 경로만 허용, 사용자 키 수취는 약관 위배 소지.
> 솔루션마켓 = 법인 전용(대표 확인). 남은 확인 = API대행사의 개인사업자 자격.

## 제목

개인사업자의 대행사/솔루션 애플리케이션 발급 자격 문의 (제3자 셀러 지원 도구)

## 본문

안녕하세요. 스마트스토어 셀러의 상품 등록 준비(이미지 가공, 판매가 계산 등)를 돕는
웹 도구를 운영 중인 개인사업자 개발자입니다.

공지 #1564(애플리케이션 인증 정보 공개 시 조치사항)를 확인했고, 제3자 서비스가
판매자의 '내스토어 애플리케이션' 인증 정보를 제공받는 방식은 약관 위배 소지가
있다는 점을 인지하고 있습니다. 정식 경로로 진행하고자 아래 세 가지를 문의드립니다.

1. API대행사 애플리케이션 발급 자격
   API대행사(대행사 애플리케이션) 발급은 법인 사업자만 가능한가요,
   개인사업자도 신청할 수 있나요? 가능하다면 신청 절차와 심사 기준이 궁금합니다.

2. 커머스솔루션마켓 입점 자격
   커머스솔루션마켓 입점(솔루션 애플리케이션 발급)은 법인 전용으로 알고 있는데,
   맞는지 공식 확인 부탁드립니다. 개인사업자를 위한 대안 경로가 있다면 안내 부탁드립니다.

3. 법인 전환 전 허용 범위
   위 두 경로가 모두 법인 전용이라면, 개인사업자 단계의 제3자 도구가
   상품 등록 API(POST /v2/products)를 약관에 맞게 활용할 수 있는 방법이
   존재하는지 궁금합니다. 없다면 법인 전환 후 진행하겠습니다.

감사합니다.

## 회신 오면

- 1번 "개인사업자 가능" → 대행사 신청 즉시 착수 (원클릭 최단 경로 개방)
- 전부 법인 전용 확정 → ROADMAP 유지 (S2 법인 전환과 커플링), 등록 준비 패키지 우선
