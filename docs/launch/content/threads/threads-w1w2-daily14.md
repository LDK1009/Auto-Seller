# 스레드 W1~W2 — 14포스트 (복붙용)

## D1

위탁판매 하려고 사업자등록까지 냈습니다.
그리고 4개월째 상품이 0개입니다.
등록하다가 빡쳐서 등록 도구를 만들고 있었거든요.
이 계정은 그 반성문입니다.

## D2

위탁판매 등록 과정 요약:
이미지 저장 → 누끼 → 규격 맞추기 → 상세 자르기 → 복붙 → 복붙 → 복붙
이걸 상품마다 반복한다는 걸 알고 개발자의 병이 도졌습니다.
"이거 자동화되는데?"
그렇게 팔지도 않을 도구를 넉 달 만들었습니다.

## D3

누끼를 서버 없이 브라우저에서 돌리면 얼마나 걸리나 실측해봤습니다.
그래픽카드 있으면 장당 1.7초, 없으면 12초.
10장에 최악 2분. 커피 한 모금이면 됩니다.
서버로 안 보내는 이유? 여러분 아이템, 저도 못 보는 게 맞으니까요.

## D4

네이버 검색광고 API 붙이다가 403 에러로 하루를 태웠습니다.
원인: 문서 구석에 있는 CUSTOMER_ID 하나.
사장님들이 밤에 이미지 노가다로 시간 버리는 동안
저는 밤에 API 문서로 시간을 버립니다. 공평하네요.

## D5

도매꾹에 공식 문의를 넣었습니다. "상품 이미지, 위탁 셀러가 도구로 가공해도 되나요?"
답: 상품별 라이선스 필드 기준으로 판단하면 된다고.
그래서 도구에 그 조건을 그대로 띄웁니다. 안 되는 상품은 차단합니다.
남의 계정 걸고 장사할 수는 없잖아요.

## D6

위탁 사장님들께 질문.
상품 하나 등록하는 데 보통 몇 분 걸리세요?
저는 처음에 한 시간 넘게 걸려서 사업을 접을 뻔했습니다. 만들던 게 도구라 다행이었지…

## D7

키워드 분석 차트를 13종 만들었습니다.
트렌드, 시즌, 성별, 연령, 가격대, 브랜드 장악도…
이쯤 되면 뭘 팔지 몰라서 못 파는 게 아니라
차트 만드느라 못 파는 겁니다.

## D8

네이버 API가 자꾸 429(과호출 차단)를 뱉어서 속도 제한을 실측했습니다.
요청 간격 재고, 청크 나누고, 재시도 붙이고.
이 정성 절반이면 상품 열 개는 올렸을 텐데요.

## D9

MOQ라고, 도매 상품엔 "2개부터 구매" 같은 조건이 있습니다.
초보 때 이거 모르고 마진 계산하면 원가가 두 배로 뛰죠.
그래서 도구가 묶음 원가로 역산해서 판매가를 뽑게 했습니다.
제가 당할 뻔한 건 다 기능이 됩니다.

## D10

오늘 처음으로 셀러 커뮤니티에 도구를 공개했습니다.
무료고 가입도 없습니다. 4개월 만의 첫 "출시"네요.
상품은 여전히 0개인데 서비스가 먼저 나왔습니다.
👉 auto-seller.co.kr

## D11

첫 사용자 피드백이 왔습니다.
버그 제보인데 기분이 좋습니다. 쓴 사람이 있다는 뜻이라서요.
고치고 "고쳤습니다" 답글 달았습니다. 이 맛에 만드나 봅니다.

## D12

오토셀러에서 제일 자신 있는 건 화려한 기능이 아니라 순서입니다.
링크 넣으면 → 이미지 → 누끼 → 규격 → 등록 정보까지 한 줄로.
따로따로 하는 도구는 많은데, 이어지는 도구가 없어서 만들었습니다.

## D13

사장님들은 소싱할 때 뭐부터 보세요? 검색량? 마진? 감?
전 데이터부터 보는 도구를 만들었는데
정작 제 소싱은 아직 감도 못 잡았습니다. 도구가 사람을 못 이기네요.

## D14

2주 일지 결산.
만든 것: 등록 준비 도구 풀세트. 판 것: 0개.
근데 이제 팔 준비하는 분들 시간은 확실히 아껴드릴 수 있습니다.
무료·무가입·이미지는 브라우저 밖으로 안 나감.
