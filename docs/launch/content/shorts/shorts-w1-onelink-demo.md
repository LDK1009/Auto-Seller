# 원링크 시연 GIF·쇼츠 스토리보드 (W1 제작물)

> 용도: ① 카페 첫 글 삽입 GIF (15~25초) ② 유튜브 쇼츠 원본 (30~40초)
> 원칙: 무편집 실시간이 기본 — 빠른 게 아니라 **진짜인 게** 포인트. 누끼 처리 대기 구간만 배속 허용, 화면에 "3배속" 표기 (사실 기반 유지).

## 녹화 준비

- 브라우저 창 1개만, 북마크바·확장 아이콘 정리 (개인정보·잡탕 화면 금지)
- 해상도 1920×1080, 페이지 줌 110~125% (모바일에서 글자 보이게)
- 시연 상품: 라이선스 usable=true + 이미지 6~10장짜리 (너무 많으면 GIF가 늘어짐)
- 도구: 화면녹화(OBS 등) → GIF 변환 시 720px 폭·15fps면 카페 용량 통과

## 씬 구성 (쇼츠 기준 — GIF는 씬 2~6만)

| 씬 | 화면 | 길이 | 자막 |
|----|------|------|------|
| 1 | 도매꾹 상품 페이지 스크롤 (이미지 여러 장 보여줌) | 3s | 이 상품, 등록하려면 이미지만 몇 장일까요 |
| 2 | 주소창 URL 복사 | 2s | 링크만 복사합니다 |
| 3 | 원링크에 붙여넣기 → 이미지 자동 수집되는 순간 | 4s | 붙여넣으면 이미지를 알아서 모아옵니다 |
| 4 | 누끼 일괄 처리 진행률 (배속 구간) | 4s | 누끼도 한 번에 (3배속) |
| 5 | 규격 변환 → 1000×1000 결과 그리드 | 4s | 마켓 규격까지 맞춰서 |
| 6 | ZIP 다운로드 클릭 → 폴더 열어 파일 목록 보여줌 | 4s | 등록 창에 바로 올리면 끝. 무료·가입 없음 |
| 7 (쇼츠만) | 등록 정보 시트 스크롤 (판매가·카테고리·태그) | 5s | 판매가 계산이랑 태그 후보까지 뽑아줍니다 |
| 8 (쇼츠만) | 랜딩 페이지 | 3s | 오토셀러 — 검색하면 나옵니다 |

## 쇼츠 업로드 메타

- 제목: `도매꾹 링크 하나로 등록 이미지 만들기 (무료, 가입 없음)`
- 설명: 링크 + "이미지는 브라우저에서만 처리됩니다 — 서버로 올라가지 않습니다."
- 마지막 프레임에 URL 텍스트 고정 (음성 없어도 성립하게)

## 체크

- [ ] 자막에 수치·최상급 금지 (BRAND 9장) — 위 자막 그대로 사용
