# 대표 직접 위탁판매 실험 (독푸딩)

> 시작: 2026-07-07 계획 수립. 목적: ① 제품 확신의 근거 확보(독푸딩) ② 커뮤니티 첫 글의 사실 기반 서사 ③ 제품 백로그 1차 소스.
> 원칙: 성공이 아니라 **학습**이 목표. 경험은 n=1 — 가설 생성용이며, 검증은 사용자 데이터로.

---

## Phase 0 — 법적 준비 (0주차, 실비 ~5만 원)

- [ ] 사업자등록 — 홈택스, 무료, 1~3일. 업태 "도매 및 소매업" / 종목 "전자상거래 소매업" / **간이과세** / 자택 주소
- [ ] 통신판매업 신고 — 정부24, 면허세 연 12,000~40,500원 (사업자등록 후)
- [ ] 스마트스토어 사업자 판매자 가입 (심사 1~2일) + **스타트 제로수수료 신청** (12개월 주문관리 수수료 면제)
- [ ] 도매매 전문셀러 가입 (사업자등록증 필요)
- [ ] 부업용 통장·카드 분리 (회계 단순화)

## Phase 1 — 상품 선정: 롱테일 역산 소싱 (1주차)

**절차:** 분야 2~3개 (소비자로서 아는 영역) → 키워드 발굴 → 숫자 검증 → 도매매 역검색 → 5~10개 선정

**키워드 통과 기준 (전부 충족):**

| 기준 | 값 | 확인 방법 |
|------|-----|----------|
| 월 검색량 | 1,000~10,000 | 네이버 검색광고 키워드도구 (무료) |
| 쇼핑 등록 상품 수 | 5,000개 미만 | 네이버쇼핑 검색 결과 수 |
| 1페이지 평균 리뷰 | 100개 미만 | 육안 확인 (빅브랜드 점령 시 패스) |
| 판매가 | 1~3만 원대 | 마진 절대액과 전환율 균형 |
| 시즌 | 3개월+ 여유 | — |

**상품 통과 기준:**
- [ ] 역산 마진 계산기: 목표 마진 20% 확보 (배송비 포함 계산)
- [ ] 원링크 라이선스 게이트: 이미지 사용 조건 "허용" 확인
- [ ] 공급사 발송 속도 빠름 (도매매 sendAvg 참고), 재고 충분
- [ ] **지뢰 회피**: KC 인증 대상(유아·전기), 인허가(식품·수입화장품), 브랜드/캐릭터(지재권) 제외

## Phase 2 — 등록 (1~2주차): 우리 도구 총동원

상품마다:
1. 원링크: 링크 붙여넣기 → 조건 확인 → 이미지 선택 → 누끼 자동
2. 규격 변환 1000×1000 → 규정 검사 → ZIP
3. 상세페이지: 도매매 상세 이미지 (+필요 시 분할 도구)
4. 상품명: `[핵심키워드] + [속성] + [세부키워드]`, 50자 내, 단어 중복·특수문자 금지
5. 가격: 역산 계산기 추천가 (10원 올림 그대로)
6. 카테고리 정확 매칭, 상품정보제공고시·원산지는 도매매 페이지 참조, 태그 10개
7. ⏱ **상품 1개 총 소요시간 기록** (= 아하 모먼트 실측)

## Phase 3 — 운영 (2~6주차)

- 루틴: 주 2~3회, 밤 1~2시간 (타겟 조건 재현)
- 주간: 신규 2~3개 등록 + 스마트스토어센터 통계 확인 (유입 키워드·노출·클릭)
- 주문 발생 시: 도매매에서 고객 주소로 발주 → 송장 등록 → 정산 확인
- 📝 **마찰 로그** (아래에 계속 기록) — 제품 백로그 1차 소스

## 4주 판정 (성공/실패가 아니라 학습 체크)

- [ ] 검색 노출 발생했는가 (키워드별)
- [ ] 클릭 발생했는가 (CTR — 대표이미지 품질 검증)
- [ ] 주문 1건 이상 (미션 "단 한 건이라도 순이익"의 셀프 검증)
- [ ] 우리 도구로 못 푼 마찰 리스트 → 백로그 반영
- [ ] 커뮤니티 첫 글 발행 (**기한: 실험 시작 +2주**, 완벽 대기 금지)
