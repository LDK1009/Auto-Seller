## 스마트스토어

### 대표이미지 (썸네일)

| 항목 | 기준 |
|------|------|
| 권장 크기 | **1000×1000 (정방형)** |
| 최소 크기 | 300×300 미만이면 부적합 |
| 용량 | 20MB 이하 |
| 형식 | JPG 권장 (PNG 가능) |

크기만큼 중요한 게 **감점 요소**입니다. 대표이미지에 이런 게 들어가면 노출에서 불이익을 받을 수 있습니다:

- 텍스트·홍보 문구 ("무료배송", "1+1" 등)
- 로고·워터마크
- 여러 상품을 한 장에 콜라주
- 과도한 테두리·배경 효과

깨끗한 단일 상품 사진이 기본입니다. 공급사 이미지를 그대로 쓰면 상단에 홍보 문구가 박혀 있는 경우가 많아서, 잘라내거나 누끼를 따서 쓰는 게 안전합니다.

### 상세페이지

| 항목 | 기준 |
|------|------|
| 가로 폭 | **860px** (스마트에디터 본문 폭) |
| 세로 | 한 장이 너무 길면 업로드·로딩이 느려짐 — 길면 분할 업로드 |
| 용량 | 장당 20MB 이하 |

가로 860px보다 크게 만들면 자동 축소되면서 글자가 뭉개질 수 있습니다. 처음부터 860px 폭으로 만드는 게 깔끔합니다.

## 쿠팡 (비교용)

| 항목 | 기준 |
|------|------|
| 대표이미지 | 정방형, 최소 500×500 · 권장 1000×1000 |
| 상세 가로 폭 | **780px** 권장 |
| 상세 세로 | **한 장당 최대 3,000px** — 긴 상세는 반드시 분할 |
| 상세 용량·형식 | 장당 5MB 이하 · JPG 권장, 최대 20장 |

스마트스토어용 상세(860px)를 쿠팡에 그대로 올리면 폭·세로 제한에 걸립니다. 마켓별로 따로 뽑아야 합니다.
