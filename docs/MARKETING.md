## 1. 전략 한 줄

> **원링크 시연 하나로 커뮤니티에 들어가서, 계산기·키워드 분석을 검색 입구로 깔고, 재방문을 습관으로 만든다.**

- 조준점: 직장인 부업 위탁 셀러 (카피만 좁힘 — 제품 게이트는 안 좁힘, SERVICE 2장)
- 파는 것: 기능이 아니라 변화 — "밤 시간을 이미지 노가다에서 되찾는다"
- 무기 서열: ① 원링크(리마커블 본체) ② 계산기·키워드 분석(검색 상시 입구) ③ 무료·무가입·프라이버시(신뢰 축)

## 2. 퍼널과 지표

```
발견(커뮤니티·검색·쇼츠) → 방문 → 30초 첫 처리(무가입) → ZIP 다운로드(아하 = NSM)
→ 재방문(원링크 루틴 = 습관) → 자발 언급(부족)
```

| 단계 | 지표 | 도구 |
|------|------|------|
| 발견 → 방문 | 채널별 세션 (UTM) | GA4 |
| 방문 → 아하 | zip_download / 세션 | GA4 (이벤트 심어짐) |
| 아하 → 습관 | 재방문율 | GA4 |
| S1 게이트 | WAU 500 × 4주 + 재방문 25% | 후퇴선: 6개월 WAU 100 미달 (SERVICE 8장) |

- 첫 4주는 목표 수치를 박지 않는다 — 사용자 0에서 전환율 가정은 소설. **4주 실데이터로 1회 보정** (SERVICE 8장 원칙).
- UTM 규칙: `utm_source=cafe|blog|youtube` / `utm_medium=post|shorts` / `utm_campaign=launch-01` 형식 고정.

## 3. 카피 원칙 — 독자 머릿속 3문장에 답한다

BRAND 4장(톤)·9장(금지) 위에 얹는 실행 규칙. 기능 나열·회사 입장 방어 논리(서버 비용·아키텍처 주어) 금지 — 독자가 이미 갖고 있는 문장에 정면으로 답한다:

| 독자 머릿속 문장 | 답 (확정 카피) |
|------|------|
| "누끼 장당 돈 아깝다" (돈) | "장당 얼마씩 내고 따던 누끼, 여기선 100장을 돌려도 0원입니다" (100장 = 실제 입력 제한, 사실) |
| "무료? 꿍꿍이 있겠지" (의심) | "맞아요, 저도 언젠가는 돈 벌 생각 있습니다. 근데 그건 나중에 지금 없는 기능 붙일 때 얘기고, 오늘 보여드린 이미지 도구는 그대로 무료입니다" — 선제 자백 + **무료 범위 한정**(유료화 시 이 문장을 인용하며 방어) |
| "내 아이템 샐라" (공포) | "이미지는 제 서버로 안 옵니다. 무슨 아이템 파시는지 저는 볼 방법도 없습니다" |

- 무료 약속은 항상 범위 한정 문장으로만 ("지금 있는 이미지 도구는 그대로 무료") — 근거를 개인 동기("받을 이유가 없었어요")에 묶는 문장 금지 (유료화 시 배신 프레임 박제).
- 커뮤니티 글은 매끈한 카피화 금지 — 홍보 레이더 회피. 힘줄 문장은 글당 1개.

## 4. 채널 플레이북 (주 10시간 배분)

| 채널 | 주당 | 역할 | 실행 규칙 |
|------|------|------|----------|
| **커뮤니티** (주력) | 3h | 발견·부족 형성 | 아사장 → 셀러오션 순차. 곳당 월 1~2편, 가치글만. 댓글 24h 응답 — 첫 20명이 피드백 자산. 피드백 반영 시 "고쳤습니다" 공개 답글 = 신뢰 루프. 도배 = 즉사 |
| **검색 자산** | 3h | 상시 유입 | 두 갈래: ⓐ 사이트 내 가이드(구글 SEO) ⓑ 네이버 블로그(닉네임 명의). 글 끝 = 해당 도구 직결 링크. 소재는 §5 뱅크 |
| **쇼츠/GIF** | 2h | 아하 시연 | 얼굴 불필요 — 화면녹화만. "도매꾹 링크 → 등록 이미지 세트" 실시간 시연. 커뮤니티 글에도 GIF 삽입 |
| **스레드** (07-14 편입) | 1h | 서사 축적·부족 | 빌드 인 퍼블릭 일지 — 하루 1포스트(5~10분): 개발·출시·피드백 반영 기록. 서사("도구부터 만든 개발자")와 포맷 최적 궁합. 외부 링크는 프로필 고정 + 가끔만(알고리즘 억제). 즉시 유입 채널 아님 — 적립식 |
| **제품 내 루프** | 1h | 재방문·확산 | ZIP 완료 화면 "다음 단계" 제안 · 계산기 결과 공유 URL · 도구별 OG 이미지 (개발 반나절짜리 3건) |
| **측정 리추얼** | 1h | 조타 | 주 1회: 채널별 세션·zip_download·재방문 + 커뮤니티 반응 로그 → 다음 주 소재 결정. 죽은 채널 4주 후 폐기 |

**콘텐츠 생산 분담:** 초안 100% = Claude (카페·블로그·쇼츠 자막·스레드 일지 배치 생산), 검수·말투 개인화(편당 10~20분)·발행·댓글 = 대표. **자동 발행 금지** — 스팸 판정·AI 문체 낙인·허락 마케팅 위반 3중 리스크.
