# 서비스 소개
한줄 소개 :도매꾹 링크 하나로 이미지 가공부터 등록 정보까지 초보 위탁 셀러의 상품 등록 반복작업을 없애는 툴
타겟 : 초보 위탁 셀러, 부업에 관심 있는 직장인•퇴작자•육아맘

# 서비스 기능
[원링크] — 플래그십
"링크 하나로 등록 정보까지" — 도매꾹 URL 하나 넣으면 스마트스토어 등록 직전까지 전부.

사용 흐름:
1. 상품 입력 — 도매꾹 링크·상품번호를 붙여넣거나, 검색(인기순·가격·낱개 필터)으로 상품 선택
2. 상품 확인 — 상품 요약(도매꾹가·최소구매수량·배송비), MOQ 2개 이상이면 묶음(1+1) 구성 판매 안내,
   공급사 이미지 사용 허용 여부 자동 확인 (미허용 상품 차단, 편집 허용 범위 고지)
3. 등록 정보 시트 — 스마트스토어 등록 화면과 똑같은 순서로 자동 생성, 위에서 아래로 복사해 붙여넣기만:
   ① 카테고리 — 후보 3개 자동 추천 (네이버쇼핑 상위 20개 분석)
   ② 상품명 — 추천 상품명 자동 조합 + 실시간 검사 (길이·특수문자·홍보문구·지재권 위험어) + 점수 등급
   ③ 판매가 — 추천 판매가 (MOQ 묶음 원가 역산·마진 표시·손익분기가), 할인율 표시용 정가 분해
   ④ 재고수량 — 도매꾹 재고를 묶음 단위로 환산
   ⑤ 옵션 — 옵션 조합 표 (가산가·재고, 엑셀 붙여넣기용 TSV 복사)
   ⑥ 상품이미지 — 대표 1장 + 추가 9장 구성. 상세이미지에서 잘라오기, 클릭 한 번으로
      편집(배경 제거·배경 교체·워터마크), 완성본 ZIP 다운로드
   ⑦ 상세설명 — 상세 이미지 미리보기 + HTML 복사 (스마트스토어 [HTML 작성]에 붙여넣기)
   ⑧ 주요정보 — 과세·원산지·제조사·상품정보제공고시 + KC 인증·인허가 배지 (전기·어린이·식품·화장품·의료)
   ⑨ 배송 — 배송비 자동 반영
   ⑩ 반품 — 반품·교환비 정리
   ⑪ 검색설정 — 태그 후보 10개 (상품명 중복 키워드 자동 제외·검색량 확인 뱃지·콤마 복사)
   ⑫ 판매자 코드 — 관리 코드 자동 제안, A/S 문구 저장

※ API 자동 등록은 준비 중.


[스텝 1 — 소싱] 뭘 팔지 정하고, 남는 장사인지 확인합니다

- 키워드 분석: 월간 검색수 ÷ 등록 상품 수로 틈새 키워드 판정. 종합차트 13종
  (12개월 트렌드·시즌성·기기·성별·연령·요일·시장 가격대·브랜드 장악도·실경쟁·블로그 문서수 등),
  연관 키워드 30개 확장, 키워드 비교(최대 4개), [도매꾹에서 찾기]로 소싱 연결
- 도매꾹 검색: 링크 없이 검색으로 소싱. 인기순·가격·낱개 구매 필터로 후보 발굴,
  상품 클릭 시 원링크로 바로 투입
- 마진 계산: 순이익 계산 + 목표 마진율을 넣으면 최소 판매가 역산

[스텝 2 — 등록 준비] 등록용 이미지를 가공 순서대로 완성합니다

- 누끼: 여러 상품 이미지의 배경을 한 번에 제거하고 원하는 배경(색·패턴·검색 이미지)으로 교체
- 규격 맞추기: 마켓별 대표이미지 규격(1000×1000 등)에 맞춰 일괄 변환, 상·하단 잘라내기 프리셋
- 규정 검사: 대표이미지가 마켓 규정(해상도·비율·용량)에 맞는지 즉시 검사, 규격 변환으로 연결
- 워터마크: 텍스트/로고 워터마크를 여러 이미지에 한 번에 합성 (도용 방지)
- 상세 분할: 긴 상세 이미지를 마켓 높이 제한에 맞춰 자동 분할, JPG 압축·번호 ZIP 저장
- 엑셀 대량 가공: 대량등록 엑셀 속 상품 이미지를 최대 100장 모아 배경 제거까지 한 번에

[스텝 4 — 운영·정산] 판매 후 광고 손익과 세금을 챙깁니다

- 광고 손익: 내 마진 기준 손익분기 ROAS와 광고 손익 시뮬레이션
- 부가세 계산: 간이/일반 과세 유형별 부가세 납부 예상액, 납부 면제 안내


# 컨텐츠 종류

구조: 3종 — A 문제해결중심(기능 축) · B 사용자 여정 중심(사람 축) · C 정보성 컨텐츠(정보 축).
생산 순서: 모든 컨텐츠는 블로그 → 쓰레드 → 유튜브 숏츠 순으로 재활용 — 1소재를 3채널 포맷으로 변주해 생산량을 극대화한다.

공통 금지 체크 (BRAND.md·SERVICE.md 기준):
- 검증 불가한 수치·성과 주장 금지 ("월 300 벌었다" 류)
- 페르소나 내부 설정 수치(32세·월 100만 등) 공개 카피 사용 금지
- 어뷰징(가구매·리뷰 조작 등) 관련 소재 영구 금지

## A. 문제해결중심 (축: 기능)

- 목적: 고려 단계 — "이 문제, 이 기능으로 끝"을 보여줘 사용 이유를 만든다

- 작성 플로우:
  1. 서비스 사용 플로우 정리 (기준 = 이 파일 상단 "서비스 기능")
     - 원링크 내부 플로우: 상품 입력(링크·검색) → 상품 확인(MOQ·라이선스) → 등록 시트 ①~⑫ 순서대로 복붙
     - 개별 기능 플로우: 소싱(키워드 분석 → 도매꾹 검색 → 마진 계산) / 이미지(누끼 → 규격 → 규정 검사 → 워터마크 → 상세 분할, 엑셀 대량 가공) / 운영(광고 손익 → 부가세)
  2. 단계별 장점 정리
     - 원링크·상품 입력: 링크 붙여넣기 하나로 시작, 링크 없어도 검색(인기순·가격·낱개 필터)으로 진입, 무료·무가입
     - 원링크·상품 확인: 이미지 사용 허용 여부 자동 확인(제재 리스크 예방), MOQ 묶음(1+1) 구성 자동 안내, 도매꾹가·배송비 한눈 요약
     - 원링크·등록 시트: 스마트스토어 등록 화면과 같은 순서 = 위에서 아래로 복붙만 / 카테고리 후보 자동(네이버쇼핑 상위 20개 분석) / 상품명 추천+실시간 검사(길이·홍보문구·지재권 위험어) / 판매가 역산(마진·손익분기 표시) / 옵션 표 TSV 복사 / 이미지 클릭 한 번 편집(누끼·배경 교체·워터마크) / 상세 HTML 복사 / KC 인증 지뢰 배지 / 태그 중복 키워드 자동 제외
     - 키워드 분석: 검색수÷상품수 틈새 판정, 차트 13종(트렌드·시즌성·연령·브랜드 장악도 등), 연관 키워드 30개 확장, 최대 4개 비교
     - 도매꾹 검색: 링크 없이 후보 발굴, 클릭 시 원링크 바로 투입
     - 마진 계산: 목표 마진율만 넣으면 최소 판매가 역산

## B. 사용자 여정 중심 (축: 사람)

- 목적: 인지 단계 — "당신 지금 이 단계죠?"로 공감 먼저, 서비스는 여정 안에서 자연 등장
- 타겟 여정: 부업 탐색~초기 진입. 아직 서비스 필요성을 모르는 사람 포함
- 작성 플로우:
  1. 여정을 단계별 문제로 분해:
     ① 불만 — 월급날이 지나도 통장 그대로, SNS·유튜브에서 부업 성공썰을 본다
        (문제: 쿠팡알바·배달·블로그·스토어… 뭐가 내 상황에 현실적인지 판별 안 됨)
     ② 해결방법 모색 — 검색하다 스마트스토어 위탁판매 발견, 무재고·소자본에 끌림
        (문제: 정보 과잉 — 성공썰과 강의·전자책 장사가 섞여 있어 뭐가 진짜인지 모름)
     ③ 시작 준비 — 사업자등록, 통신판매업 신고, 스토어 이름 짓기
        (문제: 절차 순서가 헷갈림, 사업자 없이 시작 가능한지부터 궁금)
     ④ 스토어 개설 — 개설 자체는 금방 끝났다. 텅 빈 스토어가 생겼다
        (문제: "이제 뭘 하지?" — 다음 행동이 안 보임)
     ⑤ 아이템 탐색 — 뭘 팔지 정해야 한다. 유행템? 경쟁 심한 건 피해야 하나?
        (문제: 검색량·경쟁도 보는 법을 모름, 감으로 고르게 됨)
     ⑥ 도매처 탐색 — 도매꾹 같은 도매 사이트를 밤마다 뒤진다
        (문제: 같은 상품 파는 셀러가 수두룩, 팔릴 상품 판별 기준이 없음,
        최소구매수량(MOQ)·이미지 사용 가능 여부 같은 함정을 모름)
     ⑦ 수익성 검증 — 도매가에 마켓 수수료·배송비를 얹어 계산해본다
        (문제: 수수료율을 모르고, 계산이 서툴러 팔수록 손해인 가격을 매기기도 함)
     ⑧ 상품등록 — 하위 여정으로 재분해: 카테고리 뭘로? → 상품명 어떻게? (금지어·글자수) →
        판매가·할인가 → 옵션 조합 입력 → 이미지 가공(누끼·규격·용량 제한) → 상세페이지 만들기 →
        주요정보(원산지·KC 인증 대상인지) → 배송·반품비 → 태그
        (문제: 항목마다 검색해서 배워야 하고, 이미지 가공이 시간을 제일 잡아먹음 —
        한 상품에 몇 시간, 이걸 상품 수만큼 반복)
     ⑨ 등록 후 — 올렸는데 주문이 없다. 검색해도 내 상품이 안 보인다
        (문제: 노출·광고를 모름, "등록 수를 늘려라"는 조언에 ⑤~⑧ 무한 반복 돌입 — 지치는 구간)
  2. 각 여정에 우리 기능이 해결하는 시점 표시:
     ①~④ = 콘텐츠가 커버 (공감·정보 제공, 제품 등장 전 신뢰 구간)
     ⑤ = 키워드 분석 (검색수÷상품수 틈새 판정·차트 13종 — 감이 아니라 데이터로)
     ⑥ = 도매꾹 검색 (인기순·낱개 필터로 후보 발굴) + 원링크 상품 확인 (MOQ·라이선스 함정 자동 안내)
     ⑦ = 마진 계산 (수수료 프리셋·목표 마진 역산) + 원링크 추천 판매가 (묶음 원가 자동 역산)
     ⑧ = 원링크 등록 시트 ①~⑫ (하위 여정 전부 — 카테고리·상품명·가격·옵션·이미지·상세·KC·태그)
     ⑨ = 반복 구간의 시간을 원링크가 단축 (등록 수 확장이 현실이 됨) — 노출·광고 자체는 비목표
  3. 설득 콘텐츠 작성 — 고정 구조:
     여정 문제 디테일 묘사(공감) → 그 시점에 기능 등장(해결 장면) → 차별점(무료·무가입·설치 없음)
     → CTA 1회 (auto-seller.co.kr)
  4. 페르소나별 재활용 — 같은 여정, 시간·맥락만 교체:
     직장인(퇴근 후 밤 시간이 전부) / 주부(집안일 사이 짬 시간) / 육아맘(아이 재운 뒤 새벽)
- 산출물: 여정 9단계 × 페르소나 3종 매트릭스 (최대 27편). 우선순위 = 직장인 부업러 행부터 (마케팅 조준점)
- 예시:
  - 제목: "부업 시작하고 알았다 — 적은 월급보다 무서운 건 반복작업이라는 걸"
  - 대본 (나레이션 컨셉, 페르소나 = 직장인):

    월급날이 지나도 통장이 그대로라서, 부업을 알아봤다.
    무재고로 시작할 수 있다길래 스마트스토어 위탁판매를 골랐다.
    스토어 개설까진 금방이었다. 문제는 그 다음부터.
    밤마다 도매 사이트를 뒤지는데, 이게 팔릴 상품인지 확신이 없다.
    겨우 상품을 정해도 등록이 남아 있다.
    배경 지우고, 규격 맞추고, 상품명 짓고, 카테고리 찾고, 옵션 넣고.
    한 개 올리는 데 저녁이 통째로 사라졌다.
    부업하려고 잠을 줄였는데, 사업이 아니라 야근을 하나 더 하는 기분이었다.
    그러다 도매꾹 링크만 넣으면 등록 정보가 통째로 나오는 툴을 찾았다.
    배경 지워진 이미지, 추천 판매가, 카테고리, 태그까지 —
    등록 화면 순서 그대로라서 위에서 아래로 붙여넣기만 하면 됐다.
    이제 밤 시간에 하는 일은 등록 노가다가 아니라, 뭘 팔지 고르는 일이다.
    (자막: 무료·무가입 — auto-seller.co.kr)

## C. 정보성 컨텐츠 (축: 정보)

- 목적: 정보를 찾는 사람에게 실질 정보를 주고, 그 안에서 서비스를 자연 노출
- 타겟 여정: "위탁판매 시작", "스마트스토어 상품등록 방법" 등 정보를 능동적으로 찾는 탐색자
- 작성 플로우:
  1. 주제 선정 (여정 단계별 수요: 부업 추천 / 위탁판매 방법 / 상품등록 순서 / 누끼 무료 …)
  2. 유형 선택:
     ① 오토셀러 소개 (기준 문서 = 이 파일 상단 서비스 소개·기능)
     ② 노하우·가이드 (수요에 답하는 실질 정보 + 해당 구간에서 오토셀러 자연 언급)
     ③ TOP5 리스트 (툴·방법 비교에 오토셀러 끼워넣기 + 차별점 강조: 무료·무가입·이미지 가공 깊이)
     ④ A·B 컨텐츠 재정리 (기존 컨텐츠를 정보형으로 재구성 — 보조 생산 경로)
  3. 수요(질문) → 목차 → 본문 순으로 작성, CTA는 끝 1회 (링크: auto-seller.co.kr)
- 산출물: 소개 1편 + 주제당 가이드/TOP5 1편 (주 단위 누적)
- 예시:
  - 제목: "스마트스토어 상품등록 12단계, 순서대로 따라하기 (무료 툴 포함)"
  - 구성: 등록 화면 실제 순서(카테고리→상품명→판매가→…→판매자 코드)를 그대로 목차로,
    각 단계에서 원링크가 자동으로 채워주는 부분을 표시
