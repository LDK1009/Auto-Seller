# 서비스 소개
한줄 소개 :도매꾹 링크 하나로 이미지 가공부터 등록 정보까지 초보 위탁 셀러의 상품 등록 반복작업을 없애는 툴
타겟 : 초보 위탁 셀러, 부업에 관심 있는 직장인•퇴작자•육아맘

# 서비스 기능
[원링크] — 플래그십
"링크 하나로 등록 정보까지" — 도매꾹 URL 하나 넣으면 스마트스토어 등록 직전까지 전부.

사용 흐름:
1. 상품 입력 — 도매꾹 링크·상품번호를 붙여넣거나, 검색(인기순·가격·낱개 필터)으로 상품 선택
2. 상품 확인 — 상품 요약(도매꾹가·최소구매수량·배송비), MOQ 2개 이상이면 묶음(1+1) 구성 판매 안내,
   공급사 이미지 사용 허용 여부 자동 확인 (미허용 상품 차단, 편집 허용 범위 고지)
3. 등록 정보 시트 — 스마트스토어 등록 화면과 똑같은 순서로 자동 생성, 위에서 아래로 복사해 붙여넣기만:
   ① 카테고리 — 후보 3개 자동 추천 (네이버쇼핑 상위 20개 분석)
   ② 상품명 — 추천 상품명 자동 조합 + 실시간 검사 (길이·특수문자·홍보문구·지재권 위험어) + 점수 등급
   ③ 판매가 — 추천 판매가 (MOQ 묶음 원가 역산·마진 표시·손익분기가), 할인율 표시용 정가 분해
   ④ 재고수량 — 도매꾹 재고를 묶음 단위로 환산
   ⑤ 옵션 — 옵션 조합 표 (가산가·재고, 엑셀 붙여넣기용 TSV 복사)
   ⑥ 상품이미지 — 대표 1장 + 추가 9장 구성. 상세이미지에서 잘라오기, 클릭 한 번으로
      편집(배경 제거·배경 교체·워터마크), 완성본 ZIP 다운로드
   ⑦ 상세설명 — 상세 이미지 미리보기 + HTML 복사 (스마트스토어 [HTML 작성]에 붙여넣기)
   ⑧ 주요정보 — 과세·원산지·제조사·상품정보제공고시 + KC 인증·인허가 배지 (전기·어린이·식품·화장품·의료)
   ⑨ 배송 — 배송비 자동 반영
   ⑩ 반품 — 반품·교환비 정리
   ⑪ 검색설정 — 태그 후보 10개 (상품명 중복 키워드 자동 제외·검색량 확인 뱃지·콤마 복사)
   ⑫ 판매자 코드 — 관리 코드 자동 제안, A/S 문구 저장

※ API 자동 등록은 준비 중.


[스텝 1 — 소싱] 뭘 팔지 정하고, 남는 장사인지 확인합니다

- 키워드 분석: 월간 검색수 ÷ 등록 상품 수로 틈새 키워드 판정. 종합차트 13종
  (12개월 트렌드·시즌성·기기·성별·연령·요일·시장 가격대·브랜드 장악도·실경쟁·블로그 문서수 등),
  연관 키워드 30개 확장, 키워드 비교(최대 4개), [도매꾹에서 찾기]로 소싱 연결
- 도매꾹 검색: 링크 없이 검색으로 소싱. 인기순·가격·낱개 구매 필터로 후보 발굴,
  상품 클릭 시 원링크로 바로 투입
- 마진 계산: 순이익 계산 + 목표 마진율을 넣으면 최소 판매가 역산

[스텝 2 — 등록 준비] 등록용 이미지를 가공 순서대로 완성합니다

- 누끼: 여러 상품 이미지의 배경을 한 번에 제거하고 원하는 배경(색·패턴·검색 이미지)으로 교체
- 규격 맞추기: 마켓별 대표이미지 규격(1000×1000 등)에 맞춰 일괄 변환, 상·하단 잘라내기 프리셋
- 규정 검사: 대표이미지가 마켓 규정(해상도·비율·용량)에 맞는지 즉시 검사, 규격 변환으로 연결
- 워터마크: 텍스트/로고 워터마크를 여러 이미지에 한 번에 합성 (도용 방지)
- 상세 분할: 긴 상세 이미지를 마켓 높이 제한에 맞춰 자동 분할, JPG 압축·번호 ZIP 저장
- 엑셀 대량 가공: 대량등록 엑셀 속 상품 이미지를 최대 100장 모아 배경 제거까지 한 번에

[스텝 4 — 운영·정산] 판매 후 광고 손익과 세금을 챙깁니다

- 광고 손익: 내 마진 기준 손익분기 ROAS와 광고 손익 시뮬레이션
- 부가세 계산: 간이/일반 과세 유형별 부가세 납부 예상액, 납부 면제 안내


# 컨텐츠 종류

구조: 3종 — A 문제해결중심(기능 축) · B 사용자 여정 중심(사람 축) · C 정보성 컨텐츠(정보 축).
생산 순서: 모든 컨텐츠는 블로그 → 쓰레드 → 유튜브 숏츠 순으로 재활용 — 1소재를 3채널 포맷으로 변주해 생산량을 극대화한다.

공통 금지 체크 (BRAND.md·SERVICE.md 기준):
- 검증 불가한 수치·성과 주장 금지 ("월 300 벌었다" 류)
- 페르소나 내부 설정 수치(32세·월 100만 등) 공개 카피 사용 금지
- 어뷰징(가구매·리뷰 조작 등) 관련 소재 영구 금지

---

## A. 문제해결중심 (축: 기능)

- 목적: 고려 단계 — "이 문제, 이 기능으로 끝"을 보여줘 사용 이유를 만든다
- 타겟 여정: 이미 부업/위탁판매를 시작했고 특정 작업에서 막힌 사람
- 작성 플로우:
  1. 서비스 사용 플로우 6단계로 기능 배치 (키워드 분석(틈새 판정) → 도매꾹 검색(상품찾기) → 원링크 투입(상품 정보 자동 추출·마진 역산) → 등록 시트 자동 생성(카테고리·상품명·판매가·옵션·태그) → 이미지 편집(누끼·워터마크·상세 HTML) → 스마트스토어 복붙 등록)
  2. 단계별 장점 N개 나열 (예: 상품찾기 — 인기순·낱개 필터, 상품 정보 자동 추출)
  3. 문제점 → 해결 구조로 대본화. 컨셉: 친구 요청으로 서비스 만들어주는 개발자 (통화 컨셉)
- 산출물: 플로우 단계당 1편, 총 6편 시리즈
- 예시:
  - 제목: "누끼 100장을 퇴근 후에 언제 다 따요? — 친구 전화 받고 만들어준 기능"
  - 훅 3줄: "야 나 상품 등록하는데 사진 배경 지우다 새벽 2시 됐어" /
    "보내봐. 링크만." / "…뭐야 이게, 배경 다 지워졌는데?"

## B. 사용자 여정 중심 (축: 사람)

- 목적: 인지 단계 — "당신 지금 이 단계죠?"로 공감 먼저, 서비스는 여정 안에서 자연 등장
- 타겟 여정: 부업 탐색~초기 진입. 아직 서비스 필요성을 모르는 사람 포함
- 작성 플로우:
  1. 여정을 단계별 문제로 분해:
     불만(월급 적다, 부업할까) → 해결방법 모색(부업 뭐 있지) → 시작(어떻게 시작하지)
     → 상품찾기(뭘 팔지) → 상품등록(등록은 하위 여정으로 재분해: 카테고리·상품명·가격·이미지·상세…)
  2. 각 여정에 우리 기능이 해결하는 시점 표시 (상품찾기·상품등록 구간 = 원링크 커버)
  3. 해당 여정의 문제점 + 우리가 해결하는 부분으로 설득 콘텐츠 작성
  4. 페르소나별 재활용: 같은 여정을 직장인·주부·육아맘 버전으로 변주
- 산출물: 여정 5단계 × 페르소나 3종 매트릭스 (최대 15편). 우선순위 = 직장인 부업러 행부터 (마케팅 조준점)
- 예시:
  - 제목: "월급 말고 +α 만들려고 시작한 부업이, 야근 하나 더 된 이야기"
  - 훅 3줄: "부업하려고 잠을 줄였는데" / "밤에 하는 일이 사업이 아니라 이미지 편집이었다" /
    "반복작업만 없애면 부업은 계속할 만하다"

## C. 정보성 컨텐츠 (축: 정보)

- 목적: 정보를 찾는 사람에게 실질 정보를 주고, 그 안에서 서비스를 자연 노출
- 타겟 여정: "위탁판매 시작", "스마트스토어 상품등록 방법" 등 정보를 능동적으로 찾는 탐색자
- 작성 플로우:
  1. 주제 선정 (여정 단계별 수요: 부업 추천 / 위탁판매 방법 / 상품등록 순서 / 누끼 무료 …)
  2. 유형 선택:
     ① 오토셀러 소개 (기준 문서 = 이 파일 상단 서비스 소개·기능)
     ② 노하우·가이드 (수요에 답하는 실질 정보 + 해당 구간에서 오토셀러 자연 언급)
     ③ TOP5 리스트 (툴·방법 비교에 오토셀러 끼워넣기 + 차별점 강조: 무료·무가입·이미지 가공 깊이)
     ④ A·B 컨텐츠 재정리 (기존 컨텐츠를 정보형으로 재구성 — 보조 생산 경로)
  3. 수요(질문) → 목차 → 본문 순으로 작성, CTA는 끝 1회 (링크: auto-seller.co.kr)
- 산출물: 소개 1편 + 주제당 가이드/TOP5 1편 (주 단위 누적)
- 예시:
  - 제목: "스마트스토어 상품등록 12단계, 순서대로 따라하기 (무료 툴 포함)"
  - 구성: 등록 화면 실제 순서(카테고리→상품명→판매가→…→판매자 코드)를 그대로 목차로,
    각 단계에서 원링크가 자동으로 채워주는 부분을 표시
