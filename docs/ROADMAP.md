## 스테이션별 백로그 (SERVICE.md 6장 맵 기준)

### [소싱] — 여정의 시작

- [x] P-0. 도매매/도매꾹 오픈API 검증 — 상품상세(getItemView) Open 키 즉시 사용 가능, 도매꾹·도매매 통합(v4.1+), `thumb.original`+상세 HTML 확보, multiple 최대 100개. Private(승인 2~3일)는 주문·등록 계열만
- [ ] P-1. 도매매 링크 파싱 → 파이프라인 투입 **(S0, L-6)** — ⚠️ L-2 조사 반영: 상세 API의 `desc.license.msg`(공급사 이미지 사용조건)를 이미지 수집 전에 그대로 노출하고 사용자 확인 게이트를 거칠 것. 판단 책임은 사용자·공급사 간(우리는 도구) — 단 "사용 금합니다" 류 문구 감지 시 경고 강화
- [ ] L-6b. 인기검색어 위젯 **(S0)** — 소싱 동선의 시작점, 보조 힌트 위계 유지
- [ ] P-2. 도매매 대량등록 엑셀 이미지 매칭 **(S1)** — 엑셀 → 이미지 URL 추출 → 일괄 가공 → ZIP. ⚠️ 기술 검토 선행: 대량 처리 시간 기대치, 통이미지 canvas 한계(크롬 한 변 ~32,767px)

## ★ 킬러 시나리오 (스테이션 통합 — S2~S3에서 조립)

> **"도매매 링크 → AI 등록 패키지 → 원클릭 등록"**

- 구성: P-1(수집) + ②a(이미지·텍스트 가공) + ②b(등록)
- vs 스피드고전송기(무료 복사·전송): **AI 제작 품질**로 승부
- vs 윈들리(월 3만~)·퍼센티(월 20만): **무료 진입 + 이미지 가공 깊이 + 무가입**
