## ★ 킬러 시나리오 = **원링크** (2026-07-07 골 확정·명명)

> **골: 도매꾹 URL 하나로 네이버 상품등록까지.** 기능명 "원링크" — 주 사용 동선으로 사이드바 최상단 고정, 개별 도구는 골라 쓰는 사람용.
> 현재 도달 범위: 링크 → 이미지 자동 가공(누끼 이어달리기)까지. 다음 확장: 등록 준비 패키지(추천 판매가·배송비·재고 시트) → S2 텍스트(상품명·태그) → ②b 원클릭 등록

- 구성: P-1(수집) + ②a(이미지·텍스트 가공) + ②b(등록)
- vs 스피드고전송기(무료 복사·전송): **AI 제작 품질**로 승부
- vs 윈들리(월 3만~)·퍼센티(월 20만): **무료 진입 + 이미지 가공 깊이 + 무가입**
