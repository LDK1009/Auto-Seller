## 1. 미션 · 비전 · 정의

### 미션

> **사용자가 단 한 건이라도, 우리 서비스를 통해 순이익을 남기게 한다.**

- 고객 성공의 최종 판정 기준. 모든 기능은 이 문장에 기여해야 한다.
- NSM(3장)은 이 미션의 운영 대리지표다.

### 장기 비전 — "위탁 셀러의 올인원 OS"

김진우 한 사람의 **전 여정**을 하나의 툴로:

```
소싱 실행 → 등록 준비 → 등록 → 운영(발주) → 마케팅 보조
```

- **전 단계 커버 ≠ 전 셀러 커버.**
  모든 셀러의 범용 OMS가 아니라, 한 페르소나의 풀사이클.
  이것이 1인 운영 제약(7장)과 비전을 양립시키는 프레임이다.

### 현 단계 정의

> **팔 것을 정한 셀러의 "그 다음 전부"를 자동화한다.**

- 아이템 **선정**(무엇을 팔지 판단) = 사용자·조사툴의 몫
- 소싱 **실행**(상품 데이터·이미지 가져오기)부터 = 우리 몫

### 워크플로 위치와 개발 순서

셀러 워크플로:

```
①아이템 조사 → ②a 등록 준비(이미지·텍스트) → ②b 등록 실행(계정 연동·전송)
→ ③마케팅 → ④주문/배송 → ⑤CS → ⑥정산
```

- **개발 순서 원칙: ②a 완성 → 그 후 ②b.** (Phase 1·2 = ②a, Phase 3 = ②b)
- **②는 교두보다.** 최종 정체성이 아니라 시장에 이기고 들어가는 자리. 확장은 게이트(8장) 순서로만.

### 소싱 미결정자 수용 원칙

초보의 첫 장벽은 소싱이다. (대표 직접 체험, n=1 — 출시 후 커뮤니티에서 검증)

> **결정을 대신하지 않되, 결정까지의 마찰은 줄인다.**

- 수용 수단 (미결정자가 이탈하지 않고 머물 이유):
  - 가이드 콘텐츠 (출시 후 시작)
  - 마진/역산 계산기 = 소싱 검증 도구 (구현 완료 / P-3 출시 범위)
  - 도매꾹 인기검색어 위젯 (출시 범위 L-6b 확정 — P-1 페이지 부속, 소싱 동선의 시작점)
- 위계 원칙: 소싱 해결의 본체는 P-1(링크→파이프라인). 인기검색어는 보조 힌트 — "소싱 정보 툴"로 포지션이 밀리면 안 됨
- 하지 않는 것: 상품 추천·큐레이션.
  이유: 모두에게 같은 상품을 추천 → 가격 경쟁 → 고객 순이익 파괴 = 미션 위배.

### 마케팅 가드레일

- 비전의 "마케팅 보조" = 셀러의 실행 보조 (정보 콘텐츠, 광고 세팅 보조, 체험단 정보 연결)
- **순위 조작·어뷰징·트래픽 편법은 영구 금지.** 계정 정지 = 고객 순이익 파괴 = 미션 위배.

## 2. 타겟 — 최소유효시장과 페르소나

### 최소유효시장

> **"국내 초보 1인 위탁 셀러"** — 가장 작은 시장을 깊게 만족시켜, 그들이 퍼뜨리게 한다. (고딘 원칙)

| 구분 | 내용 |
|------|------|
| 시장 정의 | 도매꾹·도매매 소싱, 진입 0~6개월 차 1인 위탁 셀러 |
| 상태 | 유료 솔루션(윈들리 3만~ / 퍼센티 20만) 결제 전, 무료 툴을 커뮤니티·유튜브·검색으로 탐색 |
| 핵심 pain | 등록 개수가 매출과 직결되는데, 업로드 전 **이미지 가공**(대량 누끼·규격·워터마크)에 시간을 다 뺏김 |
| 마케팅 조준점 | **직장인 부업러.** 부업 메시지는 전업에게도 통하지만 역은 약함. 채널도 부업·N잡 중심 |
| 시장 특성 | 회전문 시장 — 이탈 많지만 유입도 계속. 입구에서 대량 유입 → 생존자(사입 졸업자)를 붙잡는 게 LTV의 열쇠 |

### 페르소나 — "밤 10시의 김진우"

- 32세 직장인. **퇴근 후 밤 10시~새벽 1시가 부업 시간의 전부.**
- 도매매 소싱, 스마트스토어 4개월차. 목표는 **월 부수입 100만 원** (달성하면 전업 전환 고민).
- pain: 그 2~3시간이 전부 이미지 편집·등록 복붙에 사라진다.

> *"부업하려고 잠을 줄였는데, 사업이 아니라 야근을 하나 더 하는 기분이다."*

- 우리가 파는 변화: **반복 노동 → 기획·소싱에 쓰는 시간, 그리고 잠.**
- 졸업해도 남는다: 사입으로 전환한 셀러도 직접 촬영분의 이미지 작업엔 우리 도구를 계속 쓴다.

### 조준 원칙

- 마케팅은 부업러에게 말 건다. **제품 게이트는 좁히지 않는다.** (무료 툴이 전업자를 거부할 이유 없음)
- 좁히는 것은 카피의 조준점이지, 사용자 필터가 아니다.
- ⚠️ 페르소나 수치는 내부 설정 — 공개 카피에 사용 금지.

## 3. 문제 정의와 고객 경험

### ②단계의 pain 3개

1. **이미지 작업** — 누끼(장당 과금 툴뿐)·마켓 규격·워터마크·상세 분할을 낱장 수작업
2. **상품명·태그** — SEO 조합 + 글자수 제한 + 금지어 회피 노가다
3. **등록 입력** — 판매자센터 복붙 반복 × 상품 수십 개

### 고객 경험 여정

```
발견(커뮤니티 링크) → 30초 내 첫 처리(무가입) → [아하 모먼트] → [습관 모먼트] → 추천 → 결제(S2~)
```

CX 원칙 4가지:

| 원칙 | 내용 |
|------|------|
| 마찰 제로 | 가입·설치 없음 |
| 즉각 결과 | 수 분 내 결과물을 손에 쥔다 |
| 신뢰 | 내가 올린 이미지는 서버로 가지 않는다 |
| 흐름 | 도구 간 핸드오프 (파이프라인) |

### 아하 모먼트 (가설 — 배포 후 데이터로 보정)

- **아하: "첫 세션에서 이미지 10장+ 일괄 처리 → ZIP 다운로드"**
  "2시간 노가다가 5분이 됐다"는 체감. 1장 처리는 remove.bg급 경험이라 아하가 아니다.
- **최종 아하 (P-1 이후): "도매매 링크 붙여넣기 → 등록용 이미지 세트 다운로드"**
  소싱 루틴에 편입되는 순간 = 습관 모먼트.
- 보조 가설: 핸드오프 1회 경험(누끼→규격). 파이프라인은 경쟁사가 못 주는 경험.

### 노스스타 지표 (NSM)

> **주간 ZIP 다운로드 수** — 방문이 아니라 "가치가 반출된 횟수"

- S1 게이트(WAU·재방문)의 선행지표.
- 미션의 최종 판정("첫 순이익 1건")은 직접 측정이 어려움 → NSM이 운영 대리. S2 이후 인터뷰·후기로 정성 검증.

### ⚠️ 성립 리스크 (레지스터 연결)

- R-1: CPU 환경에서 10장 처리 시간이 아하를 깨뜨릴 수 있다 → 출시 전 실측 필수
- R-2: 애널리틱스 없으면 아하·NSM·게이트 전부 공염불

## 4. 가치 제안과 제품 원칙

### 3대 약속

> **무료 · 무가입 · 내 이미지는 브라우저에서**

- 사용자가 올린 이미지는 서버로 전송되지 않는다. 모든 가공은 브라우저에서.
- 진입 마찰 0 = 확산 전략의 핵심.

예외의 정확한 경계:

- 공개 상품 데이터 수집(도매매 파싱)과 외부 API 중계는 서버 프록시(`app/api`)를 거친다. (CORS·키 은닉)
- 사용자 본인 이미지가 아니므로 약속과 충돌하지 않는다.
- 문구는 항상 정확하게: **"내가 올린 이미지는 서버로 가지 않습니다."**

### 차별화 축

> **파이프라인이 유일한 차별화 축이다.**

- 소싱 → 누끼 → 규격 → 워터마크 → (상품명 → 상세 → 등록 → 발주)
- 개별 기능은 전부 경쟁자가 있다. 끝까지 잇는 툴은 없다.

### 아키텍처 원칙

- 클라이언트 처리 우선.
- 서버·AI·계정연동은 해당 단계가 요구할 때만 도입.

## 5. 경쟁 지형과 우리 좌표

### 지형 지도

```
①조사   아이템스카우트·판다랭크 (포화)        → 진출 금지, 데이터 embed만
②등록   [통합형]  ★윈들리(국내위탁, 3만~) · 퍼센티(해외, 20만) · 스토어봇
        [개별기능] 드랩아트(누끼) · 스토어부스터(상품명) · 스피드고전송기(무료 전송) · 매드스마트
④운영   플레이오토(15만)·사방넷 (범용 OMS)     → 진출 금지 (위탁 특화 발주만 S5 예외)
⑤CS     약한 영역                            → 문구 생성기로 수요 정찰만
⑥손익   셀러보드                             → 진출 금지, 계산기는 유입용만
```

### 경쟁사 순위 (타겟 × 기능 겹침)

1. **윈들리** — 두 축 모두 최고 겹침
2. **스피드고전송기** — 도매매 공식·무료. 우리 타겟의 기본값. P-1·P-2 기획 시 필수 비교 대상
3. **드랩아트** — 현 이미지 제품과 정면
4. 유플랫·쿠대·매드스마트·스토어봇
5. 퍼센티 — 기능 유사하나 타겟 어긋남 (해외 구매대행)

- S2 진입 시 스토어부스터·상세AI군이 순위 상승.

### 우리 좌표

> **윈들리(유료 완성형)와 스피드고(무료 전송기) 사이.**
> "무료인데 스피드고보다 품질, 윈들리보다 마찰 없음(무가입)"

차별화 3축:

1. **무료·무가입** — 윈들리 깔때기의 앞단 선점
2. **이미지 가공 깊이** — 수집→등록형 툴들의 공백
3. **브라우저 프라이버시** — 구조적 차별화

### 시장 신호

- 퍼센티·윈들리 성립 = ② 자동화의 지불의사 증명.
- 윈들리·퍼센티·플레이오토(셀핏AI)가 모두 ②로 수렴 중 = **선점 시급.**
- 교훈: "국내 위탁 소싱→등록은 빈자리"라는 초기 판단은 윈들리 발견으로 정정됨. 경쟁 조사는 상시 갱신.

## 6. 제품 체계 — 스테이션 맵

```
[소싱]    P-1 도매매 링크 파싱 · P-2 엑셀 대량 매칭      ← 도매매 피벗
[이미지]  누끼·규격·규정검사·워터마크·상세분할 ✅        ← 현재 무료 코어
[텍스트]  AI 상품명(+검색량 embed)·태그 검증·AI 상세     ← Phase 2 (첫 비용·과금 시작)
[등록]    이미지 업로드·원클릭 등록 (스마트스토어 단일)   ← Phase 3 (계정 연동)
[운영]    스스 주문 → 도매매 자동 발주                   ← S5
[마케팅]  정보 콘텐츠·광고 세팅 보조·체험단 정보 연결     ← S6 (비전 최종)
──────────────────────────────────────────
[유입]    계산기 허브: 마진✅ · 역산(P-3) · ROAS · 부가세 · 글자수
          → 포지셔닝 아님, 집객용 현관
```

★ **킬러 시나리오** = 소싱→등록 스테이션의 통합:
"도매매 링크 → AI 등록 패키지 → 원클릭 등록"

## 7. 사업 목표·제약과 수익화

### 목표와 제약 (모든 판단의 상위 필터)

| 항목 | 내용 |
|------|------|
| 운영 형태 | **1인 개발·운영 유지.** 직원 채용·대규모 확장 지향 안 함 |
| 판단 필터 | "1인 운영 상한(유지보수·CS)"이 매출 잠재력보다 **우선** |
| 목표 | **월 순이익 500만+** ≈ 월 매출 약 600만 (PG ~3.3% + 서버/AI 비용) |
| 타겟 근거 | 구매대행(B)은 ARPU 높지만 서버 자동화·연동 유지보수·CS가 1인 상한 초과 → A타겟 확정 |

### 가격 사다리 (초안 — S2 진입 시 확정)

| 티어 | 내용 | 가격(안) |
|------|------|---------|
| 무료 | 이미지 파이프라인 전체 — 한계비용 0, **평생 무료 유지** | 0원 |
| 라이트 | AI 상품명·태그 (무료 횟수 제한 해제) | 월 9,900~19,900원 |
| 프로 | 도매매 링크→등록 패키지 (스마트스토어 단일 = 1인 생존 설계) | 월 39,000원선 |
| (미결) | S5 발주 자동화의 티어 배치 | S5 설계 시 결정 |
| 목표점 | 프로 150명 ± 라이트 혼합 = 월 매출 600만 | — |

- **윈들리와 가격전 금지.** "이미지 품질 + 무가입 입구"라는 다른 가치축으로 싸운다.
- 사업자 제약: 개인사업자 → 커머스솔루션 마켓 입점 불가(법인만). 자체 PG 과금. 법인 전환·입점은 매출 후 선택지.

## 8. 단계별 확장 게이트 (S0~S6)

> **원칙: 게이트 통과 전엔 타겟·마켓·단계를 넓히지 않는다.**
> 기간은 참고치, 게이트가 기준. 수치는 첫 데이터로 1회 보정 허용.

## 12. 현재 상태와 넥스트 스텝

- **현 위치: S0 (출시 준비).** Phase 1 이미지 도구 5종 + 마진 계산기 구현 완료. 미배포, 사용자 0.
- **넥스트: 출시 체크리스트 L-1~L-9** ([ROADMAP.md](./ROADMAP.md)) — 타임박스 2~3주.
  - 최우선: L-1 누끼 성능 실측(R-1) · L-2 도매꾹 약관 확인(R-3)
  - 이후: L-3 디자인 → L-4 랜딩 → L-5 P-3 → L-6 P-1 → L-7 애널리틱스 → L-8 배포 → L-9 커뮤니티 첫 글
- **기획 동결:** 이 문서의 골격(미션·타겟·게이트·가격)은 S1 데이터 전까지 재론하지 않는다.
  남은 불확실성은 문서가 아니라 배포가 푼다.
