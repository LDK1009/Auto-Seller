## 1. 비전과 정의

**장기 비전: "위탁 셀러의 올인원 OS"**
소싱(도매매)부터 이미지·상품명·등록, 그리고 발주(운영)까지 — 김진우 한 사람의 **전 여정**을 하나의 툴로.

- 원칙: **"전 단계 커버 ≠ 전 셀러 커버"** — 모든 셀러의 범용 OMS가 아니라 한 페르소나의 풀사이클. 1인 운영 제약과 비전을 양립시키는 프레임
- **현 단계 정의:** 팔 것을 정한 온라인 셀러가 스토어에 상품을 올리기까지의 모든 노가다를 없애는 자동화 툴
- 셀러 워크플로: ①아이템 조사 → **②상품 등록 준비~등록** → ③마케팅 → ④주문/배송 → ⑤CS → ⑥정산
- **②는 최종 정체성이 아니라 교두보** — 시장에 이기고 들어가는 자리. 확장은 게이트(8장) 순서로만

## 2. 타겟 — 최소유효시장과 페르소나

**최소유효시장: "국내 초보 1인 위탁 셀러"** — 가장 작은 시장을 깊게 만족시켜 그들이 퍼뜨리게 한다 (고딘 원칙).

| 구분 | 내용 |
|------|------|
| 시장 정의 | **도매꾹·도매매 소싱, 진입 0~6개월 차 1인 위탁 셀러.** 유료 솔루션(윈들리 3만~/퍼센티 20만) 결제 전, 무료 툴을 커뮤니티·유튜브·검색으로 탐색하는 층 |
| 핵심 pain | 등록 개수가 매출과 직결되는데, 업로드 전 **이미지 가공(대량 누끼·규격·워터마크)** 에서 극심한 시간 낭비 |
| 마케팅 조준점 | **직장인 부업러** — 부업 메시지는 전업에게도 통하지만 역은 약함. 채널도 부업·N잡 중심 |
| 세그먼트 특성 | 회전문 시장(이탈 많고 유입 계속) — 입구에서 대량 유입, 생존자(사입 졸업자)를 붙잡는 게 LTV의 열쇠. 졸업자도 이미지 도구는 계속 씀(직접 촬영분) |

### 페르소나: "밤 10시의 김진우"

- 32세 직장인. **퇴근 후 밤 10시~새벽 1시가 부업 시간의 전부.** 도매매 소싱 스마트스토어 4개월차, 목표 **월 부수입 100만 원** (달성 시 전업 전환 고민)
- pain: 그 2~3시간이 전부 이미지 편집·등록 복붙에 사라짐 — *"부업하려고 잠을 줄였는데, 사업이 아니라 야근을 하나 더 하는 기분이다"*
- 우리가 파는 변화: **반복 노동 → 기획·소싱에 쓰는 시간, 그리고 잠(안도감)**
- 조준 원칙: 마케팅은 부업러에게 말 걸되, **제품 게이트는 좁히지 않는다** (좁히는 건 카피의 조준점이지 사용자 필터가 아님)
- ⚠️ 페르소나 수치는 내부 설정 — 공개 카피에 검증 안 된 수치 사용 금지

## 3. 문제 정의와 고객 경험

### ②단계의 pain 3개
1. **이미지 작업** — 누끼(장당 과금 툴뿐), 마켓 규격, 워터마크, 상세 분할을 포토샵/미리캔버스에서 낱장 수작업
2. **상품명·태그** — SEO 조합 + 글자수 제한 + 금지어/제한태그 회피 노가다
3. **등록 입력** — 판매자센터 복붙 반복 × 상품 수십 개

### 고객 경험 여정과 CX 원칙
```
발견(커뮤니티 링크) → 30초 내 첫 처리(무가입) → [아하 모먼트] → [습관 모먼트] → 추천 → 결제(S2~)
```
CX 원칙 4: **마찰 제로**(가입·설치 없음) / **즉각 결과** / **신뢰**(내 이미지 서버 미전송) / **흐름**(도구 간 핸드오프)

### 아하 모먼트 · NSM (가설 — 배포 후 데이터로 보정)
- **아하: "첫 세션에서 이미지 10장+ 일괄 처리 → ZIP 다운로드"** — "2시간이 5분이 됐다"는 체감. 1장 처리는 remove.bg급 경험이라 아하가 아님
- P-1 이후 진화형(최종 아하 = 습관 모먼트): **"도매매 링크 붙여넣기 → 등록용 이미지 세트 다운로드"** (소싱 루틴 편입)
- 습관 모먼트 보조 가설: 핸드오프 1회 경험(누끼→규격) — 파이프라인은 경쟁사가 못 주는 경험
- **NSM: 주간 ZIP 다운로드 수** — 방문이 아니라 "가치가 반출된 횟수". S1 게이트의 선행지표
- ⚠️ **성립 리스크 2개** (리스크 레지스터 R-1·R-2 참조): CPU 폴백 환경에서 10장 처리 시간이 아하를 깨뜨릴 수 있음(출시 전 실측 필수) / 측정 장치(애널리틱스) 없으면 전부 공염불

## 4. 가치 제안과 제품 원칙

- **3대 약속: 무료 · 무가입 · 내 이미지는 브라우저에서** — 사용자가 올린 이미지는 서버로 전송되지 않고 모든 가공은 브라우저에서. 진입 마찰 0이 확산 전략의 핵심
  - 단, 공개 상품 데이터 수집(도매매 파싱)과 외부 API 중계는 서버 프록시(`app/api`) 경유 — CORS·키 은닉 때문이며, 사용자 본인 이미지가 아니므로 약속과 충돌하지 않음. 문구는 "**내가 올린** 이미지는 서버로 가지 않습니다"로 정확히
- **파이프라인이 유일한 차별화 축** — 소싱→누끼→규격→워터마크→(상품명→상세→등록→발주). 개별 기능은 전부 경쟁자가 있지만 끝까지 잇는 툴은 전무
- 아키텍처 원칙: 클라이언트 처리 우선. 서버·AI·계정연동은 해당 단계가 요구할 때만 도입

## 5. 경쟁 지형과 우리 좌표

```
①조사   아이템스카우트·판다랭크 (포화)      → 진출 금지, 데이터 embed만
②등록   [통합형] ★윈들리(국내위탁, 3만~)·퍼센티(해외, 20만)·스토어봇
        [개별기능] 드랩아트(누끼)·스토어부스터(상품명)·스피드고전송기(무료 전송)·매드스마트
④운영   플레이오토(15만)·사방넷 (범용 OMS)   → 진출 금지 (위탁 특화 발주는 S5 예외)
⑤CS     약한 영역                          → 문구 생성기로 수요 정찰만
⑥손익   셀러보드                           → 진출 금지, 계산기는 유입용만
```

- **경쟁사 순위 (타겟×기능 겹침):** ①윈들리 ②스피드고전송기(도매매 공식·무료 — 우리 타겟의 기본값, P-1·P-2 기획 시 필수 비교) ③드랩아트(현 제품과 정면) ④유플랫·쿠대·매드스마트·스토어봇 ⑤퍼센티(기능 유사·타겟 어긋남). S2 진입 시 스토어부스터·상세AI군 상승
- **우리 좌표: 윈들리와 스피드고 사이** — "무료인데 스피드고보다 품질, 윈들리보다 마찰 없음(무가입)"
- 차별화 3축: ⓐ 무료·무가입 (윈들리 깔때기의 앞단 선점) ⓑ 이미지 가공 깊이 (수집→등록형 툴들의 공백) ⓒ 브라우저 프라이버시
- 시장 신호: 퍼센티·윈들리 성립 = ② 자동화의 지불의사 증명 / 윈들리·퍼센티·플레이오토(셀핏AI)가 모두 ②로 수렴 중 = 선점 시급성
- 교훈 기록: "국내 위탁 소싱→등록은 빈자리" 초기 판단은 윈들리 발견으로 정정됨 (경쟁 조사는 상시 갱신)

## 6. 제품 체계 — 올인원 OS의 스테이션 맵

```
[소싱]      P-1 도매매 링크 파싱 · P-2 엑셀 대량 매칭     ← 도매매 피벗
[이미지]    누끼·규격·규정검사·워터마크·상세분할 ✅ 완료   ← 현재 무료 코어
[텍스트]    AI 상품명(+검색량 embed)·태그/제한태그·AI 상세  ← Phase 2 (첫 비용·과금 시작)
[등록]      이미지 업로드·원클릭 등록 (스마트스토어 단일)   ← Phase 3 (계정 연동)
[운영]      스스 주문 → 도매매 자동 발주                  ← S5 (올인원 OS 완성)
─────────────────────────────────────────────
[유입 장치] 계산기 허브: 마진✅·역산(P-3)·ROAS·부가세·글자수 — 포지셔닝 아님, 집객용 현관
```
★ 킬러 시나리오 = 소싱→등록 스테이션의 통합: "도매매 링크 → AI 등록 패키지 → 원클릭 등록"

## 7. 사업 목표·제약과 수익화

### 목표·제약 (모든 판단의 상위 필터)
- **1인 개발·운영 유지** — 기능·확장 판단 시 "1인 운영 상한(유지보수·CS)"이 매출 잠재력보다 우선
- **목표: 월 순이익 500만+** ≈ 월 매출 약 600만 (PG ~3.3% + 서버/AI 비용)
- 이 제약이 A타겟 확정의 근거: 구매대행(B)은 ARPU 높지만 서버 자동화·연동 유지보수·CS가 1인 상한 초과

### 가격 사다리 (초안 — S2 진입 시 확정)
| 티어 | 내용 | 가격(안) |
|------|------|---------|
| 무료 | 이미지 파이프라인 전체 (한계비용 0 — 평생 무료 유지) | 0원 |
| 라이트 | AI 상품명·태그 (무료 횟수 제한 해제) | 월 9,900~19,900원 |
| 프로 | 도매매 링크→등록 패키지 (스마트스토어 단일 = 1인 생존 설계) | 월 39,000원선 |
| (미결) | S5 발주 자동화의 티어 배치 — 프로 포함 vs 상위 티어 | S5 설계 시 결정 |
| 목표점 | 프로 150명 ± 라이트 혼합 = 월 매출 600만 | — |
- 원칙: 윈들리와 **가격전 금지** — "이미지 품질 + 무가입 입구"라는 다른 가치축
- 사업자: 개인사업자 → 커머스솔루션 마켓 입점 불가(법인만). 자체 PG 과금, 법인 전환·입점은 매출 후 선택지

## 8. 단계별 확장 게이트 (S0~S5)

**원칙: 게이트 통과 전엔 타겟·마켓·단계를 넓히지 않는다. 기간은 참고치, 게이트가 기준. 수치는 첫 데이터로 1회 보정 허용.**

| 단계 | 타겟 | 마켓 | 제품 범위 | 진입 게이트 | 참고 기간 |
|------|------|------|----------|------------|----------|
| **S0. 출시 준비 ← 현재** | 위탁 초보(0~6개월) | 스마트스토어 | Phase 1 ✅ + 디자인/랜딩 + P-3 + **P-1** (출시 체크리스트 L-1~L-9, 타임박스 2~3주) | 배포 + 커뮤니티 첫 공유 | ~1개월 |
| S1. 무료 검증 | 동일 (좁게 유지) | 동일 | + P-2(엑셀 대량) 등 무료 심화 | **WAU 500 × 4주 + 주간 재방문 25%+** (NSM: 주간 ZIP 추이 보조) | 3~6개월 |
| S2. 수익화 | + 사입 졸업자 잔류 | 동일 | + Phase 2 AI(라이트) + 프로(도매매→등록) · **선행: AGPL 정리(R-4)** | **유료 100명 or MRR 200만** | 6~12개월차 |
| S3. 마켓 확장 | + 위탁 중급 | **+ 쿠팡** (프리셋 먼저) | 쿠팡 대응 | **MRR 400만 + 쿠팡 요청 반복** | 12~24개월차 |
| S4. 선택 확장 | (선택) 구매대행 or 사입 심화 | (선택) | 이미지 번역 or 촬영보정·AI모델컷 | **MRR 600만 달성 후** 신호 기반 | 24개월~ |

- **후퇴 게이트:** S1에서 6개월간 WAU 100 미달 → "무료 앞단 유입" 가설 재검토 (타겟 재논의 트리거)
- S4 판단 신호(사전 정의): 이미지 번역 요청 최다 / 구매대행 유입 급증 / 국내 앞단 유입 실패

## 9. 성장 채널 (고딘 원칙 적용 — BRAND.md 8장)

- **커뮤니티 (부업·N잡 중심)** — 부업 카페·아프니까 사장이다·셀러오션. 허락 마케팅: 결핍 공감·정보(마켓 규격표 등) 선제공 후 자연 노출, 도배 금지. 무가입이라 "그냥 써봐" 링크에 최적

## 12. 현재 상태와 넥스트 스텝

- **현 위치: S0 (출시 준비)** — Phase 1 이미지 도구 5종 + 마진 계산기 구현 완료, 미배포·사용자 0
- **넥스트 스텝: 출시 체크리스트 L-1~L-9** ([ROADMAP.md](./ROADMAP.md)) — 타임박스 2~3주
  - 최우선: L-1 누끼 성능 실측(R-1 판정) · L-2 도매꾹 약관 확인(R-3 해소)
  - 병행: L-3 디자인 컨셉(독자 노선) → L-4 랜딩(슬로건 3행+부업 서브카피) → L-5 P-3 → L-6 P-1 → L-7 애널리틱스 → L-8 배포 → L-9 커뮤니티 첫 글
- **기획 동결 (2026-07-06):** 이 문서의 골격(비전·타겟·게이트·가격)은 S1 데이터 전까지 재론하지 않는다. 남은 불확실성은 문서가 아니라 배포가 푼다
