# Auto-Seller 서비스 기획서

> 최종 수정: 2026-07-04 · 이 문서가 모든 기능·UI·우선순위 판단의 기준이다. (기능 상세·진행 상태는 [ROADMAP.md](./ROADMAP.md))

## 1. 정의와 비전

**한 줄 정의(현 단계):** 팔 것을 정한 온라인 셀러가, 스토어에 상품을 올리기까지의 모든 노가다를 없애는 자동화 툴 플랫폼.

**장기 비전 (2026-07-06 확정): "위탁 셀러의 올인원 OS"** — 소싱(도매매)부터 이미지·상품명·등록, 그리고 발주(운영)까지, 김진우 한 사람의 **전 여정**을 하나의 툴로.
- 원칙: **"전 단계 커버 ≠ 전 셀러 커버"** — 모든 셀러의 범용 OMS가 아니라, 한 페르소나의 풀사이클. 이것이 1인 운영 제약과 비전을 양립시키는 프레임
- 셀러 워크플로: ①아이템 조사 → **②상품 등록 준비~등록** → ③마케팅 → ④주문/배송 → ⑤CS → ⑥정산
- **②는 최종 정체성이 아니라 교두보** — 시장에 이기고 들어가는 자리이며, 확장은 게이트(7-1장) 순서로만

## 2. 타겟 고객 — 최소유효시장 (2026-07-06 확정)

**"국내 초보 1인 위탁 셀러"** — 가장 작은 시장을 깊게 만족시켜 그들이 퍼뜨리게 한다 (세스 고딘 원칙, [BRAND.md](./BRAND.md) 8장).

| 구분 | 내용 |
|------|------|
| 최소유효시장 | **도매꾹·도매매 소싱, 시장 진입 0~6개월 차 1인 위탁 셀러.** 퍼센티 등 월 수십만 원 유료 솔루션 결제 전, 무료 툴을 커뮤니티·유튜브·검색으로 탐색하는 층 |
| 핵심 pain | 등록 개수가 매출과 직결되는데, 소싱 후 마켓 업로드 전 **이미지 가공(대량 누끼·마켓별 규격·워터마크)** 에서 극심한 시간 낭비와 피로 |
| 2차(확장) | 쿠팡 셀러 — ②단계 작업은 마켓마다 반복되므로 프리셋 추가로 같은 제품 재사용 |

### 페르소나: "밤 10시의 김진우" (2026-07-06 부업 조준으로 개정)

- 32세 직장인. **퇴근 후 밤 10시~새벽 1시가 부업 시간의 전부.** 도매매 소싱 스마트스토어 4개월차, 목표는 **월 부수입 100만 원** (달성하면 전업 전환을 고민해보려 함)
- pain: 그 2~3시간이 전부 이미지 편집·등록 복붙에 사라짐 — *"부업하려고 잠을 줄였는데, 사업이 아니라 야근을 하나 더 하는 기분이다"*
- 우리가 파는 변화: **반복 노동 → 기획·소싱에 쓰는 시간, 그리고 잠(안도감)**
- **조준 원칙:** 마케팅은 부업러에게 말 건다(채널: 부업·N잡 카페/유튜브 중심, 부업 메시지는 전업에게도 통하지만 역은 약함). **제품 게이트는 좁히지 않는다**(무료 툴이 전업자를 거부할 이유 없음) — 좁히는 건 카피의 조준점이지 사용자 필터가 아님
- ⚠️ 페르소나 서사의 시간·수치는 내부 설정 — 공개 카피에 검증 안 된 수치 사용 금지 (BRAND.md 금지 목록)

## 3. 문제 정의 (②단계의 pain)

1. **이미지 작업** — 누끼(remove.bg 장당 과금), 마켓별 규격 맞추기, 워터마크, 상세페이지 자르기를 포토샵/미리캔버스에서 한 장씩 수작업
2. **상품명·태그** — SEO 키워드 조합 + 글자수 제한 + 금지어/제한태그 회피가 노가다
3. **등록 입력** — 판매자센터에 복붙 반복, 위탁 셀러는 상품 수십 개 × 반복

## 3-1. 고객 경험과 아하 모먼트 (2026-07-06)

**고객 경험 여정:**
```
발견(커뮤니티 링크) → 30초 내 첫 처리 시작(무가입) → [아하 모먼트] → [습관 모먼트] → 추천 → 결제(Phase 2~)
```
CX 원칙 4: **마찰 제로**(가입·설치 없음) / **즉각 결과**(수 분 내 결과물) / **신뢰**(내 이미지 서버 미전송) / **흐름**(도구 간 핸드오프)

**아하 모먼트 (가설 — 배포 후 데이터로 보정):**
- 현재: **"첫 세션에서 이미지 10장+ 일괄 처리 → ZIP 다운로드"** — "2시간 노가다가 5분이 됐다"는 체감. (1장 처리는 remove.bg급 경험이라 아하가 아님 — "대량 일괄"이 최소 체감 단위)
- P-1 이후 진화형: **"도매매 링크 붙여넣기 → 등록용 이미지 세트 다운로드"** = 최종 아하이자 습관 모먼트(소싱 루틴 편입)
- 습관 모먼트 가설: 핸드오프 1회 경험(누끼→규격) — 파이프라인은 경쟁사가 못 주는 경험

**노스스타 지표(NSM): 주간 ZIP 다운로드 수** — "가치가 실제 전달된 횟수". 방문이 아니라 결과물 반출 기준. S1 게이트(WAU·재방문)의 선행지표.

⚠️ 측정 장치 필수: 배포 시 애널리틱스(개인정보 최소형) 동시 탑재 — 없으면 아하·NSM·게이트 전부 공염불.

## 4. 가치 제안 & 원칙

- **무료 · 무가입 · 내 이미지는 브라우저에서** — 사용자가 올린 이미지는 서버로 전송되지 않으며, 모든 이미지 가공(누끼·변환·합성)은 브라우저에서 처리한다. 진입 마찰 0이 확산 전략의 핵심
  - (2026-07-06 재정의) 단, **공개 상품 데이터 수집**(도매매 상품 이미지 파싱 등)과 외부 API 중계는 CORS·키 은닉 때문에 서버 프록시(`app/api`)를 거친다 — 사용자 본인 이미지가 아니므로 프라이버시 약속과 충돌하지 않음. 마케팅 문구도 "내가 올린 이미지는 서버로 가지 않습니다"로 정확히 표현할 것
- **파이프라인** — 소싱(도매매 링크)→누끼→규격→워터마크→(상품명→상세→등록)을 한 흐름으로. 개별 기능은 전부 경쟁자가 있지만 **끝까지 이어주는 툴은 전무** → 유일한 차별화 축
- 아키텍처 원칙: 클라이언트 처리 우선, 서버·AI·계정연동은 Phase가 요구할 때만 단계적 도입

## 5. 포지셔닝 & 경쟁 지형

```
①조사   아이템스카우트·판다랭크 (포화)          → 진출 금지, 데이터 embed만
②등록   [소싱→등록 통합] ★윈들리(국내위탁 지원, 월 3만~)·퍼센티(해외, 월 20만)·스토어봇
                                                → 최대 경쟁축. 무료·무가입 + 이미지 품질로 차별화
        [개별 기능] 드랩아트(누끼)·스토어부스터(상품명)·스피드고전송기(전송, 무료)·매드스마트
                                                → 기능 싸움 회피, 파이프라인으로 승부
④운영   플레이오토(월 15만)·사방넷 (OMS)         → 진출 금지. ⚠️단 플레이오토가 셀핏AI(상세페이지)로 ② 역침투 시작 — 주시
⑤CS     (약한 영역)                              → F-2 문구 생성기로 수요 정찰만
⑥손익   셀러보드                                 → 진출 금지, 계산기는 유입용만
```

- **경쟁사 순위 (타겟×기능 겹침 순, 2026-07-06):** ①윈들리(두 축 모두 최고) ②스피드고전송기(도매매 공식·무료 — 우리 타겟의 기본값, P-1·P-2 기획 시 필수 비교) ③드랩아트(현 이미지 제품과 정면) ④유플랫·쿠대·매드스마트·스토어봇 ⑤퍼센티(기능 유사하나 타겟 어긋남) — Phase 2 진입 시 스토어부스터·상세AI군 상승
- **우리 좌표: 윈들리(유료 완성형)와 스피드고(무료 전송기) 사이** — "무료인데 스피드고보다 품질, 윈들리보다 마찰 없음(무가입)"
- "국내 위탁 소싱→등록은 빈자리"라는 초기 판단은 틀렸음 (윈들리 발견으로 정정)
- 그래도 유효한 차별화: ⓐ **무료·무가입**(윈들리는 가입+구독 필수 — 우리 최소유효시장은 그 앞단) ⓑ **이미지 가공 깊이**(누끼·배경·규격·워터마크 — 수집→등록형 툴들의 공백) ⓒ 브라우저 처리 프라이버시
- 퍼센티(월 20만)·윈들리(월 3만) 성립이 **② 자동화의 지불의사를 증명** — 수익화 시 가격 벤치마크
- 확장 원칙: **② 안에서 셀러가 다른 툴을 열 필요가 없어질 때까지** 딥다이브. 그 전에 타 단계 진출 금지 (예외: 유입용 계산기 허브, CS 정찰용 문구 생성기)

## 6. 제품 체계

### 코어 파이프라인 (Phase 순)
1. **Phase 1 — 이미지 스테이션** ✅ 완료: 누끼(배경 교체 포함) · 규격 변환 · 규정 검사 · 워터마크 · 상세 분할 + 도구 간 핸드오프
2. **Phase 2 — 텍스트 스테이션** (서버·AI 진입 = 첫 비용, 멤버십 시작점): AI 상품명(+검색량·경쟁강도 embed) · 태그 추천/제한태그 검증 · AI 상세페이지
3. **Phase 3 — 등록 스테이션** (판매자 계정 연동): 이미지 업로드 API · 원클릭 상품 등록
4. **★ 킬러 시나리오**: 도매꾹/도매매 링크 → AI 등록 패키지 → 원클릭 등록 (Phase 1~3 통합)

### 유입 장치 (포지셔닝 아님 — 집객용 현관)
- 계산기 허브: 마진 계산기 ✅ · ROAS · 부가세 · 글자수/금지어 체크 — 순수 클라이언트, 단독 URL, 검색 유입

## 7. 사업 목표·제약 & 수익화 (2026-07-06 확정)

### 사업 목표와 제약 (모든 판단의 상위 필터)
- **1인 개발·운영 유지** — 직원 채용, 대규모 확장 지향하지 않음. 기능·확장 판단 시 "1인 운영 상한(유지보수·CS 부담)"이 매출 잠재력보다 우선하는 필터
- **목표: 월 순이익 500만원 이상** ≈ 월 매출 약 600만 (PG ~3.3% + 서버/AI 비용 감안)
- 이 제약이 A타겟(국내 위탁) 확정의 근거: B(구매대행)는 ARPU는 높지만 서버 자동화·마켓 연동 유지보수·고강도 CS가 1인 상한 초과
