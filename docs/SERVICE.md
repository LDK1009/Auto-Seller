# Auto-Seller 서비스 기획서

> 최종 수정: 2026-07-04 · 이 문서가 모든 기능·UI·우선순위 판단의 기준이다. (기능 상세·진행 상태는 [ROADMAP.md](../ROADMAP.md))

## 1. 한 줄 정의

**팔 것을 정한 온라인 셀러가, 스토어에 상품을 올리기까지의 모든 노가다를 없애는 자동화 툴 플랫폼.**

- 셀러 워크플로: ①아이템 조사 → **②상품 등록 준비~등록** → ③마케팅 → ④주문/배송 → ⑤CS → ⑥정산
- 우리는 **②만** 판다. 시작점 = 아이템 확정 직후, 끝점 = 등록 완료.

## 2. 타겟 고객

| 구분 | 내용 |
|------|------|
| 1차 | **네이버 스마트스토어의 초보·1인·위탁 셀러** — 포토샵을 못 다루고, 월 수만~수십만 원 유료툴 진입 전 단계. 무료 툴을 커뮤니티·유튜브·검색으로 찾는 층 |
| 핵심 세부층 | 위탁/사입 셀러 (도매꾹·도매매 소싱, 수십~수백 개 대량 등록 니즈) |
| 2차(확장) | 쿠팡 셀러 — ②단계 작업은 마켓마다 반복되므로 "쿠팡 프리셋 추가"로 같은 제품 재사용 |

## 3. 문제 정의 (②단계의 pain)

1. **이미지 작업** — 누끼(remove.bg 장당 과금), 마켓별 규격 맞추기, 워터마크, 상세페이지 자르기를 포토샵/미리캔버스에서 한 장씩 수작업
2. **상품명·태그** — SEO 키워드 조합 + 글자수 제한 + 금지어/제한태그 회피가 노가다
3. **등록 입력** — 판매자센터에 복붙 반복, 위탁 셀러는 상품 수십 개 × 반복

## 4. 가치 제안 & 원칙

- **무료 · 무가입 · 브라우저 처리** (이미지가 서버로 전송되지 않음 = 비용 0 + 프라이버시) — 진입 마찰 0이 확산 전략의 핵심
- **파이프라인** — 누끼→규격→워터마크→(상품명→상세→등록)을 한 흐름으로. 개별 기능은 전부 경쟁자가 있지만 **끝까지 이어주는 툴은 전무** → 유일한 차별화 축
- 아키텍처 원칙: 클라이언트 처리 우선, 서버·AI·계정연동은 Phase가 요구할 때만 단계적 도입

## 5. 포지셔닝 & 경쟁 지형

```
①조사   아이템스카우트·판다랭크 (포화)          → 진출 금지, 데이터 embed만
②등록   [해외구매대행] 퍼센티 (월 20만)          → 우리 자리: 국내 소싱+자기상품+초보, 무료 진입
        [개별 기능] 드랩아트(누끼)·스토어부스터(상품명)·스피드고전송기(전송, 무료)
                                                → 기능 싸움 회피, 파이프라인으로 승부
④운영   플레이오토·사방넷 (고가 OMS)             → 진출 금지
⑤CS     (약한 영역)                              → F-2 문구 생성기로 수요 정찰만
⑥손익   셀러보드                                 → 진출 금지, 계산기는 유입용만
```

- 퍼센티(월 20만 성립)가 **② 자동화의 지불의사를 증명** — 수익화 천장 높음
- 확장 원칙: **② 안에서 셀러가 다른 툴을 열 필요가 없어질 때까지** 딥다이브. 그 전에 타 단계 진출 금지 (예외: 유입용 계산기 허브, CS 정찰용 문구 생성기)

## 6. 제품 체계

### 코어 파이프라인 (Phase 순)
1. **Phase 1 — 이미지 스테이션** ✅ 완료: 누끼(배경 교체 포함) · 규격 변환 · 규정 검사 · 워터마크 · 상세 분할 + 도구 간 핸드오프
2. **Phase 2 — 텍스트 스테이션** (서버·AI 진입 = 첫 비용, 멤버십 시작점): AI 상품명(+검색량·경쟁강도 embed) · 태그 추천/제한태그 검증 · AI 상세페이지
3. **Phase 3 — 등록 스테이션** (판매자 계정 연동): 이미지 업로드 API · 원클릭 상품 등록
4. **★ 킬러 시나리오**: 도매꾹/도매매 링크 → AI 등록 패키지 → 원클릭 등록 (Phase 1~3 통합)

### 유입 장치 (포지셔닝 아님 — 집객용 현관)
- 계산기 허브: 마진 계산기 ✅ · ROAS · 부가세 · 글자수/금지어 체크 — 순수 클라이언트, 단독 URL, 검색 유입

## 7. 수익화 방향 (단계적)

1. 지금: 완전 무료로 사용자·커뮤니티 확산 (아이템스카우트 초기 전략과 동일)
2. Phase 2부터: AI 기능 무료 횟수 제한 + 멤버십 (LLM 비용 발생 시점 = 과금 시작점)
3. Phase 3~킬러: 대량 처리·자동 등록이 유료 코어 (퍼센티 월 20만의 하위 가격대로 진입)
4. 사업자 제약: 개인사업자 → 커머스솔루션 마켓 입점 불가(법인만). 자체 PG로 과금, 매출 후 법인 전환·입점은 후속 선택지

## 8. 성장 채널

- 셀러 커뮤니티(아프니까 사장이다·셀러오션 등) 공유 — 무가입이라 "그냥 써봐" 링크에 최적
- 검색 유입 — 계산기·검사기가 단독 검색어("스마트스토어 수수료 계산기" 등)의 입구
- 도구 사용 → 파이프라인으로 자연 이동(핸드오프 버튼) → 재방문·즐겨찾기

## 9. 하지 않는 것 (명시적 비목표)

- 독립 키워드 분석·순위 추적·매출 추정 (①, 누적 데이터 싸움 → 아이템스카우트 영역)
- 주문/재고 통합 관리 (④, OMS 영역) / 손익 대시보드 (⑥, 셀러보드 영역)
- 크롤링 기반 기능 (약관·인프라 리스크)
- ② 완성 전 마켓 확장·CS 본격 진출
