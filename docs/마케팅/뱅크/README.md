# 콘텐츠 뱅크 — 자동 발행 소스

> 쓰레드 원고를 **frontmatter md**로 쌓는다. 사람이 검수(git)하고, 발행 스크립트가 파싱해 Threads에 자동 발행한다.

## 파일 = 글 1개

각 글은 `뱅크/{pain}-{format}-{seq}.md` 한 파일. frontmatter + 본문.

```markdown
---
format: 꿀팁          # 댓글유도 | 꿀팁 | 감정 | Q&A
pain: 세부키워드       # 소재은행 pain
media: 영상/데모/nukki-basic.mp4   # 첨부 영상(실물만) · 없으면 생략
reply_keyword: 누끼    # 댓글유도 포맷만
scheduled:            # 예약 시각 (비우면 미배정)
status: 대기          # 대기 | 승인 | 발행됨
---
(본문 — 부드럽고 정중한 톤. MARKETING.md 톤앤매너 준수)
```

## 발행 흐름 (자동)

```
뱅크/*.md → 스크립트 파싱 → status:승인 & scheduled 도래분
→ Threads API 발행 → status:발행됨 갱신 → replies 수집 → 리드 저장
```

## 상태 규칙

- **대기** — 초안. 대표 검수 전
- **승인** — 대표가 검수·확정. 발행 큐 대상
- **발행됨** — 크론이 발행 완료 (수정 금지)
