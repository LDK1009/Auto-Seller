# 성과 리포트

GA4는 Claude가 analytics-mcp로 직접 조회한다 (속성 544305521). 대표는 트리거 한마디만.

| 주기 | 트리거 | 산출물 | 성격 |
|------|--------|--------|------|
| 매주 일요일 | `/주간리포트` | `{YYYY-MM}-{N}주차.md` | 관찰·기록 (판단 금지) |
| 매월 마지막 일요일 | `/월간리포트` | `{YYYY-MM}-월간.md` | 판단·컨셉 유지/재정의·차월 계획 |

## GA 밖 지표 (월간에만 대표가 제공)
유튜브(조회·시청지속률·구독) · 쓰레드(조회·팔로워·프로필클릭) · 네이버/티스토리(조회·검색어) + 소감 한 줄.
없으면 "미제공"으로 표기하고 진행.
