# 서비스 소개

- **한줄 소개:** 도매꾹 링크 하나로 이미지 가공부터 등록 정보까지 초보 위탁 셀러의 상품 등록 반복작업을 없애는 툴
- **타겟:** 초보 위탁 셀러 전체가 시장 — 카피 조준점은 **직장인 부업러**, 페르소나 변주로 주부·육아맘 (기준: [../기획/PLAN.md](../기획/PLAN.md) 2장)

# 서비스 기능

## 원링크 — 플래그십

> **"링크 하나로 등록 정보까지"** — 도매꾹 URL 하나 넣으면 스마트스토어 등록 직전까지 전부.

### 사용 흐름

1. **상품 입력** — 도매꾹 링크·상품번호를 붙여넣거나, 검색(인기순·가격·낱개 필터)으로 상품 선택
2. **상품 확인** — 상품 요약(도매꾹가·최소구매수량·배송비), MOQ 2개 이상이면 묶음(1+1) 구성 판매 안내, 공급사 이미지 사용 허용 여부 자동 확인 (미허용 상품 차단, 편집 허용 범위 고지)
3. **등록 정보 시트** — 스마트스토어 등록 화면과 똑같은 순서로 자동 생성, 위에서 아래로 복사해 붙여넣기만:

| 순서 | 섹션 | 내용 |
|------|------|------|
| ① | 카테고리 | 후보 3개 자동 추천 (네이버쇼핑 상위 20개 분석) |
| ② | 상품명 | 추천 상품명 자동 조합 + 실시간 검사 (길이·특수문자·홍보문구·지재권 위험어) + 점수 등급 |
| ③ | 판매가 | 추천 판매가 (MOQ 묶음 원가 역산·마진·손익분기가·시장 가격 밴드), 할인율 표시용 정가 분해 |
| ④ | 재고수량 | 도매꾹 재고를 묶음 단위로 환산 |
| ⑤ | 옵션 | 옵션 조합 표 (가산가·재고) — 스마트스토어 옵션 일괄등록 양식(.xlsx) 다운로드 |
| ⑥ | 상품이미지 | 대표 1장 + 추가 9장 구성. 상세이미지에서 잘라오기, 클릭 한 번으로 편집(배경 제거·배경 교체·워터마크), 완성본 ZIP 다운로드 |
| ⑦ | 상세설명 | 상세 이미지 미리보기 + HTML 복사 (스마트스토어 [HTML 작성]에 붙여넣기) |
| ⑧ | 주요정보 | 모델명·품번·제조사·원산지·미성년자 구매 (API 확정값만) + KC 인증·인허가 배지 (전기·어린이·식품·화장품·의료) |
| ⑨ | 배송 | 배송비 자동 반영 |
| ⑩ | 반품 | 반품·교환비 정리 |
| ⑪ | 검색설정 | 태그 후보 10개 (상품명 중복 키워드 자동 제외·검색량 확인 뱃지·콤마 복사) |
| ⑫ | 판매자 코드 | 관리 코드(DG-) 자동 제안 |

> ※ 자동 등록(API 전송)은 제공하지 않는다 — 시트 복사·붙여넣기 방식. (카피에 "준비 중" 표현 금지 — 갭 관리 원칙)

## 소싱

> 뭘 팔지 정하고, 남는 장사인지 확인합니다

| 메뉴 | 설명 |
|------|------|
| 키워드 분석 | 월간 검색수 ÷ 등록 상품 수로 틈새 키워드 판정. 종합차트 13종 (12개월 트렌드·시즌성·기기·성별·연령·요일·시장 가격대·브랜드 장악도·실경쟁·블로그 문서수 등), 연관 키워드 30개 확장, 키워드 비교(최대 4개), [도매꾹에서 찾기]로 소싱 연결 |
| 도매꾹 검색 | 링크 없이 검색으로 소싱. 인기순·가격·낱개 구매 필터로 후보 발굴, 상품 클릭 시 원링크로 바로 투입 |
| 마진 계산 | 순이익 계산 + 목표 마진율을 넣으면 최소 판매가 역산 |

## 등록 준비

> 등록용 이미지를 가공 순서대로 완성합니다

| 메뉴 | 설명 |
|------|------|
| 누끼 | 여러 상품 이미지의 배경을 한 번에 제거하고 원하는 배경(색·패턴·검색 이미지)으로 교체 |
| 규격 맞추기 | 마켓별 대표이미지 규격(1000×1000 등)에 맞춰 일괄 변환, 상·하단 잘라내기 프리셋 |
| 규정 검사 | 대표이미지가 마켓 규정(해상도·비율·용량)에 맞는지 즉시 검사, 규격 변환으로 연결 |
| 워터마크 | 텍스트/로고 워터마크를 여러 이미지에 한 번에 합성 (도용 방지) |
| 상세 분할 | 긴 상세 이미지를 마켓 높이 제한에 맞춰 자동 분할, JPG 압축·번호 ZIP 저장 |
| 엑셀 대량 가공 | 대량등록 엑셀 속 상품 이미지를 최대 100장 모아 배경 제거까지 한 번에 |

# 컨텐츠 종류

- **구조:** 3종 — A 문제해결중심(기능 축) · B 사용자 여정 중심(사람 축) · C 정보성 컨텐츠(정보 축)
- **생산 순서:** 모든 컨텐츠는 블로그 → 쓰레드 → 유튜브 숏츠 순으로 재활용 — 1소재를 3채널 포맷으로 변주해 생산량을 극대화한다

> **공통 금지 체크 ([../기획/PLAN.md](../기획/PLAN.md) 9.5 금지 목록·11장 비목표 기준)**
> - 검증 불가한 수치·성과 주장 금지 ("월 300 벌었다" 류)
> - 페르소나 내부 설정 수치(32세·월 100만 등) 공개 카피 사용 금지
> - 어뷰징(가구매·리뷰 조작 등) 관련 소재 영구 금지
> - "평생 무료" 등 영구 무료 약속 금지 — 유료화 여지 보존을 위해 "지금 무료·무가입"처럼 현재형 사실 서술만

## 카피 재료 (전부 사실)

핵심 메시지 블록 (1~3 = 기획서 4장 "3대 약속"의 카피 번역):

1. **무료** — 장당 과금 없음, 무제한
2. **무가입** — 열면 바로 사용
3. **내 이미지는 브라우저에서** — 서버로 전송되지 않음 (상품 유출 걱정 없음)
4. **여정 메시지** — "도매꾹 링크 하나 → 등록용 이미지 세트" (도구 나열이 아니라 흐름으로 말한다)

서브카피 변주 (기본형·갭 관리 원칙은 기획서 9.3 — 여기는 조준점별 변주만):

- 부업 조준형: *"퇴근 후 몇 시간이 전부라면 — 이미지 작업은 오토셀러가 끝냅니다."*

## A. 문제해결중심 (축: 기능)

| 항목 | 내용 |
|------|------|
| 목적 | 고려 단계 — "이 문제, 이 기능으로 끝"을 보여줘 사용 이유를 만든다 |
| 타겟 여정 | 이미 부업/위탁판매를 시작했고 특정 작업에서 막힌 사람 |
| 산출물 | 플로우 단계당 1편 시리즈 (원링크 시트 ①~⑫ + 개별 기능별) |

### 작성 플로우

**1. 소재 선정** — 기준 = 상단 "서비스 기능" 표 (**단일 소스** — 별도 장점 표 두지 않음, 드리프트 방지). 플로우 단계당 1편: 원링크(상품 입력 → 상품 확인 → 시트 ①~⑫) + 개별 기능별

**2. 문제점 → 해결 구조로 대본화** — 기능 표의 사실 서술을 설득 어투로 변환 (예: "이미지 사용 허용 자동 확인" → "제재당할 상품인지 미리 걸러줌"). 컨셉: 친구 요청으로 서비스 만들어주는 개발자 (통화 컨셉)

### 예시

**제목:** "누끼 100장을 퇴근 후에 언제 다 따요? — 친구 전화 받고 만들어준 기능"

**대본 (통화 컨셉):**

```
친구: 야 바쁘냐. 나 부업으로 스마트스토어 시작했거든.
나: 오 잘했네. 근데 목소리가 왜 그래.
친구: 상품 등록하려는데 사진 배경 지우다가 새벽 2시 됐어.
     한 장에 몇 분씩 걸리는데 이게 수십 장이야.
나: 포토샵으로 하나씩 따고 있다고?
친구: 어. 부업 하려고 잠 줄였는데 사업이 아니라 야근을 하나 더 하는 기분이다.
나: 잠깐만. 내가 만들어둔 거 하나 있는데, 링크 보낼게. 거기에 그 도매꾹 주소 넣어봐.
친구: 뭔데 이게.
나: 넣어보면 알아.
친구: (잠시 후) 야. 배경 지워진 이미지가 바로 나오는데?
나: 어. 이미지 누르면 배경 교체도 되고 워터마크도 넣을 수 있어.
친구: 미쳤다. 이거 뭐 설치해야 돼?
나: 아니. 그냥 브라우저에서 링크 넣으면 끝. 가입도 없어.
친구: 야 이거 나만 쓰면 안 되냐.
나: 이미 사이트로 올려놨는데? auto-seller.co.kr
(자막: 다음 편 — "상품명은 뭐라고 지어야 되는데?")
```

## B. 사용자 여정 중심 (축: 사람)

| 항목 | 내용 |
|------|------|
| 목적 | 인지 단계 — "당신 지금 이 단계죠?"로 공감 먼저, 서비스는 여정 안에서 자연 등장 |
| 타겟 여정 | 부업 탐색~초기 진입. 아직 서비스 필요성을 모르는 사람 포함 |
| 산출물 | 여정 9단계 × 페르소나 3종 매트릭스 (최대 27편). 우선순위 = 직장인 부업러 행부터 (마케팅 조준점) |

### 작성 플로우

**1. 여정을 단계별 문제로 분해:**

| 단계 | 여정 | 문제 |
|------|------|------|
| ① 불만 | 월급날이 지나도 통장 그대로, SNS·유튜브에서 부업 성공썰을 본다 | 쿠팡알바·배달·블로그·스토어… 뭐가 내 상황에 현실적인지 판별 안 됨 |
| ② 해결방법 모색 | 검색하다 스마트스토어 위탁판매 발견, 무재고·소자본에 끌림 | 정보 과잉 — 성공썰과 강의·전자책 장사가 섞여 있어 뭐가 진짜인지 모름 |
| ③ 시작 준비 | 사업자등록, 통신판매업 신고, 스토어 이름 짓기 | 절차 순서가 헷갈림, 사업자 없이 시작 가능한지부터 궁금 |
| ④ 스토어 개설 | 개설 자체는 금방 끝났다. 텅 빈 스토어가 생겼다 | "이제 뭘 하지?" — 다음 행동이 안 보임 |
| ⑤ 아이템 탐색 | 뭘 팔지 정해야 한다. 유행템? 경쟁 심한 건 피해야 하나? | 검색량·경쟁도 보는 법을 모름, 감으로 고르게 됨 |
| ⑥ 도매처 탐색 | 도매꾹 같은 도매 사이트를 밤마다 뒤진다 | 같은 상품 파는 셀러가 수두룩, 팔릴 상품 판별 기준이 없음, 최소구매수량(MOQ)·이미지 사용 가능 여부 같은 함정을 모름 |
| ⑦ 수익성 검증 | 도매가에 마켓 수수료·배송비를 얹어 계산해본다 | 수수료율을 모르고, 계산이 서툴러 팔수록 손해인 가격을 매기기도 함 |
| ⑧ 상품등록 | 하위 여정으로 재분해: 카테고리 뭘로? → 상품명 어떻게? (금지어·글자수) → 판매가·할인가 → 옵션 조합 입력 → 이미지 가공(누끼·규격·용량 제한) → 상세페이지 만들기 → 주요정보(원산지·KC 인증 대상인지) → 배송·반품비 → 태그 | 항목마다 검색해서 배워야 하고, 이미지 가공이 시간을 제일 잡아먹음 — 한 상품에 몇 시간, 이걸 상품 수만큼 반복 |

## 생산 단위 — 소재 1개 = 산출물 세트 (2026-07-21 전면 개정)

**축이 채널별 일일 한도에서 "소재 단위 세트"로 바뀌었다.** 유튜브 롱폼이 주축이고, 나머지는 같은 소재에서 파생한다.

```
소재 1개 (검색어 기반)
   ↓
공통 뼈대 — 목차 · 핵심 주장 · 시연 구간 · 근거
   ├─→ 유튜브 롱폼 1편      구어체 대본, 화면 녹화, TTS 나레이션
   ├─→ 숏폼 3-4개           롱폼에서 구간 추출 (숏츠·릴스·클립)
   ├─→ 네이버 블로그 1편     검색 구조(소제목·표), 스크린샷, 영상 임베드
   └─→ 티스토리 1편          같은 소재 재작성 (문장 복붙 금지)
```

**변환이 아니라 병렬 집필이다.** 뼈대만 공유하고 문장은 매체 문법을 따른다 — 블로그 문어체를 TTS로 읽으면 낭독이 되어 이탈한다.

## 블로그 공통 (네이버·티스토리, 2026-07-20 확정)

- **이모지 사용 금지** (본문·제목·태그 전부)
- **CTA 링크는 고정:** `https://www.auto-seller.co.kr/` — URL만, 뒤에 "(무료·무가입)" 같은 괄호 문구 붙이지 않는다
- **누끼(배경 제거) 숏츠 제외:** AI 모델 처리로 실측 60초~2분 — 타이머 챌린지(30초) 부적합. 누끼 시연은 릴스·클립(길이 여유)에서만, 유튜브 숏츠 소재로는 다른 도구(원링크·계산기·규격·검사) 사용
- **원고 파일 = 발행용 클린 본문** — 상단 메타(종류·요약·발행 안내)와 줄 앞 `[속성]` 마커를 넣지 않는다. 소재 분류는 캘린더가 관리
- **이미지 체계:** 서비스 화면을 미리 일괄 캡처해 `public/marketing/`에 커밋 → 배포되면 `https://www.auto-seller.co.kr/marketing/<파일명>.png` 고정 URL. 원고에는 **이미지가 들어갈 자리에 URL만 한 줄로** 남긴다 (`![]()` 마크다운 금지 — 대표가 발행 시 URL을 붙여 이미지로 삽입)
  - 티스토리·네이버 공통: 해당 URL을 에디터에 붙여 이미지로 삽입 (링크 카드로 들어가면 드래그 업로드로 대체)
- **가독성 원칙:** 시선이 위→아래로 한 번에 흐르게 — 좌우 병렬 나열 금지, 한 단락 = 한 메시지, 소제목 사이 이미지·표·목록으로 리듬 부여, 문장은 짧게
- **섹션 제목과 바로 아래 내용 사이 빈 줄 금지** — `### 소제목` 다음 줄에 곧바로 본문 시작 (섹션과 섹션 사이 간격은 유지)

## 네이버 블로그 (검색 유입 주력 — C-Rank·D.I.A. 대응)

- **파일 양식:** 제목 / 본문(마크다운) / 태그(최대 30)
- **제목:** 검색 키워드를 앞쪽에 + 구체 편익 (예: "스마트스토어 상품등록 12단계, 순서대로 따라하기")
- **본문 구조:** 훅(인용구) → 소제목 3~5개 → CTA 1회(가운데 정렬, 글 끝). 단락은 500자 이내로 분할
- **길이:** 본문 공백 제외 **1,500~2,000자** (용어사전·FAQ는 하한 1,200 — 억지 늘리기 금지)
- **이미지: 6장 이상** — D.I.A. 경험 신호·체류시간은 글자수보다 이미지가 큰 변수. 원고의 `[사진]` 슬롯(2~3개)은 필수 위치이고, **나머지는 발행 시 소제목마다 실측 캡처 1장씩 추가**해 총 6장+을 채움
- **서식 적용 (마커 폐지 — 2026-07-20):** 원고는 순수 마크다운, 서식은 고정 매핑으로 적용
  - 1순위 (테스트 후 확정): 마크다운 **렌더 화면**(VSCode 미리보기·크롬)을 전체 복사 → 네이버 에디터 붙여넣기 — 헤딩·볼드가 리치텍스트로 유지되면 수작업 제로
  - **서식 최소화 (2026-07-20):** 본문 볼드 제거, 소제목은 작은따옴표('소제목'), **표 사용 금지**(수동 작업 부담 — 화살표 목록으로 대체). 발행 시 소제목만 볼드+19. 티스토리는 마크다운 그대로(표·### 유지)
- **태그:** 주제 키워드 + 타겟 공통 축(직장인부업·무재고 등) + 오토셀러. **특수문자 금지** — 한글·영문·숫자만 (1+1 ❌ → 원플러스원 ⭕). 입력 방법: **태그 편집창에 붙여넣기 금지** (붙여넣기 분리 미지원 — 통째로 1태그 + 100자 오류). 대신 원고의 `#태그 #태그` 블록을 **본문 맨 끝에 붙여넣기** — 본문 해시태그는 자동으로 태그 등록됨(동일 30개 한도). 붙여넣은 해시태그가 링크(초록)로 변환되는지 발행 전 확인, 안 되면 각 태그 뒤에서 스페이스 한 번씩

- **부가 기능 활용:** ① 셀프 댓글 연작 ≫≫ ② 설문 > ③ 캔버스 — 댓글을 **압도적으로** 자주, 설문·캔버스는 **가끔 리프레시용**
  - **① 셀프 댓글 연작 (1/N) — 압도적 주력:** 정보량 있는 유형은 대부분 연작화. 본문 = 훅 1줄, 본론은 자기 댓글 2~4개로 분해. 연작(1/N) = 클릭 유도 + 댓글 수 = 도달 가중치. 마지막 댓글 = "프로필 링크" CTA. (③공감 단문만 예외)
  - **② 설문/투표 — 가끔:** ④사실 팁+질문 유형과 결합. 투표 참여 = 반응 신호. 하루 5개 중 1개 정도
  - **③ 캔버스(텍스트 배경 카드) — 가끔, 본문 전용:** ⚠️ **댓글에는 캔버스 카드 못 넣음 — 본문에만.** 공식·단계 요약을 본문 카드로 시선 고정 (리프레시 효과). 주 2~3편에 1장 정도, 남발 금지
- **이미지 첨부 = 파일 링크 제공:** ②기능 팁 등 스크린샷이 필요하면 원고에 그 이미지 파일을 마크다운 링크로 — 대표가 Ctrl+클릭으로 파일 열어 첨부. 형식: `[설명](상대경로/파일.png)` (쓰레드.md 기준 `../../../../../../public/marketing/파일.png`)
- **고정 게시물:** 프로필 유입자용 브랜드 소개 1개 상시 고정 (구조: 슬로건 3행 오프닝 → 기능 → 공감 반전 → 프로필 링크 CTA + 팔로우 가치, 화자 = 브랜드) + 시트 스크린샷 1장 첨부
- **금지:** 블로그 문장 복붙, 해시태그 남발 (쓰레드는 태그 문화 약함 — 0~1개)

## 유튜브 롱폼 — 주축 채널 (2026-07-21 전환)

> 배포: 유튜브 롱폼(가로 16:9). 무본명·무얼굴, **TTS 나레이션**(일레븐랩스). 파이프라인 설계는 [../개발/LONGFORM-PIPELINE.md](../개발/LONGFORM-PIPELINE.md)

**왜 주축인가**
- 타겟(초보 위탁 셀러)은 **발언하지 않고 검색한다** — 소싱처·키워드 노출이 곧 경쟁 유발이라 SNS에서 조용하다. Push(피드) 아닌 **Pull(검색)** 채널이어야 도달한다
- **자산이 축적된다** — 쓰레드 글은 3일이면 죽지만 롱폼은 1년 뒤에도 검색 유입이 붙는다. 1인 운영에서 결정적
- **전환이 된다** — 전 과정을 가르치면서 "이 단계는 이 도구로 줄인다"를 보여주는 게 광고보다 세다. 롱폼만 할 수 있는 형식

**제목 = 검색어**
우리가 하고 싶은 말이 아니라 **초보가 치는 말**을 제목으로 쓴다. 블로그 제목과 같은 검색어를 노려 두 채널이 서로 밀어주게 한다. 특수문자(`?` `/` `:`) 금지 — mp4 파일명이 곧 제목이 되므로.

**대본 규칙**
- **구어체 필수** — 블로그 문장을 그대로 읽으면 낭독이 된다. 지속률이 곧 노출인데 여기서 깎인다
- 문장 1줄 = TTS 1호출 = 자막 1줄. 줄바꿈이 곧 호흡
- 챕터 구조 + `[화면: 시나리오]` 지시 + `(정차역)` 강조 시점
- 실측 수치만 기입 (금지 체크 4항 유지)

**BGM 없음** — 나레이션이 무음을 채우므로 불필요. Content ID 클레임 리스크도 함께 소거된다 (7월 사고 재발 방지).

**소재 축** — [소재/키워드-리서치.md](./소재/키워드-리서치.md) 참조. 여정 9단계 × 페르소나 3종 매트릭스에 검색 빈틈·시의성 키워드를 곱한다. **첫 소재군 = 스마트스토어 등록 한도제(26.6 시행)** — 유튜브 공급이 2021년작 하나뿐이고, 한도제가 대량등록 전략을 무효화해 기존 상위 영상이 전부 낡았다. 우리 "선별 돕는 도구" 포지션과 정확히 맞물린다.

> **페르소나 분할 규칙:** 시간·맥락만 바꾼 복제는 금지. 페르소나별 **고유 제약·문제**를 축으로 재집필한다 — 직장인(겸업 금지·연말정산) / 주부(건강보험 피부양자 자격) / 육아맘(전화 CS 불가). 문제가 다르면 해법도 달라 진짜 다른 콘텐츠가 된다.
