## 한눈에

**주축 = 유튜브 롱폼.** 소재 하나로 롱폼 1편 + 블로그 2편 + 숏폼 3-4개를 만든다.

| 채널 | 상태 | 산출 |
|---|---|---|
| **쓰레드** | **주 채널** — 유입·전환·고객조사 | 댓글유도형 (유도어 10종) |
| 유튜브 롱폼 | 장기 자산 (초기 성과 느림) | 소재당 1편 |
| 유튜브 숏폼 (릴스·클립) | 롱폼 파생 + **쓰레드 첨부용** | 3-4개 |
| 네이버 블로그 | 검색 자산 | 소재당 1편 |
| 티스토리 | 검색 자산 | 소재당 1편 |
| 네이버 카페 | 보류 (질문 희소) | 0 |

> **주 채널 = 쓰레드 (2026-07-23).** GA4에서 유입·전환이 나오는 유일한 채널. 유튜브는 접지 않되 초기 성과가 가장 느리므로 기대치를 조정한다.

> **주간 편수: 소재 2개/주 (2026-07-22 확정, 파일럿 실측 후).** 롱폼 2편 → 파생 숏폼 6-8개 → 블로그 3-4편. 신규 채널이라 편수보다 편당 완주율 우선. **7월 말 시청 지속률 데이터 보고 증감 결정.**
> 실측 근거: 소재당 렌더 약 20분(자동), 대표 시간 0 — 대본·시나리오는 Claude, 녹화·TTS·합성·렌더는 배치 자동.

# 1. 무엇을 말하는가

## 서비스 소개

- **한줄:** 도매꾹 링크 하나로 이미지 가공부터 등록 정보까지, 초보 위탁 셀러의 상품 등록 반복작업을 없애는 툴
- **타겟:** 초보 위탁 셀러 전체가 시장. 카피 조준점은 **직장인 부업러**, 변주로 주부·육아맘
- **갭 관리:** 자동 등록(API 전송) 미제공 — "준비 중" 표현 금지

## 카피 재료

**가격·가입 조건은 카피 축이 아니다.** 유료화·가입 도입 예정이라 바뀐다. 축은 제품이 주는 **결과**여야 한다.

| 축 | 메시지 | 왜 |
|---|---|---|
| **시간** | 상품 하나 올리는 데 걸리던 몇 시간을 몇 분으로 | 핵심 pain. 실측 가능해 검증 문제 없음 |
| **실수 방지** | MOQ·이미지 사용권·금지어·KC를 등록 전에 걸러준다 | 초보가 모르는 함정. 진짜 차별점 |
| **판단 근거** | 감으로 고르지 않게, 검색량과 마진을 숫자로 | 한도제 시대엔 선별이 핵심 |
| **여정** | 도매꾹 링크 하나 → 등록 직전까지 | 도구 나열이 아니라 흐름으로 |

서브카피 예시:
- *"퇴근 후 몇 시간이 전부라면 — 등록 준비는 오토셀러가 끝냅니다."*
- *"몰라서 제재당하는 일, 등록 전에 막습니다."*

가격·가입은 **각주로만**: "지금은 무료로 쓸 수 있습니다" 수준. 조건이 바뀌면 이 문구만 갱신한다.

## 금지 사항

- 검증 불가한 수치·성과 주장 ("월 300 벌었다")
- 페르소나 내부 설정 수치 (32세·월 100만 등)
- 어뷰징 소재 (가구매·리뷰 조작)
- 영구 무료 약속 ("평생 무료")
- 경쟁 툴 깎아내리기

근거: [기획서 9.5](../기획/PLAN.md)

# 2. 어떻게 쓰는가

## AI 냄새 금지 — 최우선

**콘텐츠에서 AI 티가 나면 안 된다.**

가장 흔한 실패는 **고통 묘사는 진짜인데 해결 전환이 광고**가 되는 것이다.

```
부업하려고 잠을 줄였는데, 야근을 하나 더 하는 기분이었다.   ← 진짜
그러다 링크만 넣으면 다 나오는 툴을 찾았다.                ← 광고
```

"그러다 ~를 찾았다"는 사람이 안 쓰는 문장이다. 실제로는 "몇 개 써봤는데 다 별로였고, 이건 좀 낫더라"에 가깝다.

### 금지

| 패턴 | 설명 |
|---|---|
| 마찰 없는 전개 | 문제→해결 직행. 실제론 의심·실패·재시도가 섞인다 |
| 과장 리액션 | "미쳤다" "대박" "완전" — 진짜 반응은 "어 되네" 수준 |
| 대칭 문장 | "A가 아니라 B다" — AI 문장의 대표 지문 |
| 교훈형 마무리 | 정리하며 끝내기. 사람은 그냥 끝낸다 |
| 균일한 리듬 | 모든 문장이 같은 길이 |
| 결론 먼저 → 근거 나열 | 사람은 겪은 순서대로 말한다 |
| 등장인물이 기능 설명 | 친구가 스펙을 읊는 대사 |
| 이모지·감탄사 | 블로그는 전면 금지 |

### 필수

| 요소 | 예 |
|---|---|
| 실패를 포함 | "처음엔 이것도 안 됐다" |
| 구체적 수치·고유명사 | "새벽 2시", "37장", "3,900원짜리 텀블러" |
| 불완전한 문장 | 중간에 끊기, 되돌아가기 |
| 단점 인정 | "누끼는 좀 느리다" |
| 확신 없는 표현 | "내 경우엔", "아마" |
| 딴소리 한 줄 | 본론과 무관한 문장 하나 |

> **검증 방법: 입으로 읽어본다.** 어색하면 고친다. 롱폼은 TTS라 이게 그대로 결과가 된다 — 문어체면 낭독이 되고, 매끄러우면 광고가 된다.

### 훅 라이브러리 (2026-07-23)

첫 줄이 도달을 정한다. 아래는 **AI 냄새 필터를 통과한 것만** 남긴 목록 — 그대로 쓰거나 소재만 갈아끼운다.

**손실회피 — 모르면 손해**
```
"최소 3개"의 뜻을 첫 주문 정산서 보고 알게 되는 것만큼 비싼 수업료가 없더라고요.
낱개 값으로 올렸는데 알고 보니 3개 묶음이었던 적 있으세요?
상세 이미지 길게 올렸다가 등록 거부당하신 분 계실까요.
전기용품에 KC 인증 필요한 거, 저도 최근에야 알았어요.
```

**호기심 — 몰랐던 사실**
```
대표이미지 최소 크기가 300×300인 건 의외로 모르시더라고요.
판매중지해둔 상품도 등록 개수에는 그대로 잡혀요.
태그 10칸에 상품명이랑 겹치는 단어 쓰면 그만큼 날리는 거예요.
```

**반전 — 알던 것과 다름**
```
6월부터 많이 올리는 게 손해가 됐습니다.
등록 수 적으면 불리하다던 얘기, 지금은 통하지 않아요.
매출이 좋아도 조건 하나 때문에 1,000개로 묶입니다.
상세페이지, 새로 만들지 않아도 등록되는 경우가 많아요.
싼 물건 많이 파는 쪽이 불리할 줄 알았는데 아니었습니다.
```

**비교 — 판단 기준**
```
검색수를 등록 상품수로 나눠보면 레드오션인지 숫자로 나옵니다.
간이랑 일반, 매출 넣어보면 어디가 유리한지 바로 보여요.
카테고리 하나 잘못 넣으면 검색에서 아예 안 뜨는 경우가 있어요.
상품 20개 배경 지우는 데 저녁이 통째로 갑니다.
```

**남은 것들의 공통점:** 겪은 일이거나 · 물어보거나 · 놀라운 사실. 전부 **사람이 말할 법한 것**이다.

#### ❌ 폐기: 권위 후킹

출처를 인용하면 문체가 딱딱해진다 — "명시돼 있습니다", "정해져 있어요"는 대화에서 안 쓰는 말이다. 5개 중 4개가 필터에 걸려 카테고리째 폐기.

**대신 위치를 바꾼다:**
```
❌ 훅에 출처    "산정 대상은 셋뿐이라고 명시돼 있습니다"
✅ 훅은 경험    "판매중지해둔 상품도 개수에 잡혀요"
   본문에 출처    → "공식 FAQ 보니까 그렇더라고요"
```
근거는 버리지 않되 **첫 줄에는 두지 않는다.**

#### ❌ 폐기: FOMO·정체성 후킹

"지금이 마지막 기회" "상위 1%는 다 안다" 류. **우리가 그 말을 할 근거가 없고**, [PLAN 9.5](../기획/PLAN.md) 금지(검증 불가 수치·과장)에 걸린다.

> 범용 후킹 템플릿(160개 모음 류)을 참고할 때 주의: 절반이 우리 금지 조항에 걸리고, 반전 계열은 "A가 아니라 B다" 대칭이라 AI 냄새 규칙과 충돌한다. **우리 무기는 낚시가 아니라 구체성이다** — 셀러는 "마지막 기회"엔 안 속지만 "최소구매수량"엔 반응한다.

### 화면에서도 AI 티가 난다

대본만 사람 같아도 소용없다. 화면이 자동생성 티를 내면 거기서 끝난다. 강한 신호부터:

| 신호 | 왜 티가 나나 | 규칙 |
|---|---|---|
| **균일한 타이밍** | 모든 간격이 똑같다. 사람 편집은 불균일 | 챕터 끝 1.0초 · 정차역 뒤 0.8초 · 일반 0.35초 |
| **기계적 커서** | 등속 직선 이동 | 곡선 경로 + 목표 근처 감속 + 미세 오버슈트 |
| **딱딱 끊기는 컷 전환** | 화면이 뚝뚝 바뀜 = 자동생성 티 | 챕터 전환에 크로스페이드·슬라이드 등 **전환 효과 필수** |
| **모션그래픽 인트로 카드** | 매 편 같은 카드 = 템플릿 티 | 타이틀 모션 카드 금지. 강의형 콘텐츠 슬라이드는 허용 |
| **선형 줌·팬** | `interpolate` 기본값이 등속 | 모든 움직임에 easing. **등속 금지** |
| **정지 화면 방치** | 이미지가 강조 없이 오래 떠 있으면 지루 = 이탈 | 화면에 항상 **움직임(줌·팬) + 강조(하이라이트/화살표)**를 준다 |

> **자막은 전문장(100%) 표시.** 초기 방침(강조만)은 파일럿에서 지루하고 정보 전달이 약했다 — 폐기. 롱폼도 숏폼처럼 모든 문장에 자막을 깐다 (2026-07-22 대표 판정).

> ⚠️ **의도적으로 허술하게 만들지 마라.** 오타를 넣거나 화면을 지저분하게 두면 "사람 같다"가 아니라 **"품질이 낮다"**가 된다.
> 목표는 불완전함이 아니라 **자연스러움**이다 — 리듬이 불균일하고, 움직임에 관성이 있고, 여백이 있는 것. 실수가 있는 게 아니다.

## 콘텐츠 구조

```
도입 30초 — 여정 문제 묘사 (공감)
    ↓
본론 — 실제 해결 절차
    ↓
그 과정에 도구 등장
    ↓
CTA 1회 (auto-seller.co.kr)
```

공감은 **도입 30초까지만**. 검색해서 온 사람은 답을 원한다. 공감이 길면 이탈한다.

# 3. 무엇을 만드는가

## 콘텐츠 4종 — 검색 의도 기준

| 유형 | 고객의 질문 | 예시 소재 |
|---|---|---|
| **① How-to** | "어떻게 하나" | 도매꾹 위탁판매 하는 법 · 상품등록 방법 |
| **② 트러블슈팅** | "안 되는데 왜" | 노출 안 됨 · 반품 처리 · 품절 대응 |
| **③ 판단 기준** | "뭐가 나은가" | 도매꾹 vs 도매매 · 간이 vs 일반과세 |
| **④ 최신 정보** | "바뀌었다는데" | 등록 한도제 · 수수료 개편 |

공감·여정 서사는 별도 종류가 아니다. **모든 콘텐츠의 도입 30초**로 흡수한다.

## 유형별 비중

| 유형 | 초기 3개월 | 안정 후 | 이유 |
|---|---|---|---|
| ④ 최신 정보 | **40%** | 15% | 한도제 공백이 현재 최대. 수명이 짧아 계속 의존 불가 |
| ② 트러블슈팅 | **30%** | 30% | 빈틈 키워드 대부분. 문제는 계속 생겨 수명이 길다 |
| ③ 판단 기준 | 20% | 25% | 영상 공급이 적고 우리 도구가 판단 근거를 준다 |
| ① How-to | 10% | **30%** | 포화라 초기엔 안 뜬다. 권위 쌓은 뒤 늘린다 — 전환은 이게 제일 세다 |

초기 목표는 **뚫는 것**, 안정 후는 **전환**. 산정 근거는 [부록 채점표](#부록-유형별-채점표).

## 소재 발굴 — 여정 9단계

고객이 어느 단계에서 뭘 검색하는지의 지도다. 모든 소재가 여기서 나온다.

| 단계 | 상황 | 문제 |
|---|---|---|
| ① 불만 | 통장은 그대로, 부업 성공썰을 본다 | 뭐가 내 상황에 현실적인지 판별 안 됨 |
| ② 해결 모색 | 위탁판매 발견, 무재고·소자본에 끌림 | 성공썰과 강의 장사가 섞여 뭐가 진짜인지 모름 |
| ③ 시작 준비 | 사업자등록·통신판매업 신고 | 절차 순서가 헷갈림, 사업자 없이 가능한지 |
| ④ 스토어 개설 | 텅 빈 스토어가 생겼다 | "이제 뭘 하지" — 다음 행동이 안 보임 |
| ⑤ 아이템 탐색 | 뭘 팔지 정해야 한다 | 검색량·경쟁도 보는 법을 모름, 감으로 고름 |
| ⑥ 도매처 탐색 | 밤마다 도매 사이트를 뒤진다 | 판별 기준 없음. MOQ·이미지 사용권 함정을 모름 |
| ⑦ 수익성 검증 | 수수료·배송비를 얹어 계산 | 팔수록 손해인 가격을 매기기도 함 |
| ⑧ 상품등록 | 카테고리·상품명·가격·옵션·이미지·상세·KC·태그 | 항목마다 검색해서 배워야 함. 이미지 가공이 시간을 다 먹음 |
| ⑨ 등록 후 | 올렸는데 주문이 없다 | 노출·광고를 모름. "등록 수를 늘려라"에 ⑤-⑧ 무한 반복 |

**우리 도구가 등장하는 지점:**

| 여정 | 기능 |
|---|---|
| ①-④ | 콘텐츠가 커버 (제품 등장 전 신뢰 구간) |
| ⑤ | 키워드 분석 — 감이 아니라 데이터로 |
| ⑥ | 도매꾹 검색 + 원링크 상품 확인 (MOQ·라이선스 자동 안내) |
| ⑦ | 마진 계산 + 원링크 추천 판매가 |
| ⑧ | 원링크 등록 시트 ①-⑫ |
| ⑨ | 반복 구간 시간 단축 (노출·광고 자체는 범위 밖) |

## 페르소나 분할

**시간·맥락만 바꾼 복제는 금지.** 페르소나가 유효한 건 시간대가 달라서가 아니라 **부딪히는 문제가 다르기 때문**이다.

| | 직장인 부업 | 주부 | 육아맘 |
|---|---|---|---|
| 가용 시간 | 밤 10시-1시, 연속 3시간 | 낮 짬 시간, 조각남 | 아이 재운 새벽, 예측 불가 |
| **고유 문제** | 겸업 금지, 사업자등록이 회사에 알려지나, 연말정산 | **건강보험 피부양자 자격 탈락** | **전화 CS를 못 받는다** |

같은 여정 단계라도 결론과 검색어가 달라진다.

# 4. 어디에 올리는가

## 생산 단위 — 소재 1개 = 산출물 세트

```
소재 1개 (검색어 기반)
   ↓
공통 뼈대 — 목차 · 핵심 주장 · 시연 구간 · 근거
   ├─→ 유튜브 롱폼 1편     구어체 대본, 화면 녹화, TTS
   ├─→ 숏폼 3-4개          롱폼에서 구간 추출
   ├─→ 네이버 블로그 1편    검색 구조, 스크린샷, 영상 임베드
   └─→ 티스토리 1편         전면 재작성
```

**변환이 아니라 병렬 집필이다.** 뼈대만 공유하고 문장은 매체 문법을 따른다. 블로그 문어체를 TTS로 읽으면 낭독이 되어 이탈한다.

> **채널 간 문장 복붙 금지.** 유사문서 감지를 피하려면 채널별로 재작성해야 한다.

## 블로그 공통

- **이모지 금지** (본문·제목·태그 전부)
- **CTA 링크 고정:** `https://www.auto-seller.co.kr/` — URL만, 괄호 문구 붙이지 않는다
- **원고 = 발행용 클린 본문** — 상단 메타·`[속성]` 마커 넣지 않는다
- **가독성:** 시선이 위→아래로 흐르게. 좌우 병렬 금지, 한 단락 = 한 메시지, 문장은 짧게
- **섹션 제목 바로 아래 빈 줄 금지** (섹션 사이 간격은 유지)

**이미지 체계**

서비스 화면을 미리 캡처해 `public/marketing/`에 커밋 → 배포되면 `https://www.auto-seller.co.kr/marketing/<파일명>.png` 고정 URL.

원고에는 **URL만 한 줄로** 남긴다. `![]()` 마크다운 금지 — 대표가 발행 시 URL을 붙여 이미지로 삽입한다. 링크 카드로 들어가면 드래그 업로드로 대체.

## 네이버 블로그

검색 유입 주력. C-Rank·D.I.A. 대응.

| 항목 | 규칙 |
|---|---|
| 파일 양식 | 제목 / 본문(마크다운) / 태그(최대 30) |
| 제목 | 검색 키워드를 앞쪽에 + 구체 편익 |
| 본문 구조 | 훅(인용구) → 소제목 3-5개 → CTA 1회(가운데, 글 끝). 단락 500자 이내 |
| 길이 | 공백 제외 **1,500-2,000자** (용어사전·FAQ는 하한 1,200) |
| 이미지 | **6장 이상** — 체류시간엔 글자수보다 이미지가 크다 |
| 발행 | 소재당 1편. 10·15·20시 중 택1 |

**서식 최소화** — 본문 볼드 제거, 소제목은 작은따옴표(`'소제목'`), **표 금지**(수동 작업 부담 — 화살표 목록으로 대체). 발행 시 소제목만 볼드+19.

**태그 입력** — 특수문자 금지(한글·영문·숫자만. `1+1` ❌ → `원플러스원` ⭕).

> ⚠️ **태그 편집창에 붙여넣기 금지** — 분리 미지원이라 통째로 1태그가 되고 100자 오류가 난다.
> 대신 원고의 `#태그 #태그` 블록을 **본문 맨 끝에 붙여넣는다** (본문 해시태그는 자동 태그 등록, 30개 한도). 초록 링크로 변환되는지 확인하고, 안 되면 각 태그 뒤에 스페이스 한 번씩.

## 유튜브 롱폼 (주축)

가로 16:9. 무본명·무얼굴, **TTS 나레이션**(일레븐랩스). 제작은 [LONGFORM-PIPELINE.md](../개발/LONGFORM-PIPELINE.md).

**왜 주축인가**

- 타겟은 **발언하지 않고 검색한다** — 소싱처·키워드 노출이 경쟁을 부르니 SNS에서 조용하다. Push가 아니라 Pull 채널이어야 도달한다
- **자산이 쌓인다** — 쓰레드 글은 3일이면 죽지만 롱폼은 1년 뒤에도 검색 유입이 붙는다
- **전환이 된다** — 전 과정을 가르치며 "이 단계는 이 도구로 줄인다"를 보여주는 게 광고보다 세다

**제목 = 검색어**

우리가 하고 싶은 말이 아니라 초보가 치는 말을 쓴다. 블로그와 같은 검색어를 노려 두 채널이 서로 밀어주게 한다. 특수문자(`?` `/` `:`) 금지 — mp4 파일명이 곧 제목이 된다.

**분량**

| 구분 | 길이 | 대본 분량 (공백 제외) |
|---|---|---|
| **하한** | 5분 | 약 1,700자 |
| **표준** | 8-12분 | 2,700-4,100자 |
| **상한** | 15분 | 약 5,100자 |

- **소재가 길이를 정한다.** 억지로 늘리지 않는다 — 늘어진 구간이 완주율을 깎고, 완주율이 곧 노출이다
- **5분 미만이면 영상으로 만들지 않는다.** 블로그로 충분하다는 뜻이다
- **초기 3개월은 6-10분 권장** — 신규 채널은 완주율이 중요하다. 긴 영상은 권위가 쌓인 뒤
- 유형별 적정: 트러블슈팅 5-8분 / 판단 기준 6-10분 / 최신 정보 8-12분 / How-to 10-15분
- 환산 기준(실측): 나레이션 **분당 385자**, 문장 간 간격 포함 **실효 340자/분**. 렌더는 **영상 길이의 3.6배** — 10분 영상 = 36분

**대본 규칙**

- **구어체 필수** — 블로그 문장을 읽으면 낭독이 된다
- 문장 1줄 = TTS 1호출 = 자막 1줄. 줄바꿈이 곧 호흡
- 챕터 구조 + `[화면: 시나리오]` + `(정차역)` 강조 시점
- 실측 수치만

**BGM 없음** — 나레이션이 무음을 채운다. Content ID 리스크도 함께 소거된다.

**첫 소재군 = 스마트스토어 등록 한도제(26.6 시행).** 유튜브 공급이 2021년작 하나뿐이고, 한도제가 대량등록 전략을 무효화해 기존 상위 영상이 전부 낡았다. 우리 "선별 돕는 도구" 포지션과 맞물린다.

### 왜 댓글인가 — 리드가 남는다

조회수는 누가 봤는지 모른다. **댓글·좋아요는 계정이 남아 DM으로 이어진다.** 댓글 단 사람 = 그 기능이 필요한 사람 = 리드 명단.

- 유도어는 **한 단어**로 (복붙 가능해야 함 — 문장 요구는 진입장벽)
- **댓글엔 전부 답장** — 대댓글 수가 도달을 만들고, "뭐길래 이렇게 많나" 클릭 유인이 된다
- 본문에 링크 금지 → 프로필 링크 경유
- 같은 유도어 2주 내 반복 금지

> 근거: 경쟁 채널 @bulsaja_ — **7/7 시작해 보름 만에 594댓글**. 신규 채널도 이 형식이면 된다는 증거.

# 피벗 기준 (2026-07-23 확정)

**미리 못 박아둔다.** 기준이 없으면 매일 흔들린다. 흔들릴 때는 이 표만 보고 "지금 철수 조건에 해당하나?"를 확인한다.

## 피벗은 3층 — 섞지 않는다

| 층 | 무엇을 바꾸나 | 주기 |
|---|---|---|
| **① 형식** | 글 유형·훅·썸네일·구성 | 2주 |
| **② 채널** | 어디에 시간을 쓰나 | 월 1회 |
| **③ 제품** | 타겟·기능 방향 | 분기 또는 명확한 신호 |

> 불안할 때 대부분 ②를 의심하지만, 실제로 손봐야 할 건 ①인 경우가 많다.

## 채널별 판정

### 쓰레드 (주 채널)
```
유지  → 주간 세션 10+ 또는 전환 5+
경고  → 2주 연속 세션 5 미만
철수  → 4주 연속 전환 0
```

### 유튜브
```
판정 시점 = 5편 누적 + 100노출 (둘 다 충족해야 판정)
  CTR 2% 미만              → 썸네일·제목 교체 (형식 피벗)
  CTR 정상 + 지속률 30% 미만 → 육성·구성 재검토
  검색 노출 계속 0          → 제목 키워드 재설계
철수 → 10편 + 8주 후에도 검색 노출 0
```

> **노출이 안 붙는 건 영상 품질이 아니라 채널 나이 문제다.** 구독자 0이면 유튜브가 반응을 측정할 시드 자체가 없다. 몇 시간 만에 뜨는 채널은 기존 구독자가 시드 역할을 한다.
> 대응: 쓰레드에서 영상으로 유입을 보내 **초기 시드를 외부에서 만든다.**

### 블로그
```
판정 시점 = 발행 후 4-8주 (색인·랭킹 안착)
철수 → 8주 후 검색 유입 0
```

## 제품 피벗 — 채널보다 중요

| 신호 | 지표 | 뜻 |
|---|---|---|
| 🔴 **제품** | `domeggook_lookup` 대비 `zip_download` 전환이 낮음 | 도구를 열었는데 결과물을 안 가져감 = 기대와 다름 |
| 🔴 **타겟** | 설문에서 이미지편집이 1위에서 밀림 | 페인포인트 가설이 틀림 |
| 🟢 유지 | 위 둘 다 아님 | 현행 |

| 시점 | 무엇 | 층 |

| 매월 마지막 일요일 | 월간 리뷰 — 채널 형식 반응 | ① |

## 판정 불가일 때는 판정하지 않는다

- 표본 부족(노출 100 미만·세션 10 미만)이면 **"판정 불가"로 기록하고 넘어간다**
- 억지 결론 금지. 다음 주기로 이월
- **작동 중인 것은 바꾸지 않는다** — 개선은 안 되는 것부터
