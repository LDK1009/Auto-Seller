# 유튜브 벤치마크 영상 분석

> 다른 채널의 영상 구성·자막을 추출해 **구조·패턴을 학습**하고 우리 콘텐츠에 반영한다.
> ⚠️ **구조 학습이지 복제가 아니다.** 자막 문장을 그대로 베끼지 않는다 ([MARKETING 원칙](../MARKETING.md): AI 냄새·과장 금지). 남의 대본은 "훅 위치·챕터 구성·템포"만 뽑아 우리 방식으로 재작성한다.

## 추출 방법 (yt-dlp)

```bash
# 채널 인기 영상 목록 (조회·길이·제목)
yt-dlp --flat-playlist --playlist-end 15 --print "%(view_count)s|%(duration)s|%(title)s" "https://youtube.com/@채널/videos"
# 자막(자동생성 포함) 추출
PYTHONIOENCODING=utf-8 yt-dlp --skip-download --write-auto-sub --sub-lang "ko,ko-orig" --sub-format vtt URL
# 검색 상위 트렌드
yt-dlp --print "%(view_count)s|%(duration)s|%(title)s" "ytsearch12:키워드"
```
> 콘솔 한글 깨짐 → 파일로 저장 후 Read. 공식 API는 남의 채널 자막 불가라 yt-dlp 사용(회색지대, 로컬 소량 리서치 한정).

## 분석 1 — @maker39 (셀러 도구 무료배포 채널) · 우리와 유사 포지션

15편 전부 **"무료 배포" 프로그램** 영상. 네이버쇼핑·쿠팡 상위노출 데이터 추출 도구.

| 패턴 | 관측 |
|---|---|
| 제목 | `[Free Release/Distribution/Giveaway]` + 기능 + 프로그램 + 버전(v0.0.x) |
| 조회 | 900~5,300 (셀러 니치라 규모는 작음) |
| 길이 | 4~13분 |
| 후크 | "돈 내던 게 이제 무료" / "유료 프로그램 필요 없다" |

**우리 시사점:** 무료 후크가 셀러 니치에서 먹힌다. **단 우리는 웹도구(설치 없음·무가입)가 차별점** — @maker39는 exe 프로그램 배포라 설치·보안 부담이 있다. "설치도 가입도 없이 브라우저에서 바로"가 우리 우위.

## 분석 2 — 3H 프레임워크 강의 (콘텐츠 전략) ⭐ 채널 운영 지침

715초·조회 8,105. 유튜브가 만든 **히어로·허브·헬프** 콘텐츠 3분류.

| 유형 | 목적 | 성격 | 예 |
|---|---|---|---|
| **히어로** | 신규 유입·채널 인지 | 대규모 캠페인, 알고리즘 확산 | 볼보 트럭 반담 스플릿 광고 |
| **허브** | 기존 구독자 유지 | 정기 시리즈("급식처럼 따박따박") | 브라이언의 트럭 리포트 |
| **헬프** | 검색 유입 | 문제 답변, 트렌드 안 타 오래 쌓임 | 조립 가이드·사용법 |

**핵심 논리:** 셋은 서로 단점을 메운다. 히어로만=유령구독자, 허브만=볼륨 정체, 헬프만=브랜드 인지 약함. **비율(원안 10/30/60)은 유연하게** — 사업에 맞게 조정.

> **강의의 결정적 조언 (우리 현 단계와 정확히 일치):**
> "신생 채널·사업 초기가 히어로를 찍어놓고 제작하는 건 위험하다. **허브·헬프를 만들며 구독자가 뭘 좋아하는지 살피고, 확신이 생기면 그때 히어로에 투자**하라."
> "검색으로 문제 해결하는 분야(세무·법률·IT툴)는 **헬프만 꾸준히 해도 매출로 이어진다.**"

## 우리 반영점

### ① 3H로 채널 운영 정리 (즉시 반영)

| 우리 콘텐츠 | 3H 유형 | 근거 |
|---|---|---|
| **교차 소싱 시리즈**(주1회) | **허브** | 정기 시리즈 = 구독자 유지. 방금 만든 게 정확히 허브 |
| 도구 사용법·용어·How-to | **헬프** | 검색 유입, 오래 쌓임. 유튜브 롱폼 상당수 |
| (아직 없음) | 히어로 | **강박 금지** — 사용자 0 신생이라 허브·헬프 먼저가 정석 |

> 우리 현 단계(사용자 0) 전략을 강의가 뒷받침한다: **히어로 없이 허브·헬프로 시작 → 반응 보고 히어로 투자.** 우리 도구는 검색 문제해결형(헬프 강함)이라 "헬프만 꾸준히 해도 매출" 케이스에 해당.

### ② 숫자 충격 제목 — 우리 원칙 안에서만

검색 상위가 전부 숫자 제목(월1000만·120억)이다. 조회는 견인하지만 **우리 원칙(과장·위로 금지)과 충돌**한다. "월1000만원" 같은 건 안 쓴다. 대신 **팩트 숫자**로: "누끼 20장 2시간 → 3분", "검색 6만9천·경쟁 여유" 같은 실측치. 충격 대신 신뢰.

### ③ 소싱 주제 = 조회 견인 확인

검색 상위·쇼츠·@maker39 전부 소싱이 핵심. 우리 교차 소싱 시리즈(허브)가 방향이 맞다. 쇼츠는 시연+숫자, 롱폼은 헬프(방법론)로.

### ④ 우리 우위 = 무가입·무설치 웹도구

@maker39는 exe 배포(설치·보안 부담). 우리는 브라우저 즉시 실행. 콘텐츠에서 이 차이를 후크로: "설치도 가입도 없이".
