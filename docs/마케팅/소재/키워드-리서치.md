## 판정 — 첫 10편은 한도제 계열로 몰아라

**"스마트스토어 상품등록 한도 2026"** 계열이 이 리스트에서 수요·공급 격차가 가장 크다.

1. 정책 시행이 **지난달(26.6)**인데 유튜브 공급이 2021년작 하나뿐
2. 한도제가 **대량등록 전략 전체를 무효화** → 기존 상위 영상들이 전부 낡은 정보가 됨
3. `판매상품비중 3%`·`그룹상품`·`상품 자동 정리` 등 파생 키워드가 전부 공백
4. [PLAN.md R-9](../../기획/PLAN.md)에서 이미 감시 대상으로 잡아둔 리스크 — **"선별 돕는 도구" 포지션과 정확히 맞물린다**

우리 도구(키워드 분석으로 팔릴 상품 선별, 원링크로 등록 시간 단축)가 한도제 시대의 해법이 된다. 소재와 제품이 같은 방향을 가리킨다.
