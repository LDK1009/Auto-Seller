## ① 10시 — 키워드 ⭐

**영상:** `26/숏츠/뭘 팔지 감 말고 숫자 보는 데 몇 초.mp4`

```
뭘 팔지 정할 때 감으로 고르면 도박이잖아요.

검색은 많이 되는데 등록된 상품은 적은 키워드,
그 비율을 숫자로 보여주는 거 만들었어요.

궁금한 스친은 좋아요 + 댓글에 "키워드" 남겨주세요!
```

**대댓글 준비**
- "무료인가요?" → "지금은 무료로 열어뒀어요. 가입도 없어서 바로 됩니다"
- "검색량은 어디서 가져와요?" → "네이버 데이터 기준이에요"

## ③ 21시 — 페인포인트 설문 ⭐ (제품 방향 결정용)

**영상 없음 — 설문 기능 사용**

```
상품 하나 등록하는 데 실제로 얼마나 걸리세요?

이미지 가공부터 등록 버튼까지 다 포함해서요.
```

**설문 옵션:** `10분 이내` / `30분쯤` / `1시간 이상` / `상품마다 달라요`

**대댓글 준비**
- "저는 ○○분이요" → "생각보다 오래 걸리시네요. 어느 단계가 제일 오래 걸리세요?"
