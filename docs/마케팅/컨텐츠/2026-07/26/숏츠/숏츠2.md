# [7/26 숏츠 2편차] 발행 18시 — 키워드 비교 실측

## 영상 제목

비슷한 키워드 둘, 어디로 들어가야 할까

> 시나리오: 26-2 (키워드 분석 — 키워드 2개 비교 조회 → 어느 쪽이 틈새인지 판정)

## 훅 (0~3초)

자막: **"비슷한 키워드 두 개 | **어디로 들어가야 할까요** | 타이머 켜고 재봤습니다"** — 스톱워치 스타트

## 시연 + 타이머 (3~22초)

1. 키워드 분석에 키워드 2개 순차 조회
2. 정차역 3곳 (키워드 A 결과·키워드 B 결과·비교 판정)

| 초 | 자막 |
|----|------|
| 3~8 | 비슷한 키워드 둘 다 조회할게요 |
| 8~13 | 첫 번째는 검색 많고 상품도 많죠 |
| 13~18 | 두 번째는 검색 대비 상품이 적어요 |
| 18~22 | 들어갈 곳은 숫자가 알려줘요 |

> 자막 규칙: 자막 4 = 정차역 3 + 1

## 결과 카드 (22~28초)

**"키워드 비교, [실측: mm:ss]"** → "링크는 프로필에 있어요" / "재보고 싶은 작업, 댓글로"

## 설명란 (네이버 클립·릴스·숏츠 공통 — 영상별 1줄 + 고정 꼬리말)

키워드 2종 비교 조회, 타이머 켜고 직접 재봤어요.

오토셀러는 도매꾹 링크 하나로 스마트스토어 등록 준비를 자동으로 해주는 무료 도구예요.
가입도 필요 없어요. 링크는 프로필에 있습니다.
