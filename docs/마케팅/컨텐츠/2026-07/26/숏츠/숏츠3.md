# [7/26 숏츠 3편차] 발행 21시 — 원링크 반려용품 실측

## 영상 제목

반려용품 팔아볼까, 등록 준비 몇 초

> 시나리오: 26-3 (원링크 풀 플로우 — 강아지급식기 검색)

## 훅 (0~3초)

자막: **"반려용품 팔아볼까 싶다면 | **등록 준비는 이만큼 걸려요** | 타이머 켜고 재봤습니다"** — 스톱워치 스타트

## 시연 + 타이머 (3~24초)

1. 원링크에 "강아지급식기" 검색 → 상품 선택 → 시트 생성
2. 정차역 4곳 (카테고리·상품명·판매가·검색설정)

| 초 | 자막 |
|----|------|
| 3~9 | 반려용품 하나 골라볼게요 |
| 9~13 | 카테고리 잡혀 있고요 |
| 13~17 | 상품명 검사 끝났어요 |
| 17~21 | 마진 계산도 돼 있네요 |
| 21~24 | 태그 복사하면 준비 끝 |

> 자막 규칙: 자막 5 = 정차역 4 + 1

## 결과 카드 (24~30초)

**"등록 준비, [실측: mm:ss]"** → "링크는 프로필에 있어요" / "재보고 싶은 작업, 댓글로"

## 설명란 (네이버 클립·릴스·숏츠 공통 — 영상별 1줄 + 고정 꼬리말)

반려용품 등록 준비, 타이머 켜고 직접 재봤어요.

오토셀러는 도매꾹 링크 하나로 스마트스토어 등록 준비를 자동으로 해주는 무료 도구예요.
가입도 필요 없어요. 링크는 프로필에 있습니다.
