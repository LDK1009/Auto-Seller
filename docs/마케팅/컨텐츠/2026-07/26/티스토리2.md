# [7/26 티스토리 2편차] 발행 19시 | 마크다운 그대로 붙여넣기

> **종류:** A 문제해결 — 워터마크 기능
> **요약:** 이미지 자산 보호 관점의 워터마크 전략과 일괄 적용법 (네이버판과 별도 원고)

## 제목

상품 이미지 도용 대처법 — 사후 신고보다 사전 워터마크

## 본문

동일 도매 상품을 여러 셀러가 파는 시장에서, 편집 품질이 좋은 이미지는 곧 복제 대상이 됩니다.
도용을 발견한 뒤의 대응(신고·요청)은 시간이 들고 결과도 불확실합니다.

비용 대비 효과가 가장 확실한 건 사전 조치입니다.


### 워터마크의 실제 효과 두 가지

1. **심리적 허들** — 지우는 수고가 드는 이미지는 애초에 복사 대상에서 밀립니다
2. **역광고** — 그대로 가져가면 내 스토어명이 남의 상세페이지에 노출됩니다


### 적용 원칙

- 위치: 상품 본체를 가리지 않는 모서리 또는 여백부
- 투명도: 시인성과 상품 가독성의 중간값 — 너무 진하면 이미지 품질을 해칩니다
- 일관성: 전 상품 동일 위치·동일 로고 — 브랜드 인지가 쌓입니다


### 일괄 처리 도구

장당 편집은 비현실적이므로 일괄 합성이 전제입니다.
텍스트/로고 선택 → 3×3 위치 지정 → 투명도 조절 → 여러 장 동시 적용 → 원본 포맷 유지 저장까지 한 흐름으로 처리되는 무료 도구가 있습니다.

배경 제거·규격 변환 결과물을 이어받아 바로 처리할 수 있어 이미지 파이프라인의 마무리 단계로 쓰기 좋습니다.

auto-seller.co.kr (무료, 회원가입 없음)

※ 공급사 원본에 대한 가공은 상품별 편집 허용 범위 확인이 먼저입니다.


### 도용을 발견했을 때의 대응 순서

[이미지: 워터마크 적용 완료 이미지]

사전 조치를 했어도 도용은 발생할 수 있습니다.
발견 시 순서:

1. **증거 확보** — 도용 페이지 캡처(URL·날짜 포함). 원본 제작 시점을 입증할 파일 원본도 보관
2. **판매자에게 직접 요청** — 의외로 "몰랐다, 내리겠다"로 끝나는 경우가 많습니다. 감정 빼고 사실만
3. **플랫폼 신고** — 응하지 않으면 마켓의 지재권 침해 신고 절차로. 워터마크가 박힌 원본은 이때 소유 입증 자료가 됩니다

워터마크의 마지막 역할이 여기 있습니다 — 분쟁 시 "내 것"임을 증명하는 표식. 예방·역광고에 더해 세 번째 보험입니다.


### 한 줄 정리

이미지 보호는 도용을 0으로 만드는 게 아니라, 도용의 기대 손실을 낮추고 대응 비용을 줄이는 게임입니다.
일괄 워터마크는 그 게임에서 가장 싼 수입니다.
