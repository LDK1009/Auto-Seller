## 본문

위탁판매처럼 같은 공급사를 쓰는 구조에서는 드물지 않은 일입니다.
사후 대응과 사전 예방을 나눠 정리합니다.

---

'먼저, 무엇이 도용인가'
공급사 원본을 서로 쓰는 건 도용이 아닙니다 (사용 허용 범위 내라면).
문제는 내가 가공한 결과물 — 배경 교체, 합성, 구성 편집한 이미지를 무단으로 가져가는 경우입니다.
가공물에는 내 작업이 들어가 있습니다.

'사후 대응 절차'
1. 증거 확보 — 상대 페이지 캡처, 게시 일자 기록
2. 원본 입증 준비 — 내 원본 파일·작업 파일의 생성 일시
3. 마켓 신고 — 각 마켓의 지식재산권 침해 신고 절차 이용
4. 공급사 확인 — 상대가 같은 공급사 원본을 쓴 건지 내 가공물을 쓴 건지 구분

사후 대응은 가능하지만, 시간이 들고 입증 부담이 내게 있습니다.

'사전 예방 — 워터마크'

- 가져가려는 쪽에서 편집 비용이 생겨 억제 효과
- 도용됐을 때 출처 입증이 즉시 가능
- 소비자에게는 스토어 식별 요소
