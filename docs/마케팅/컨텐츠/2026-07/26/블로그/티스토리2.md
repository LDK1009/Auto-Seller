## 제목
상품 이미지 도용, 신고보다 먼저 할 일 — 셀러의 이미지 보호 실무

## 본문
가공한 상품 이미지가 남의 스토어에 걸려 있는 걸 발견하면 화부터 납니다.
그런데 실무 순서는 감정과 반대로 가야 합니다.
신고는 마지막이고, 그 전에 할 일들이 있습니다.


### 구분부터 — 이게 도용인가
| 상황 | 판정 |
|------|------|
| 같은 공급사 원본을 서로 사용 | 도용 아님 (허용 범위 내) |
| 내가 배경 교체·합성한 가공물 사용 | 도용 |
| 내 워터마크가 지워지거나 잘린 채 사용 | 도용 + 고의성 정황 |

원본 공유 구조인 위탁판매에서는 이 구분이 먼저입니다.
가공물이어야 내 권리를 주장할 근거가 섭니다.


### 신고 전 준비물 3가지
1. **상대 페이지 증거** — 화면 캡처 + 게시 일자
2. **내 원본 파일** — 가공 작업 파일과 생성 일시 (원본 보관 습관이 여기서 빛납니다)
3. **선후 관계** — 내 게시일이 앞선다는 기록

이 셋이 갖춰져야 마켓 지식재산권 신고 절차가 굴러갑니다.


### 그런데, 더 좋은 방법
사후 입증은 이기더라도 피곤합니다.
실무자의 답은 가공 단계에서 워터마크를 박아두는 것입니다.

https://www.auto-seller.co.kr/marketing/watermark.png

- 도용자 입장에선 지우는 편집 비용 발생 → 애초에 안 가져감
- 도용당해도 출처가 이미지 안에 있음 → 입증 절차 단축
- 여러 장 일괄 처리라 작업 비용 거의 없음


### 가공 마지막 단계에 고정하기
배경 제거 → 규격 변환 → **워터마크** → 저장.
이미지 공정 마지막 칸에 워터마크를 고정해두면, 보호가 습관이 됩니다.
분쟁을 잘하는 셀러보다 분쟁이 안 생기는 셀러가 이깁니다.
