## 훅 (0~3초)

자막: **"공들인 사진 도용당하기 전에 — 워터마크 30장, 몇 초?"** — 스톱워치 스타트

## 시연 + 타이머 (3~24초)

1. 워터마크에 이미지 30장 업로드
2. 스토어명 텍스트 입력 → 3×3 위치·투명도 설정 (크롭 줌)
3. 일괄 합성 → 완성 그리드 → 저장 → ⏱ 정지

| 초 | 자막 |
|----|------|
| 3~9 | 스토어명 넣고 위치 정하면 |
| 9~15 | 30장에 한 번에 박힙니다 |
| 15~20 | 가져가면 내 광고가 되는 구조 |
| 20~24 | 원본 포맷 그대로 저장 |

## 결과 카드 (24~30초)
