# [7/26 숏츠 1편차] 발행 12시 — 키워드 분석 실측

> 시나리오: 26-1 (키워드 분석 — 키워드 입력 → 검색량·상품 수·경쟁강도 확인)

## 훅 (0~3초)

자막: **"뭘 팔지 감으로 정한다면 | **숫자 보는 데 몇 초인지 아세요?** | 타이머 켜고 재봤습니다"** — 스톱워치 스타트

## 시연 + 타이머 (3~22초)

1. 키워드 분석에 키워드 입력 → 조회
2. 정차역 3곳 (검색량·등록 상품 수·경쟁강도 판정)

| 초 | 자막 |
|----|------|
| 3~8 | 키워드 하나 넣어볼게요 |
| 8~13 | 월 검색량이 바로 나오고요 |
| 13~18 | 등록 상품 수도 같이 떠요 |
| 18~22 | 경쟁강도까지 판정해줘요 |

> 자막 규칙: 자막 4 = 정차역 3 + 1

## 결과 카드 (22~28초)

**"키워드 판정, [실측: mm:ss]"** → "링크는 프로필에 있어요" / "재보고 싶은 작업, 댓글로"
