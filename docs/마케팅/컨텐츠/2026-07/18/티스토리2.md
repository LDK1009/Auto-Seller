# [7/18 티스토리 2편차] 발행 19시 | 마크다운 그대로 붙여넣기

> **종류:** A 문제해결 — 도매꾹 검색 기능
> **요약:** 검색→필터→클릭 투입의 소싱 동선을 절차식으로 소개 (네이버판과 별도 원고)

## 제목

도매꾹 상품 찾는 시간 줄이기 — 검색·필터·원클릭 등록 준비 흐름

## 본문

위탁판매 소싱은 보통 이런 동선입니다: 도매 사이트 열기 → 검색 → 상품 비교 → URL 복사 → 등록 도구로 이동. 창을 오가는 사이 흐름이 끊깁니다.

이 왕복을 없앤 사용 흐름을 소개합니다.

### 1) 한 화면에서 검색

오토셀러 안의 도매꾹 검색 메뉴는 키워드 입력만으로 도매꾹 상품을 불러옵니다. 카테고리 탐색도 지원합니다.

### 2) 셀러 기준 필터

- 인기순: 실제 판매량 기준 정렬로 검증된 후보부터
- 가격대: 목표 원가 범위 지정
- 낱개 구매: 최소구매수량 조건 없는 상품만 — 묶음 계산이 부담스러운 초보에게 유용

### 3) 클릭 = 파이프라인 투입

상품 카드를 누르는 순간 해당 상품이 등록 준비 흐름으로 넘어갑니다. 이미지 사용 가능 여부 자동 확인을 거쳐, 분류·이름·가격·옵션·태그가 채워진 시트가 생성됩니다.

### 활용 팁

키워드 분석 기능에서 수요·경쟁 데이터를 먼저 확인하고, 그 키워드로 도매꾹 검색을 여는 순서를 추천합니다. "데이터로 고르고, 클릭으로 등록 준비"가 되면 소싱 밤샘이 사라집니다.
