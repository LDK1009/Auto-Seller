# [7/18 티스토리 2편차] 발행 19시 | 마크다운 그대로 붙여넣기

> **종류:** A 문제해결 — 도매꾹 검색 기능
> **요약:** 검색→필터→클릭 투입의 소싱 동선을 절차식으로 소개 (네이버판과 별도 원고)

## 제목

도매꾹 상품 찾는 시간 줄이기 — 검색·필터·원클릭 등록 준비 흐름

## 본문

위탁판매 소싱은 보통 이런 동선입니다: 도매 사이트 열기 → 검색 → 상품 비교 → URL 복사 → 등록 도구로 이동. 창을 오가는 사이 흐름이 끊깁니다.

이 왕복을 없앤 사용 흐름을 소개합니다.

### 1) 한 화면에서 검색

오토셀러 안의 도매꾹 검색 메뉴는 키워드 입력만으로 도매꾹 상품을 불러옵니다. 카테고리 탐색도 지원합니다.

### 2) 셀러 기준 필터

- 인기순: 실제 판매량 기준 정렬로 검증된 후보부터
- 가격대: 목표 원가 범위 지정
- 낱개 구매: 최소구매수량 조건 없는 상품만 — 묶음 계산이 부담스러운 초보에게 유용

### 3) 클릭 = 파이프라인 투입

상품 카드를 누르는 순간 해당 상품이 등록 준비 흐름으로 넘어갑니다. 이미지 사용 가능 여부 자동 확인을 거쳐, 분류·이름·가격·옵션·태그가 채워진 시트가 생성됩니다.

### 활용 팁

키워드 분석 기능에서 수요·경쟁 데이터를 먼저 확인하고, 그 키워드로 도매꾹 검색을 여는 순서를 추천합니다. "데이터로 고르고, 클릭으로 등록 준비"가 되면 소싱 밤샘이 사라집니다.

auto-seller.co.kr (무료, 회원가입 없음)

### 검색으로 소싱할 때의 사고 순서

[이미지: 검색 결과 → 상품 카드 → 등록 시트 흐름]

도구가 있어도 판단 순서는 사람 몫입니다. 검색 결과 앞에서 이 순서로 보면 시간이 절약됩니다.

1. **인기순 상위 = 검증된 수요, 그러나 경쟁도 검증됨** — 상위 상품은 이미 파는 셀러가 많다는 뜻이기도 합니다. 그대로 팔지 말고 "이 수요의 파생 니즈"를 찾는 재료로 쓰세요
2. **가격대는 내 마진 공식에서 역산** — 목표 마진율과 예상 판매가에서 허용 원가 상한을 먼저 구하고, 그 구간만 필터링합니다
3. **낱개 가능 여부는 초기에만 필터** — 익숙해지면 MOQ 상품의 묶음 구성이 오히려 차별화 수단이 됩니다 (낱개 셀러들과 구성이 달라지므로)

### 정리

소싱의 병목은 "찾는 시간"이 아니라 "찾고 나서 검증하는 시간"입니다. 검색→확인→등록 준비가 한 화면에서 이어지면 검증 비용이 내려가고, 그만큼 더 많은 후보를 볼 수 있습니다. 후보를 많이 보는 셀러가 결국 좋은 상품을 먼저 찾습니다.
