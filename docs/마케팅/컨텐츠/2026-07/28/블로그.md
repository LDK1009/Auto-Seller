## 1단계 — 월간 검색수 확인

이 상품을 사려는 사람이 검색할 단어의 월간 검색수를 봅니다.
검색수가 거의 없으면 수요가 없다는 뜻이고, 수만 단위면 수요는 충분하되 경쟁을 봐야 합니다.

## 2단계 — 등록 상품 수와 비교

같은 키워드로 등록된 상품 수를 봅니다. 핵심은 비율입니다:

```
월간 검색수 ÷ 등록 상품 수 = 틈새 지수
```

검색은 많은데 상품이 적으면 → 수요 대비 공급 부족 = 진입 기회.
검색도 많고 상품도 수십만이면 → 신규 진입 어려움.

## 3단계 — 12개월 트렌드와 시즌성

지금 검색량이 좋아도 하강 추세면 늦은 겁니다.
- 우상향 키워드: 지금 진입해도 성장분을 먹습니다
- 시즌 키워드: 성수기 2~3개월 전이 등록 적기입니다

## 4단계 — 상위 장악도 확인

검색 결과 상위가 브랜드·대형 셀러 판이면 숫자가 좋아도 초보 자리는 없습니다.
상위가 일반 셀러들이면 등록 품질로 겨뤄볼 수 있는 시장입니다.
