# [7/28 티스토리] 발행 9시 | 마크다운 그대로 붙여넣기
## 제목
네이버 키워드 검색량 조회하고 해석하는 법 — 셀러용 4단계 체크

## 본문
검색량 조회는 배우기 쉽습니다.
어려운 건 해석 — 숫자를 보고 "그래서 팔까 말까"를 정하는 부분입니다.
조회와 해석을 묶은 4단계 체크를 정리합니다.


### 체크 1 — 검색량: 수요의 존재 확인
키워드를 넣고 월 검색량부터 봅니다.

https://www.auto-seller.co.kr/marketing/keyword-stats.png

해석 기준:

- 사실상 0 → 무인도. 후보 폐기
- 적당히 있음 → 다음 체크로
- 매우 큼 → 좋아 보이지만 대형 셀러 전장일 가능성. 다음 체크가 더 중요


### 체크 2 — 상품 수: 공급의 밀도 확인
같은 키워드의 등록 상품 수를 봅니다.
검색량과의 비율(경쟁강도)이 판단값입니다.

| 경쟁강도 | 해석 |
|----------|------|
| 낮음 | 수요 대비 공급 부족 — 진입 유리 |
| 높음 | 공급 과잉 — 키워드를 좁혀 재조회 |


### 체크 3 — 시즌성: 숫자의 시점 확인
지금 검색량이 연중 어느 구간인지 생각합니다.
여름 상품을 겨울에 조회하면 낮게 나오는 게 당연합니다.
시즌 상품은 "수요가 오르기 직전"이 진입 적기 — 오른 뒤엔 이미 늦습니다.


### 체크 4 — 마진: 숫자에서 돈으로
키워드가 통과해도 상품 계산이 안 서면 의미가 없습니다.
후보 상품 링크를 등록 준비 도구에 넣어 수수료·배송비 반영 마진을 확인합니다.

https://www.auto-seller.co.kr/marketing/domeggook-import-sheet-kitchen.png


### 4단계를 습관으로
```
검색량(수요) → 상품 수(공급) → 시즌성(시점) → 마진(돈)
```

후보당 몇 분이면 도는 체크입니다.
이 네 관문을 통과한 상품만 올린다는 원칙 하나로, 실패의 대부분이 등록 전에 걸러집니다.
