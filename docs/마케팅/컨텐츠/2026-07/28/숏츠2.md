# [7/28 숏츠 2편차] 발행 18시 — 태그 완성 실측 (검색설정 중심)

> 시나리오: 28-2 (원링크 — 검색설정(태그 후보) 정차 중심, 문구류 검색어)

## 훅 (0~3초)

자막: **"태그 10칸 뭘로 채우지 | **고르기만 하면 됩니다** | 타이머 켜고 재봤습니다"** — 스톱워치 스타트

## 시연 + 타이머 (3~22초)

1. 원링크에 "차량용거치대" 검색 → 상품 선택 → 시트 생성
2. 정차역 3곳 (태그 후보(검색량 표시)·태그 복사 버튼·완료)

| 초 | 자막 |
|----|------|
| 3~9 | 상품 하나 불러올게요 |
| 9~14 | 태그 후보에 검색량이 붙어 있죠 |
| 14~18 | 통째로 복사하면 |
| 18~22 | 등록 폼에 붙여넣기만 하면 돼요 |

> 자막 규칙: 자막 4 = 정차역 3 + 1

## 결과 카드 (22~28초)

**"태그 완성, [실측: mm:ss]"** → "링크는 프로필에 있어요" / "재보고 싶은 작업, 댓글로"
