# [7/28 블로그 3편차] 발행 20시
## 제목
숫자를 보기 시작하고 달라진 것들 — 감으로 팔던 시절과의 결별

## 본문
부업 초기의 저는 "느낌 좋은 상품"을 올렸습니다.
지금은 "숫자가 맞는 상품"을 올립니다.
그 사이에 무엇이 달라졌는지 기록해봅니다.

---

'감으로 팔던 시절의 패턴'
도매 사이트를 구경하다 "오, 이거 괜찮은데"가 오면 등록했습니다.
근거는 내 취향이었고, 결과는 조용했습니다.
문제는 실패에서 배울 게 없다는 것 — 왜 안 팔렸는지 알 수가 없으니 다음에도 같은 방식이었습니다.

'숫자를 보기 시작한 계기'
우연히 키워드 검색량이라는 걸 조회해봤습니다.
제가 올린 상품의 핵심 키워드 — 월 검색량이 거의 없었습니다.
안 팔린 게 아니라, 팔릴 기회 자체가 없었던 겁니다.

https://www.auto-seller.co.kr/marketing/keyword-stats.png

'달라진 것 1 — 실패에 이유가 생겼다'
지금은 안 팔리면 원인을 좁힐 수 있습니다.
수요가 없었나(검색량), 경쟁에 밀렸나(상품 수), 가격이 안 맞았나(마진 계산).
원인이 보이면 다음 시도가 달라집니다. 실패가 수업이 됩니다.

'달라진 것 2 — 등록 전에 거른다'
느낌 오는 상품이 생기면 등록 대신 조회부터 합니다.
검색량 → 경쟁강도 → 마진 계산.
세 관문을 통과 못 하면 미련 없이 다음 후보로.

https://www.auto-seller.co.kr/marketing/domeggook-import-sheet-price-kitchen.png

등록하는 상품 수는 줄었는데, 등록하는 이유는 분명해졌습니다.

'달라진 것 3 — 불안이 줄었다'
감으로 팔 때의 불안은 "내가 뭘 모르는지 모른다"에서 왔습니다.
숫자를 보면 모르는 게 명확해집니다.
모르는 게 명확하면 조회하면 되고, 조회는 몇 초면 됩니다.

---

'감의 재정의'
숫자를 본다고 감이 필요 없어지는 게 아니었습니다.
숫자를 오래 보면 그게 감이 됩니다 — 조회 전에 경쟁강도가 대충 맞아떨어지기 시작합니다.
감은 타고나는 게 아니라 데이터가 쌓여 생기는 것이었습니다.
