# [7/28 쓰레드] 5개 — 10·12·15·19·22시

## ① 10시 — 블로그 분해 · 연작 (1/4)

**본문 (훅):**
아이템 선정, 감으로 하면 실패에서 배울 게 없어요.
왜 안 팔렸는지 모르니까.
데이터 4단계로 바꾸는 법 정리했습니다. (스레드로 이어집니다)

**댓글 1:**
1단계 수집(판단 없이 후보만) → 2단계 검색량(수요 확인)
→ 3단계 경쟁강도(공급 확인) → 4단계 마진(돈 확인).
각 관문에서 실패 원인 하나씩이 걸러져요.

**댓글 2:**
이 절차의 가치는 좋은 상품 발견이 아니라
나쁜 상품 차단이에요.
수요 없음·공급 과잉·손해 구조 — 등록 전에 셋 다 거릅니다.

**댓글 3 (CTA):**
후보당 몇 분이면 도는 체크예요.
단계별 화면이랑 도구는 프로필 링크에.

**설문 항목:** 내 취향 / 검색량 숫자 / 도매 인기순 / 마진 계산

**댓글 (팁):**

취향이 마지막이면 무기가 되고, 처음이면 도박이 됩니다.
