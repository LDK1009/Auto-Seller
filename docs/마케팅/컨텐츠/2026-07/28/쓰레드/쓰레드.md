## ① 10시 — 감정 · 뭘 팔지

```
스토어는 열어놨는데, 정작 뭘 올려야 할지부터 막히더라고요.
그러다 보니 벌써 일주일째 상품 하나를 제대로 못 올리고 있어요.

이게 팔릴 만한 건지 감이 안 오니까, 자꾸 망설이게 되고요.
남들 파는 걸 따라 올리자니 경쟁만 치일 것 같고.

혹시 다들 이 구간은 어떻게 넘기셨는지 궁금해요.
```

**댓글 오면** → 공감 + "저는 검색량이랑 상품 수 비교해서 정하는 편이에요" (도구 자연 언급)

---

## ② 15시 — 꿀팁 · 세부키워드 ⭐금맥

```
🗣️ 상품 올렸는데 조회수가 계속 0이에요
👤 혹시 상품명, 도매처에서 준 그대로 쓰셨어요?
🗣️ 네 그냥 "캠핑의자"라고 했는데…

<올려도 노출이 안 되는 진짜 이유>
1. "캠핑의자"는 리뷰 수천 개짜리 대형 키워드예요
2. 신규 셀러는 여기서 노출될 기회가 거의 없어요
3. "야외 폴딩체어"처럼 세부 키워드로 쪼개보세요
👉 검색은 되면서 경쟁이 덜한 세부 키워드가 답이더라고요

세부 키워드 검색량이랑 경쟁을 한 번에 보는 거, 프로필에 걸어뒀어요.
```

**댓글 오면** → "어떤 상품이세요? 세부 키워드 몇 개 같이 찾아볼게요" (대화 이어가기)

---

## ③ 21시 — 댓글유도 · 번아웃 — 📎영상 nukki-basic.mp4 · 유도어 "누끼"

```
상품 스무 개쯤 올리려다가, 누끼 따는 것만 두 시간 걸린 적 있으시죠.
포토샵으로 하나씩 만지다 보면 어느새 새벽이고요.

여러 장을 한 번에 배경 빼는 걸 만들어뒀어요.
필요하신 분은 댓글에 "누끼"라고 남겨주시면 알려드릴게요.
```

**댓글 오면** → "누끼" 남긴 분께 프로필 링크 안내 + "몇 장 정도 하세요?"
