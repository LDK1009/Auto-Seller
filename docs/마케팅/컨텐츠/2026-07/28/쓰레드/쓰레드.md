# 7/28 쓰레드 — 댓글 유도형 3개

발행: 10시 · 15시 · 21시

---

## ① 10시 — 태그

**영상:** `28/숏츠/태그 10칸 뭘로 채우지, 고르기만 하면 끝.mp4`

```
검색설정 태그 10칸, 뭘로 채우세요?

상품명에 이미 들어간 단어는 빼고,
검색되는 것만 골라서 후보로 뽑아줍니다.

궁금한 스친은 좋아요 + 댓글에 "태그" 남겨주세요!
```

**대댓글 준비**
- "중복은 어떻게 알아요?" → "상품명이랑 겹치는 건 자동으로 제외돼요"

## ② 15시 — 부가세

**영상:** `28/숏츠/부가세 신고 전 얼마 나올지 미리 확인.mp4`

```
부가세 신고 전에 얼마 나올지 몰라서
막판에 당황한 적 있으신가요?

매출·매입만 넣으면 예상액이 나오게 만들었어요.
간이/일반 유형별로요.

궁금한 스친은 좋아요 + 댓글에 "부가세" 남겨주세요!
```

## ③ 21시 — 선별 (한도제 연결)

**영상:** `28/숏츠/감으로 고르면 도박, 숫자로 고르면 절차.mp4`

```
6월에 등록 한도 바뀌면서
많이 올리는 전략이 막혔잖아요.

이제 몇 개를 올리냐보다 뭘 올리냐가 중요해진 것 같은데,
다들 어떻게 고르세요?

궁금한 스친은 좋아요 + 댓글에 "선별" 남겨주세요!
```
