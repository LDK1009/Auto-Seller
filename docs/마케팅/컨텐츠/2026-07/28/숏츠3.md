# [7/28 숏츠 3편차] 발행 21시 — 부가세 계산 실측

> 시나리오: 28-3 (부가세 계산기 — 매출·매입 입력 → 예상 부가세)

## 훅 (0~3초)

자막: **"부가세 신고 전에 | **얼마 나올지 미리 아세요** | 타이머 켜고 재봤습니다"** — 스톱워치 스타트

## 시연 + 타이머 (3~22초)

1. 부가세 계산기 진입 → 매출·매입 입력
2. 정차역 3곳 (과세유형 선택·입력값·예상 세액)

| 초 | 자막 |
|----|------|
| 3~8 | 과세유형부터 고를게요 |
| 8~13 | 매출이랑 매입 넣으면 |
| 13~18 | 계산이 바로 돌아가고요 |
| 18~22 | 예상 부가세가 나왔어요 |

> 자막 규칙: 자막 4 = 정차역 3 + 1

## 결과 카드 (22~28초)

**"부가세 계산, [실측: mm:ss]"** → "링크는 프로필에 있어요" / "재보고 싶은 작업, 댓글로"
