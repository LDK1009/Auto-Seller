## 제목

스마트스토어 태그 제대로 쓰는 법 — 유효 태그와 무효 태그의 차이

## 본문

태그는 검색 유입의 보조 통로입니다. 그런데 10개를 다 채우고도 통로가 0개인 경우가 흔합니다. 무효 태그로 채웠기 때문입니다.

### 무효가 되는 3가지 패턴

**패턴 1 — 상품명 재탕.** 검색 시스템은 상품명과 겹치는 태그를 중복으로 보고 반영하지 않습니다. "캠핑 랜턴"이 상품명에 있는데 태그에도 넣으면 그 칸은 낭비입니다.

**패턴 2 — 무관 키워드 편승.** 상품과 상관없는 트렌드 단어는 유입돼도 이탈하고, 심하면 어뷰징 판정 리스크만 남습니다.

**패턴 3 — 죽은 키워드.** 아무도 검색하지 않는 단어는 통로 자체가 없습니다.

### 유효 태그 설계 = 상품명과의 분업

상품명에는 핵심 검색어를, 태그에는 상품명에 못 넣은 보조 검색어(파생어·용도어·시즌어)를 배치합니다. 둘이 서로 다른 검색어를 커버할 때 총 노출 면적이 최대가 됩니다.

### 자동 생성 도구의 처리 순서

1. 공급사 키워드와 상품명에서 후보 추출
2. 상품명 중복 키워드 제거 (패턴 1 차단)
3. 홍보성 단어 필터 (패턴 2 방지)
4. 검색량 확인 뱃지 제공 (패턴 3 검증)
5. 10개 확정 후 콤마 복사

### 태그와 상품명의 분업 설계 예시

충전식 미니 랜턴을 예로 실제 분업을 짜보면:

- **상품명이 가져가는 검색어**: 캠핑 랜턴, 미니 랜턴, 충전식 랜턴 (핵심 수요)
- **태그가 가져가는 검색어**: 차박 조명, 백패킹 랜턴, 감성 캠핑 소품, 텐트 조명, 낚시 랜턴, 정전 대비 (파생·용도 수요)

이렇게 나누면 하나의 상품이 10개 이상의 서로 다른 검색어에 노출 후보가 됩니다. 상품명에 다 욱여넣으면 가독성이 깨지고, 태그에 중복하면 무효 — 분업만이 노출 면적을 온전히 씁니다.

### 마지막 확인 — 태그의 검색량

기껏 분업해도 아무도 안 치는 단어면 통로가 아닙니다. 태그 후보마다 실제 검색량을 확인하는 습관까지가 태그 설계의 완성입니다. 검색량 확인 뱃지가 붙은 후보 목록이면 이 확인이 클릭 한 번입니다.
