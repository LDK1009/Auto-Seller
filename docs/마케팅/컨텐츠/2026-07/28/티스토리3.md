# [7/28 티스토리 3편차] 발행 19시 | 마크다운 그대로 붙여넣기
## 제목
취향으로 고르던 상품을 숫자로 고르게 되기까지

## 본문
셀러 초기, 제 소싱 기준은 "내가 사고 싶은가"였습니다.
지금 기준은 "숫자가 맞는가"입니다.
전환의 과정에서 배운 것들을 남깁니다.


### 취향 소싱의 문제 — 표본이 1이다
내가 사고 싶은 상품이 팔릴 거라는 가정은, 표본 1(나)의 시장조사입니다.
내 취향이 대중 수요와 겹치면 운이 좋은 거고, 아니면 조용한 스토어가 됩니다.
문제는 어느 쪽인지 팔아보기 전엔 모른다는 것.


### 전환점 — 검색량이라는 표본
키워드 검색량은 표본 수만 명짜리 시장조사입니다.
"이 단어를 한 달에 몇 명이 찾는가"는 취향이 아니라 집계입니다.

https://www.auto-seller.co.kr/marketing/keyword-stats.png

처음 조회해본 날, 제 취향 상품의 키워드 검색량이 바닥이라는 걸 봤습니다.
안 팔린 이유가 상품이 아니라 수요 부재였다는 걸 그때 알았습니다.


### 지금의 소싱 순서
1. 후보 키워드 검색량 조회 — 수요 확인
2. 등록 상품 수 대비 — 경쟁 확인
3. 도매 상품 링크로 마진 확인 — 돈 확인
4. 셋 다 통과하면 그때 취향 개입 — 같은 조건이면 내가 아는 카테고리

https://www.auto-seller.co.kr/marketing/domeggook-import-sheet-living.png

취향을 버린 게 아니라 순서를 뒤로 보냈습니다.
취향은 마지막 타이브레이커로는 유용합니다 — 아는 만큼 상세 설명이 좋아지니까요.


### 숫자 소싱이 준 뜻밖의 것
실패해도 덜 아픕니다.
근거를 갖고 들어간 실패는 원인 분석이 되고, 다음 판의 데이터가 됩니다.
취향으로 들어간 실패는 자존심만 다칩니다.


### 마무리
"사고 싶은 것"을 파는 게 아니라 "찾고 있는 것"을 파는 것.
그 한 줄의 전환이 소싱의 전부였습니다.
