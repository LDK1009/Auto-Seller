# 쓰레드 댓글 유도 세트 (2026-07-23 신설)

> **형식 전환.** 인사이트·교훈형 원고는 반응 0이었고(예약발행 전량), 대표가 즉흥으로 쓴 **질문형**이 20배 이겼다.
> 경쟁 채널(@bulsaja_, 7/7 시작 → 보름 만에 594댓글) 패턴을 우리 자산에 적용한다.

## 공식

```
① 문제 한 줄 (셀러가 겪는 상황)
② 해결 장면 = 영상 첨부 (필수)
③ "궁금한 스친은 좋아요 + 댓글에 '○○' 남겨주세요"
```

**댓글 = 리드.** 조회수는 누가 봤는지 모르지만 댓글·좋아요는 계정이 남아 DM으로 이어진다.
**대댓글로 댓글 수를 늘린다** — 알고리즘 신호이자 "뭐길래 이렇게 많나" 클릭 유인.

## 운영 규칙

- 유도어는 **한 단어**, 복붙 가능하게 (문장 요구 금지 — 진입장벽)
- 본문에 링크 금지, 프로필 링크로 유도
- 댓글 오면 **전부 답장** (대댓글이 도달을 만든다)
- 답장에 "DM 드릴게요" 또는 링크 안내 → 리드 전환
- 같은 유도어를 2주 내 반복하지 않는다
