# [7/19 티스토리 2편차] 발행 19시 | 마크다운 그대로 붙여넣기

> **종류:** A 문제해결 — 이미지 도구 4종 파이프라인
> **요약:** 반려 없는 등록용 이미지 만들기 절차 — 규격·검사·워터마크·분할 (네이버판과 별도 원고)

## 제목

쇼핑몰 이미지 반려 안 당하는 법 — 등록 전 이미지 처리 4단계

## 본문

이미지 때문에 상품 등록이 반려되면 다시 편집하고 다시 올려야 합니다. 반려 사유는 대부분 규격·용량·비율 위반 — 사전에 거를 수 있는 것들입니다.

등록 전 이미지 처리를 4단계 파이프라인으로 정리합니다.

### 1단계 — 규격 통일

마켓마다 대표이미지 권장 규격이 있습니다(정사각 1000×1000이 표준). 프리셋 선택으로 여러 장을 한 번에 변환하고, 여백·크롭 옵션으로 구도를 다듬습니다.

### 2단계 — 규정 사전 검사

업로드 전에 해상도·비율·파일 용량을 마켓 기준과 대조합니다. 통과 못 한 파일만 골라 규격 변환으로 되돌리는 식으로, 반려를 등록 전에 소진합니다.

### 3단계 — 워터마크로 도용 방지

배경까지 갈아 끼운 편집본은 다른 판매자가 복사해 가기 좋은 표적입니다. 로고나 스토어명을 일괄 합성해두면 가져가도 광고가 됩니다.

### 4단계 — 상세 이미지 분할

에디터에는 이미지 높이 제한이 있어 긴 상세 원본은 그대로 안 올라갑니다. 높이 프리셋으로 자동 분할하면 번호가 붙은 조각들이 ZIP으로 떨어집니다.

### 핵심은 "이어달리기"

이 4단계가 한 사이트 안에서 결과물을 서로 넘겨받는 구조면, 파일을 내려받고 다시 올리는 반복이 사라집니다. 무료·무설치로 제공되는 도구: auto-seller.co.kr (회원가입 없음)

### 파이프라인 순서를 지키면 좋은 이유

[이미지: 도구 간 핸드오프 화면]

4단계의 순서 자체에 논리가 있습니다. 규격을 먼저 맞춰야 검사를 통과하고, 검사를 통과한 최종본에 워터마크를 박아야 재작업이 없으며, 분할은 항상 마지막입니다(분할 후 수정하면 조각 전부를 다시 만들어야 하므로).

순서를 어기면 생기는 대표적 재작업: 워터마크를 먼저 박고 규격 변환 → 워터마크 위치·비율이 틀어져 처음부터 다시. 분할 후 오탈자 발견 → 병합본 수정 후 재분할. 도구가 순서대로 이어져 있으면 이런 역주행이 구조적으로 안 생깁니다.

### 소요 시간 감각

상품 1개(대표 1장 + 추가 5장 + 상세 1본) 기준으로 4단계 전체가 10분 안쪽입니다. 수작업 대비 절감분은 장수에 비례해 커지므로, 등록 수를 늘릴 계획일수록 파이프라인 정착이 먼저입니다.
