> **요약:** 키워드 입력→검색수·상품수·틈새 판정→도매꾹 소싱 연결까지 실측

## 훅 (0~3초)

자막: **"뭘 팔지 정하는 데 몇 초 걸리나 재봤습니다"** — 스톱워치 스타트

## 시연 + 타이머 (3~24초)

1. 키워드 분석에 키워드 입력
2. 검색수·상품수·틈새 판정 등장 (크롭 줌)
3. 12개월 트렌드 차트 확인
4. [도매꾹에서 찾기] → 상품 후보 등장 → ⏱ 정지

| 초 | 자막 |
|----|------|
| 3~9 | 키워드 하나 넣으면 |
| 9~15 | 검색수 대비 파는 사람 수 — 틈새 판정 |
| 15~20 | 오르는 키워드인지까지 확인 |
| 20~24 | 바로 도매꾹에서 소싱 |

## 결과 카드 (24~30초)

**"아이템 판정, [실측: mm:ss]"** → "무료·무가입 — 오토셀러" / "재볼 키워드, 댓글로"
