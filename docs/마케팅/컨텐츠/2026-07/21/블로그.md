# [7/21 블로그] 발행 10~11시
## 제목
상품 사진 배경제거(누끼), 무료로 수십 장 한 번에 처리하는 법

## 본문
상품 등록에서 시간을 제일 잡아먹는 건 이미지 작업, 그중에서도 배경 제거입니다.
포토샵으로 한 장씩 따면 장당 몇 분 — 수십 장이면 저녁이 사라집니다.

무료로, 설치 없이, 대량으로 처리하는 방법을 정리합니다.

---

### 배경 제거가 필요한 이유
- 대표이미지는 깔끔한 단색 배경이 클릭률에 유리합니다
- 공급사 원본에는 다른 셀러도 같은 이미지를 씁니다 — **배경만 바꿔도 차별화**됩니다
- 마켓 규정(권장 규격·흰 배경)에 맞추기도 쉬워집니다

---

### 무료 대량 처리 방법 (설치 없음)
1. https://www.auto-seller.co.kr/ 접속 → 누끼 메뉴
2. 상품 이미지를 한 번에 올립니다 (여러 장 동시)
3. 자동으로 배경이 제거됩니다 — 진행률이 보이고 중간 취소도 됩니다
4. 배경을 원하는 색·패턴·검색 이미지로 교체할 수 있습니다
5. 완성본을 ZIP으로 한 번에 내려받습니다

### 알아두면 좋은 것
- **이미지는 서버로 전송되지 않습니다** — 브라우저 안에서만 처리돼 상품 이미지 유출 걱정이 없습니다
- 배경 제거 후 규격 맞추기로 넘기면 1000×1000 등 마켓 규격 변환까지 이어집니다
- 도매꾹 상품이라면 링크만 넣어도 이미지 수집→배경 제거까지 자동입니다 (원링크)

### 배경 선택 실전 팁 — 뭘로 갈아 끼울까
배경 제거 다음 고민은 "그래서 무슨 배경"입니다.

- **대표이미지 = 흰색 or 밝은 단색** — 검색 목록에서 상품이 도드라지는 기본값
- **감성 카테고리(리빙·인테리어) = 패턴·질감** — 단색보다 사용 맥락이 연상되는 배경이 클릭에 유리
- **시즌 상품 = 검색 이미지 배경** — 캠핑용품 뒤에 숲, 여름용품 뒤에 물가. 배경 검색 기능으로 바로 찾아 합성

### 결과물이 어색할 때 점검 2가지
경계선이 지저분하면 원본 해상도가 너무 낮은 경우가 대부분입니다 — 더 큰 원본으로 다시.
상품이 배경에 묻히면 배경 밝기를 상품과 반대로(어두운 상품엔 밝은 배경).
이 두 개만 잡아도 결과물이 달라집니다.
