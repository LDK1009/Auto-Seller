# [7/21 숏츠 2편차] 발행 18시 — 도매꾹 인기순 소싱 실측

## 영상 제목

뭘 팔지 모를 때 팔리는 순서로 찾는 법

> 시나리오: 21-2 (도매꾹 검색 — 키워드 검색 → 인기순 결과 → 상품 조건 확인)

## 훅 (0~3초)

자막: **"뭘 팔지 모르겠다면 | **팔리는 순서로 보면 됩니다** | 타이머 켜고 재봤습니다"** — 스톱워치 스타트

## 시연 + 타이머 (3~22초)

1. 도매꾹 검색에 키워드 입력 → 인기순 결과
2. 정차역 3곳 (인기순 목록·상품 조건(MOQ·배송비)·이미지 사용 여부)

| 초 | 자막 |
|----|------|
| 3~8 | 키워드 하나만 검색할게요 |
| 8~13 | 지금 팔리는 순서로 나와요 |
| 13~18 | 최소수량이랑 배송비 보이고요 |
| 18~22 | 낱개 구매 필터도 걸 수 있어요 |

> 자막 규칙: 자막 4 = 정차역 3 + 1

## 결과 카드 (22~28초)

**"소싱 후보 찾기, [실측: mm:ss]"** → "링크는 프로필에 있어요" / "재보고 싶은 작업, 댓글로"

## 설명란 (네이버 클립·릴스·숏츠 공통 — 영상별 1줄 + 고정 꼬리말)

도매꾹 인기순 소싱, 타이머 켜고 직접 재봤어요.

오토셀러는 도매꾹 링크 하나로 스마트스토어 등록 준비를 자동으로 해주는 무료 도구예요.
