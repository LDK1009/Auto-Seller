# [7/21 숏츠 1편차] 발행 12시 — 누끼 일괄 처리 실측

## 영상 제목

상품 사진 배경 제거, 여러 장 한 번에 몇 초

> 시나리오: 21-1 (배경 제거 — 이미지 여러 장 업로드 → 일괄 처리 → 완료)

## 훅 (0~3초)

자막: **"상품 사진 배경 제거 | **한 장씩 따던 시절은 끝** | 타이머 켜고 재봤습니다"** — 스톱워치 스타트

## 시연 + 타이머 (3~24초)

1. 누끼 도구에 이미지 여러 장 업로드
2. 정차역 3곳 (진행률·완료 결과·ZIP 저장)

| 초 | 자막 |
|----|------|
| 3~9 | 이미지 한꺼번에 올릴게요 |
| 9~15 | 배경이 알아서 빠지고 있어요 |
| 15~20 | 전부 처리됐어요 |
| 20~24 | ZIP으로 한 번에 받으면 끝 |

> 자막 규칙: 자막 4 = 정차역 3 + 1

## 결과 카드 (24~30초)

**"배경 제거, [실측: mm:ss]"** → "링크는 프로필에 있어요" / "재보고 싶은 작업, 댓글로"

## 설명란 (네이버 클립·릴스·숏츠 공통 — 영상별 1줄 + 고정 꼬리말)

상품 사진 배경 일괄 제거, 타이머 켜고 직접 재봤어요.

오토셀러는 도매꾹 링크 하나로 스마트스토어 등록 준비를 자동으로 해주는 무료 도구예요.
가입도 필요 없어요. 링크는 프로필에 있습니다.
