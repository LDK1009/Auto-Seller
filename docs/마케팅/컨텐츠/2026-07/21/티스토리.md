# [7/21 티스토리] C② 가이드 | 발행 14~15시 | ⚠️ 네이버판과 문장 중복 금지 원칙으로 재작성됨

## 제목

포토샵 없이 상품 이미지 배경 지우기 — 여러 장 일괄 처리 가이드

## 본문

쇼핑몰 대표이미지의 기본은 깔끔한 배경입니다. 문제는 작업량입니다. 편집 프로그램으로 한 장씩 오려내면 상품 몇 개만 등록해도 밤이 샙니다.

브라우저에서 여러 장을 동시에 처리하는 방법을 단계별로 정리합니다.

### 왜 배경을 정리해야 하나

- 목록 화면에서 시선을 잡는 건 정돈된 이미지입니다
- 도매처 원본 사진은 경쟁 셀러들과 겹칩니다. 배경 교체만으로도 구분됩니다
- 마켓이 요구하는 규격(정사각·흰 배경)을 맞추기 쉬워집니다

### 처리 순서

1. auto-seller.co.kr의 누끼 메뉴를 엽니다 (설치·가입 불필요)
2. 이미지 여러 장을 드래그해서 한꺼번에 올립니다
3. 진행률을 보며 기다리면 전체 배경이 자동 제거됩니다
4. 필요하면 단색·패턴·검색 이미지로 배경을 갈아끼웁니다
5. 결과물 전체를 ZIP 파일로 저장합니다

이후 규격 변환 메뉴로 넘기면 1000×1000 같은 마켓 표준 사이즈 변환까지 연결됩니다.

### 보안이 신경 쓰인다면

이 도구는 이미지를 서버로 보내지 않고 사용자 브라우저 안에서 연산합니다. 외부 업로드가 없으므로 미공개 상품 사진도 안심하고 쓸 수 있습니다.

### 저작권 체크

도매처 상품 사진이라면 편집 전에 공급사의 사용·가공 허용 조건부터 확인하는 것이 순서입니다.

auto-seller.co.kr (무료, 회원가입 없음)
