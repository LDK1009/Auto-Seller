# [7/21 티스토리 3편차] 발행 19시 | 마크다운 그대로 붙여넣기

## 제목

도매 사이트에서 아이템 고르는 순서 — 초보 셀러의 소싱 동선 만들기

## 본문

"뭘 팔지 모르겠다"는 위탁판매 초보의 공통 증상입니다.
원인은 아이템이 없어서가 아니라 훑는 순서가 없어서입니다.
도매 사이트에서 후보를 좁혀가는 동선을 순서대로 만듭니다.


### 0단계 — 랜덤 탐색을 멈춘다

메인 페이지를 정처 없이 스크롤하는 건 소싱이 아닙니다.
카테고리 키워드를 정하고, 그 안에서만 봅니다.


### 1단계 — 팔리는 순서로 정렬한다

도매꾹이라면 검색 후 인기순 정렬.
지금 발주가 일어나는 상품 목록이므로, 수요가 있다는 것까지는 검증된 상태에서 시작합니다.

![도매꾹 인기순 검색](https://www.auto-seller.co.kr/marketing/domeggook-search.png)


### 2단계 — 거르는 조건 3개를 통과시킨다

| 조건 | 탈락 기준 |
|------|-----------|
| 최소구매수량 | 수량이 크고 묶음 구성으로 풀 계산이 안 서면 탈락 |
| 이미지 사용 조건 | 사용 불가·문의 필요인데 대체 이미지 계획이 없으면 탈락 |
| 배송비 구조 | 기본+도서산간 추가비 반영 시 마진이 사라지면 탈락 |

세 조건은 전부 "등록 후"가 아니라 "등록 전"에 확인해야 하는 것들입니다.


### 3단계 — 남은 후보만 등록 준비로 넘긴다

통과한 상품의 링크를 등록 준비 도구에 붙여넣습니다.
카테고리 추천, 상품명 검사, 판매가 역산, 태그 후보까지 자동 생성되므로 후보당 검토 비용이 낮아집니다.

![링크 붙여넣기 → 등록 시트](https://www.auto-seller.co.kr/marketing/domeggook-import-sheet.png)

후보를 여러 개 넘겨보고, 마진 계산 결과가 좋은 것부터 실제 등록하는 방식이 효율적입니다.

![판매가 역산 결과](https://www.auto-seller.co.kr/marketing/domeggook-import-sheet-price.png)


### 동선 요약

키워드 확정 → 인기순 정렬 → 3조건 필터 → 링크 등록 준비 → 마진 좋은 순 등록.
이 다섯 칸이면 "뭘 팔지 모르겠다"가 "뭐부터 올릴까"로 바뀝니다.

https://www.auto-seller.co.kr/ (무료, 회원가입 없음)
