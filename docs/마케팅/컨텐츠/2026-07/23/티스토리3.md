# [7/23 티스토리 3편차] 발행 19시 | 마크다운 그대로 붙여넣기

## 제목

계산기 하나로 상품을 거르는 법 — 등록 전에 손익부터 보는 습관

## 본문

상품을 먼저 정하고 가격을 나중에 계산하면, 계산 결과가 나빠도 미련 때문에 등록하게 됩니다.
순서를 바꾸면 이 문제가 사라집니다.
계산을 상품 선정 단계로 앞당기는 방법입니다.


### 습관의 차이

**기존 순서:** 상품 발견 → 마음에 듦 → 등록 준비 → (마지막에) 가격 계산 → 마진 안 나옴 → 그래도 등록
**바꾼 순서:** 상품 발견 → **가격 계산** → 마진 나오는 것만 → 등록 준비

계산이 "마무리 작업"에서 "필터"로 바뀝니다.


### 필터로 쓰는 법

후보 상품마다 마진 계산기에 세 값만 넣습니다.

1. 도매가 (묶음이면 × 수량)
2. 배송비
3. 목표 마진 (예: 20%)

나온 역산 판매가를 시장가와 비교합니다.

![마진 계산기](https://www.auto-seller.co.kr/marketing/margin-calculator.png)

| 비교 결과 | 판정 |
|-----------|------|
| 역산가가 시장가보다 낮다 | 통과 — 마진 확보하며 경쟁 가능 |
| 비슷하다 | 보류 — 이미지·구성 차별화 있을 때만 |
| 높다 | 탈락 — 미련 없이 다음 상품 |


### 링크로 더 빠르게

도매꾹 상품이면 계산기에 값을 옮겨 적을 필요도 없습니다.
링크를 붙여넣으면 도매가·수량·배송비가 자동 반영된 판매가가 시트에 나오므로, 후보당 몇 초면 판정이 끝납니다.

![링크 자동 계산](https://www.auto-seller.co.kr/marketing/domeggook-import-sheet-price-living.png)

후보 다섯 개를 넣어보고 계산이 제일 좋은 상품부터 등록하는 방식이 실전 동선입니다.


### 마무리

파는 실력보다 거르는 실력이 먼저입니다.
계산기를 등록 마지막이 아니라 소싱 처음에 두세요.
