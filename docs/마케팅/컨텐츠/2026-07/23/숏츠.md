## 훅 (0~3초)

자막: **"안 망하는 판매가 찾기, 타이머 켜고 재봤습니다"** — 스톱워치 스타트

## 시연 + 타이머 (3~24초)

1. 마진 계산기 — 도매가·배송비 입력
2. 수수료 프리셋 선택
3. 목표 마진율 입력 → 최소 판매가 등장 (크롭 줌)
4. 손익분기가 표시 → ⏱ 정지

| 초 | 자막 |
|----|------|
| 3~9 | 원가 넣고 수수료 고르고 |
| 9~15 | "20% 남기고 싶다" 입력하면 |
| 15~20 | 최소 판매가가 바로 나옵니다 |
| 20~24 | 이 밑으론 팔수록 손해라는 뜻 |
