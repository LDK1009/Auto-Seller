# [7/23 숏츠 3편차] 발행 21시 — 원링크 리빙용품 실측

## 영상 제목

이 상품 팔면 얼마 남을까, 링크로 바로 확인

> 시나리오: 23-3 (원링크 풀 플로우 — 수납정리함 검색, 판매가 역산 정차 강조)

## 훅 (0~3초)

자막: **"이 상품 팔면 얼마 남을까 | **링크 넣으면 바로 나와요** | 타이머 켜고 재봤습니다"** — 스톱워치 스타트

## 시연 + 타이머 (3~24초)

1. 원링크에 "수납정리함" 검색 → 상품 선택 → 시트 생성
2. 정차역 4곳 (상품 정보(도매가)·판매가 역산·개당 순이익·검색설정)

| 초 | 자막 |
|----|------|
| 3~9 | 리빙 상품 하나 골라볼게요 |
| 9~13 | 도매가랑 배송비 읽혔고요 |
| 13~17 | 판매가가 역산돼 있어요 |
| 17~21 | 개당 순이익까지 보여요 |
| 21~24 | 이대로 복사하면 끝이에요 |

> 자막 규칙: 자막 5 = 정차역 4 + 1

## 결과 카드 (24~30초)

**"손익 확인까지, [실측: mm:ss]"** → "링크는 프로필에 있어요" / "재보고 싶은 작업, 댓글로"
