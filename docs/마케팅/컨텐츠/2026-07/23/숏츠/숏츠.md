## 훅 (0~3초)

자막: **"정산서 보고 우는 이유 | **계산을 마지막에 해서예요** | 타이머 켜고 재봤습니다"** — 스톱워치 스타트

## 시연 + 타이머 (3~22초)

1. 마진 계산기 진입 → 원가·배송비 입력
2. 정차역 3곳 (입력값·목표 마진 선택·역산 결과)

| 초 | 자막 |
|----|------|
| 3~8 | 도매가랑 배송비 넣을게요 |
| 8~13 | 목표 마진 20% 고르고요 |
| 13~18 | 수수료까지 반영해서 |
| 18~22 | 판매가랑 순이익이 나왔어요 |

> 자막 규칙: 자막 4 = 정차역 3 + 1
