# [7/23 숏츠 2편차] 발행 18시 — 광고 손익(ROAS) 실측

## 영상 제목

광고 ROAS 400퍼면 버는 걸까 (손익분기 계산)

> 시나리오: 23-2 (ROAS 계산기 — 광고비·매출·마진율 입력 → 손익분기 판정)

## 훅 (0~3초)

자막: **"ROAS 400%면 버는 걸까 | **마진율 모르면 모릅니다** | 타이머 켜고 재봤습니다"** — 스톱워치 스타트

## 시연 + 타이머 (3~22초)

1. 광고 손익 계산기 진입 → 광고비·매출·마진율 입력
2. 정차역 3곳 (입력값·손익분기 ROAS·광고 손익 판정)

| 초 | 자막 |
|----|------|
| 3~8 | 광고비랑 매출 넣을게요 |
| 8~13 | 마진율까지 넣으면 |
| 13~18 | 손익분기 ROAS가 나오고요 |
| 18~22 | 지금 광고가 이득인지 떠요 |

> 자막 규칙: 자막 4 = 정차역 3 + 1

## 결과 카드 (22~28초)

**"광고 손익 판정, [실측: mm:ss]"** → "링크는 프로필에 있어요" / "재보고 싶은 작업, 댓글로"

## 설명란 (네이버 클립·릴스·숏츠 공통 — 영상별 1줄 + 고정 꼬리말)

손익분기 ROAS 계산, 타이머 켜고 직접 재봤어요.

오토셀러는 도매꾹 링크 하나로 스마트스토어 등록 준비를 자동으로 해주는 무료 도구예요.
가입도 필요 없어요. 링크는 프로필에 있습니다.
