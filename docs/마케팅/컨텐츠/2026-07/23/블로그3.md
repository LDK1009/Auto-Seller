# [7/23 블로그 3편차] 발행 20시
## 제목
원가만 넣으면 판매가가 나온다 — 마진 계산기 실전 사용법

## 본문
가격 책정이 어려운 이유는 수식이 어려워서가 아니라, 변수가 많아서입니다.
도매가, 배송비, 수수료, 목표 마진, 묶음 수량.
이걸 매번 암산하다 보면 하나쯤 빠지고, 빠진 항목이 손해가 됩니다.

계산기에 맡기는 실전 순서를 화면과 함께 정리합니다.

---

### 1단계 — 원가 입력
마진 계산기에 도매가와 배송비를 입력합니다.
묶음 판매(최소구매수량 있는 상품)라면 도매가 × 수량이 원가입니다.

![마진 계산기 입력](https://www.auto-seller.co.kr/marketing/margin-calculator.png)

### 2단계 — 목표 마진 선택
10% / 15% / 20% / 30% 버튼 중 고르거나 직접 입력합니다.
초보라면 20%부터 시작해 경쟁 상황 보며 조정하는 방식이 무난합니다.

### 3단계 — 결과 확인
수수료까지 반영된 판매가와 개당 순이익이 바로 나옵니다.
계산 근거(순이익 = 판매가 − 원가 − 수수료)도 함께 표시되므로 검산이 필요 없습니다.

### 실전 팁 — 역산 결과를 기준으로 경쟁가 판단
역산 판매가가 나오면 같은 상품의 시장가와 비교합니다.

- 역산가 < 시장가: 들어갈 만한 상품 (마진 확보하고도 가격 경쟁력)
- 역산가 ≈ 시장가: 차별화(이미지·구성) 없으면 힘든 싸움
- 역산가 > 시장가: 이 상품은 접는 게 계산상 맞습니다

가격을 "정하는" 도구가 아니라 상품을 "거르는" 도구로도 쓰이는 셈입니다.

### 도매꾹 상품이면 더 빠르게
링크를 원링크에 붙여넣으면 도매가·배송비·수량이 자동으로 들어간 계산 결과가 시트에 바로 표시됩니다.
