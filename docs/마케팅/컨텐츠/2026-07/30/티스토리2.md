# [7/30 티스토리 2편차] 발행 19시 | 마크다운 그대로 붙여넣기

> **종류:** A 문제해결 — 규격 맞추기 + 규정 검사 콤보
> **요약:** 형식 요건 사전 판정 → 일괄 변환 → 재검증 루프 소개 (네이버판과 별도 원고)

## 제목

상품 이미지 규격 총정리 — 검사부터 일괄 변환까지 무료로 끝내기

## 본문

마켓마다 이미지 형식 요건이 있고, 요건 미달은 등록 반려나 노출 불이익으로 돌아옵니다.
요건을 외울 필요는 없습니다 — 검사하고 변환하면 되니까요.


### 확인해야 할 형식 요건

| 항목 | 흔한 문제 |
|------|-----------|
| 해상도 | 도매처 원본이 권장 기준보다 작음 |
| 비율 | 정사각 권장 vs 직사각 원본 |
| 용량 | 고화질 원본의 용량 초과 |
| 포맷 | 지원하지 않는 확장자 |


### 처리 루프: 검사 → 변환 → 재검사

**검사** — 이미지를 올리면 위 항목들을 마켓 기준과 자동 대조합니다.
어떤 항목이 왜 미달인지 표시되므로 짐작할 필요가 없습니다.

**변환** — 미달 이미지는 규격 변환으로 넘깁니다.
목표 규격 프리셋을 고르면 여러 장이 한 번에 변환됩니다.
비율이 안 맞을 때 여백을 채울지 잘라낼지 선택할 수 있고, 원본 위아래의 불필요한 영역(배너·문구 띠)을 퍼센트 단위로 미리 잘라내는 옵션도 있습니다.

**재검사** — 변환본을 다시 검사에 통과시키면 업로드 전 확정입니다.


### 장점 요약

- 반려를 등록 전에 소진 — 등록 후 수정 왕복 없음
- 일괄 처리 — 상품 단위가 아니라 배치 단위 작업
- 무료·무설치, 이미지는 브라우저 내 처리

auto-seller.co.kr (회원가입 없음)


### 마켓별 규격 차이 대응

[이미지: 마켓 프리셋 선택 화면]

스마트스토어만 팔 계획이어도 규격 체계를 알아두면 확장 때 편합니다.
마켓마다 권장 규격·용량 상한·비율 허용치가 다르기 때문에, "마켓별 프리셋으로 변환"이 가능한 도구면 같은 원본에서 마켓별 세트를 한 번에 뽑을 수 있습니다.
멀티 채널 판매의 이미지 비용이 사실상 0이 되는 구조입니다.


### 검사를 소싱 필터로 역이용

규정 검사는 등록 직전에만 쓰는 게 아닙니다.
소싱 후보의 공급사 이미지를 미리 검사에 넣어보면 "이 상품은 이미지 품질 때문에 손이 많이 갈 것"이 사전에 보입니다.
같은 조건의 상품이라면 이미지 손질 비용이 낮은 쪽을 고르는 것도 원가 절감입니다 — 시간도 원가니까요.


### 정리

이미지 형식 문제는 지식이 아니라 절차로 푸는 영역입니다.
검사 → 변환 → 재검사 루프를 한 번 익히면, 이후로는 규격 걱정 자체가 사라집니다.
