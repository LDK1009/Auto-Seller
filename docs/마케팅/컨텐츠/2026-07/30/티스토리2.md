> **요약:** 형식 요건 사전 판정 → 일괄 변환 → 재검증 루프 소개 (네이버판과 별도 원고)

## 제목

상품 이미지 규격 총정리 — 검사부터 일괄 변환까지 무료로 끝내기

## 본문

마켓마다 이미지 형식 요건이 있고, 요건 미달은 등록 반려나 노출 불이익으로 돌아옵니다. 요건을 외울 필요는 없습니다 — 검사하고 변환하면 되니까요.

### 확인해야 할 형식 요건

| 항목 | 흔한 문제 |
|------|-----------|
| 해상도 | 도매처 원본이 권장 기준보다 작음 |
| 비율 | 정사각 권장 vs 직사각 원본 |
| 용량 | 고화질 원본의 용량 초과 |
| 포맷 | 지원하지 않는 확장자 |

### 처리 루프: 검사 → 변환 → 재검사

**검사** — 이미지를 올리면 위 항목들을 마켓 기준과 자동 대조합니다. 어떤 항목이 왜 미달인지 표시되므로 짐작할 필요가 없습니다.

**변환** — 미달 이미지는 규격 변환으로 넘깁니다. 목표 규격 프리셋을 고르면 여러 장이 한 번에 변환됩니다. 비율이 안 맞을 때 여백을 채울지 잘라낼지 선택할 수 있고, 원본 위아래의 불필요한 영역(배너·문구 띠)을 퍼센트 단위로 미리 잘라내는 옵션도 있습니다.

**재검사** — 변환본을 다시 검사에 통과시키면 업로드 전 확정입니다.
