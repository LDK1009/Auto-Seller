# [7/30 쓰레드] 5개 — 10·12·15·19·22시 (짝수날: 댓글 연작 4 + 일반 1)

## ① 10시 — 댓글 연작 (1/3)

**본문 (훅):**
위탁판매에서 제일 위험한 말:
"설마 이게 KC 인증 대상이겠어." (이어서)

**댓글 1:**
KC는 몰랐다고 봐주지 않아요.
확인 신호는 세 단어 — 전원 쓰는가(전기용품) / 어린이가 쓰는가(어린이제품) / 안전사고 직결인가.
하나라도 해당되면 인증 확인이 먼저.

**댓글 2:**
절차는 4단계 —
특성 점검 → 공급사에 인증번호 요청 → 번호 조회 → 없으면 판매 보류.
"공급사가 알아서 했겠지"는 절차가 아니에요.

**댓글 3 (CTA):**
상품 불러올 때 KC 가능성을 자동 경고해주는 도구까지,
프로필 링크에 정리해뒀어요.

## ② 12시 — 댓글 연작 (1/2)

**본문 (훅):**
이미지 반려의 대부분은 규격(크기·비율·형식) 문제예요.
기계적인 기준이니 기계로 미리 검사하면 끝. (이어서)

**이미지 (Ctrl+클릭 → 파일 열어 첨부):** [규정 검사 화면](../../../../../../public/marketing/image-check.png)

**댓글 1:**
올리기 전 일괄 검사 → 걸린 것만 변환.
50장 중 걸린 게 12장이면 처리 대상은 12장뿐이에요.
검사가 공정 앞에 있을 때만 가능한 효율이죠.

**댓글 2 (CTA):**
"올리고 기도"에서 "검사하고 등록"으로.
순서 하나 바꾸면 반려가 사라져요. 방법은 프로필 링크에.

## ③ 15시 — 일반 (공감 단문)

**본문:**
부업 검색 몇 달 차,
남의 제재 사례만 읽다가 깨달았어요.
사고당한 게 아니라 확인을 건너뛴 거였구나.

## ④ 19시 — 댓글 연작 (1/2)

**본문 (훅):**
등록 전에 제일 불안한 항목들, 사실 공통점이 있어요. (이어서)

**댓글 1:**
KC 인증 / 상품명 금지어 / 이미지 규격 / 세금.
넷 다 사전 확인 절차가 존재해요.
불안은 "확인 안 한 상태"의 다른 이름이더라고요.

**댓글 2:**
겁 많은 성격이 셀러에 불리한 줄 알았는데 반대였어요.
겁은 절차를 만들게 하고, 절차는 사고를 막아요.

## ⑤ 22시 — 댓글 연작 (1/2)

**본문 (훅):**
시작을 막는 건 규제가 아니라 규제의 안개예요. (이어서)

**댓글 1:**
막연한 공포를 목록으로 적어보면 놀랄 만큼 짧아요 —
KC / 상품명 / 이미지 규격 / 세금. 네 줄.
그리고 그 네 줄은 전부 확인 절차가 있어요. 상당수는 자동으로.

**댓글 2:**
안개는 목록과 절차로 걷혀요.
겁낼 시점을 "등록 후"에서 "등록 전"으로 옮기면
등록 전의 겁은 확인으로 해소되거든요.
