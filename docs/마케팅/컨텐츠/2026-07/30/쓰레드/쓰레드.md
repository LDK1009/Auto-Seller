## ① 10시 — 감정 · 번아웃

```
퇴근하고 집에 오면, 좀 쉬고 싶은데도 결국 또 노트북을 켜게 되더라고요.
소싱하고 이미지 만지고 등록하다 보면 어느새 새벽 한 시고요.

부업 좀 해보려고 잠을 줄인 건데,
어쩐지 야근을 하나 더 늘린 기분이 들 때가 있어요.
```

**댓글 오면** → 공감 + "어느 단계가 제일 오래 걸리세요?" (pain 수집)

---

## ② 15시 — 꿀팁 · 뭘 팔지

```
🗣️ 뭘 팔지 몰라서 일주일째 상품을 못 올리고 있어요
👤 그럴 땐 검색량 대비 상품 수를 한번 보세요
🗣️ 그건 어떻게 보는 거예요?

<팔릴 틈새인지 5초 만에 보는 법>
1. 네이버쇼핑에 팔고 싶은 키워드를 검색해요
2. 결과 맨 위에 뜨는 '상품 수'를 확인해요
3. 검색은 많은데 상품 수가 적으면, 그게 틈새예요
👉 반대로 상품 수가 수백만이면 이미 레드오션이더라고요

검색량이랑 상품 수를 나눠서 한눈에 보여주는 거, 프로필에 걸어뒀어요.
```

**댓글 오면** → "지금 보고 계신 키워드 있으세요?" (대화)

## ③ 21시 — Q&A · 왜 안 팔림

```

그럴 때 제일 먼저 뭘 의심하세요?
① 가격  ② 이미지  ③ 키워드  ④ 그냥 아직 때가 아닌 거

저는 보통 키워드부터 다시 보는 편이에요.
```
