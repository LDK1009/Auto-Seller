# [7/22 숏츠 2편차] 발행 18시 — 원링크 캠핑용품 실측 (MOQ 묶음)

> 시나리오: 22-2 (원링크 풀 플로우 — 캠핑의자 검색, MOQ 묶음 안내 정차 포함)

## 훅 (0~3초)

자막: **"도매가만 보고 올리면 | **팔릴수록 손해날 수 있어요** | 타이머 켜고 재봤습니다"** — 스톱워치 스타트

## 시연 + 타이머 (3~24초)

1. 원링크에 "캠핑의자" 검색 → 상품 선택 → 시트 생성
2. 정차역 4곳 (카테고리·상품명·판매가·검색설정)

| 초 | 자막 |
|----|------|
| 3~9 | 캠핑용품 하나 골라볼게요 |
| 9~13 | 카테고리는 정해져 있고요 |
| 13~17 | 상품명 검사도 끝났어요 |
| 17~21 | 판매가 마진 계산돼 있고요 |
| 21~24 | 태그 복사하면 끝이에요 |

> 자막 규칙: 자막 5 = 정차역 4 + 1

## 결과 카드 (24~30초)

**"등록 준비, [실측: mm:ss]"** → "링크는 프로필에 있어요" / "재보고 싶은 작업, 댓글로"
