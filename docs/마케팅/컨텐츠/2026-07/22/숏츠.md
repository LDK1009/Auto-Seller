# [7/22 숏츠 1편차] 발행 12시 — 엑셀 대량 가공 실측

> 시나리오: 22-1 (엑셀 대량 가공 — 엑셀 업로드 → 상품 목록 로드 → 일괄 처리)

## 훅 (0~3초)

자막: **"상품 50개 대량등록 | **이미지 50장이 문제죠** | 타이머 켜고 재봤습니다"** — 스톱워치 스타트

## 시연 + 타이머 (3~24초)

1. 엑셀 대량 가공에 파일 업로드 → 상품 목록 자동 로드
2. 정차역 3곳 (상품 목록·일괄 처리 진행·완료 집계)

| 초 | 자막 |
|----|------|
| 3~9 | 엑셀 파일만 올릴게요 |
| 9~15 | 상품 목록이 그대로 읽혔어요 |
| 15~20 | 이미지가 일괄로 처리되고요 |
| 20~24 | 전부 끝났어요, 받기만 하면 돼요 |

> 자막 규칙: 자막 4 = 정차역 3 + 1

## 결과 카드 (24~30초)

**"대량 가공, [실측: mm:ss]"** → "링크는 프로필에 있어요" / "재보고 싶은 작업, 댓글로"
