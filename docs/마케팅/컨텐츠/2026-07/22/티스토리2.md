# [7/22 티스토리 2편차] 발행 19시 | 마크다운 그대로 붙여넣기

> **종류:** A 문제해결 — 엑셀 대량 가공 기능
> **요약:** 대량등록 워크플로의 이미지 병목을 xlsx 업로드 한 번으로 푸는 절차 (네이버판과 별도 원고)

## 제목

상품 100개 이미지 작업을 한 번에 — 엑셀 기반 일괄 배경제거 워크플로

## 본문

대량등록의 역설: 정보 입력은 엑셀로 빨라졌는데, 이미지 준비 속도는 그대로라는 것. 결국 전체 속도는 이미지가 정합니다.


### 기존 동선의 문제

1. 엑셀에서 상품 확인
2. 이미지 주소를 하나씩 열어 저장
3. 편집 도구로 배경 제거
4. 상품별 폴더 정리

상품 수 × 4단계. 50개면 200번의 손작업입니다.


### 바뀐 동선

1. 대량등록 xlsx를 그대로 업로드
2. 도구가 상품명 컬럼을 인식하고 이미지 주소를 뽑아냅니다
3. 최대 100장 자동 수집 후 배경 제거가 연달아 실행됩니다
4. 상품별로 구분된 ZIP 하나를 받습니다

손작업 200번이 업로드 1번 + 다운로드 1번으로 압축됩니다.


### 유의점

- 이미지 수집은 검증된 도매처 도메인만 허용됩니다 (무분별한 외부 주소 수집 방지)
- 각 상품의 이미지 사용 허용 여부 확인은 여전히 판매자 책임입니다


### 대량 작업이 필요한 시점 판단

[이미지: 대량 처리 진행률 화면]

모든 셀러에게 대량 가공이 필요한 건 아닙니다.
단계별로 보면:

- **등록 10개 미만** — 원링크 개별 처리가 더 빠릅니다. 대량 도구는 오버헤드
- **등록 30~50개 계획** — 엑셀 대량 가공의 효율 구간 시작. 소싱을 엑셀로 정리하는 습관도 이때 생기면 좋습니다
- **기존 상품 리뉴얼** — 등록 수와 무관하게 유용합니다. 계절 배경 교체, 워터마크 일괄 추가 같은 전체 갱신 작업에 적합


### 실무자의 팁 — 엑셀을 소싱 장부로

이 기능을 쓰다 보면 부수 효과가 생깁니다: 소싱 후보를 처음부터 엑셀로 관리하게 된다는 것. 상품명·URL·도매가·MOQ를 열로 정리해두면 이미지 가공뿐 아니라 가격 재점검·품절 확인 때도 같은 파일로 돌 수 있습니다.
도구가 습관을 만들고, 습관이 운영 체계가 됩니다.

처리 자체는 브라우저에서 이루어지며 무료입니다: auto-seller.co.kr (회원가입 없음)
