# [7/22 티스토리 2편차] 발행 14시 | 마크다운 그대로 붙여넣기
## 제목
상품 100개 이미지 작업을 한 번에 — 엑셀 기반 일괄 배경제거 워크플로

## 본문
소량 등록과 대량 등록은 다른 종목입니다.
10개까지는 손으로 되지만, 100개부터는 공정이 없으면 무너집니다.
그 공정에서 가장 무거운 이미지 작업을 일괄화하는 워크플로를 정리합니다.


### 대량 작업이 무너지는 지점
엑셀 대량등록 자체는 어렵지 않습니다.
무너지는 건 이미지 열입니다.

- 상품 100개 = 대표이미지 최소 100장
- 각 장마다 배경 정리 + 규격 변환 필요
- 장당 몇 분씩 손으로 하면 주말이 사라짐

게다가 손으로 만들면 100장의 톤이 제각각이 됩니다.


### 워크플로 4단계
**1단계 — 원본 일괄 수집**
공급사 이미지 사용이 허용된 상품 위주로 원본을 모읍니다.

**2단계 — 배경 일괄 제거**
전체 이미지를 한 번에 올려 배경을 자동 제거합니다.
브라우저 안에서 처리되므로 미공개 이미지도 서버로 나가지 않습니다.

https://www.auto-seller.co.kr/marketing/background-removal.png

**3단계 — 규격 일괄 변환**
1000×1000 프리셋으로 전체를 한 번에 변환합니다.
여백 맞춤(전체 보존)과 꽉 채움(중앙 크롭) 중 상품 형태에 맞는 쪽을 고릅니다.

https://www.auto-seller.co.kr/marketing/image-resize.png

**4단계 — ZIP 다운로드 → 엑셀 연결**
완성본을 ZIP으로 받아 파일명 기준으로 엑셀 행과 연결합니다.

엑셀 파일을 직접 올려 상품 목록 기준으로 가공하는 대량 가공 메뉴를 쓰면 이 연결까지 한 흐름이 됩니다.

https://www.auto-seller.co.kr/marketing/excel-import.png


### 소요 구조의 변화
| 방식 | 공정 | 균일함 |
|------|------|--------|
| 장당 수작업 | 100장 × 장당 편집 | 장마다 다름 |
| 일괄 워크플로 | 업로드 2회 + 다운로드 1회 | 전체 동일 규격 |

핵심은 속도보다 공정 수입니다.
"100번의 편집"이 "3번의 클릭 묶음"으로 바뀝니다.

공정이 잡히면 100개도 1,000개도 같은 방식입니다.
