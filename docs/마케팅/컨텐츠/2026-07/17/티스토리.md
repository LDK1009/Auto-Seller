# [7/17 티스토리] 발행 14시 | 마크다운 그대로 붙여넣기

> **종류:** C 정보성 — 유형② 노하우·가이드
> **요약:** 등록 폼 항목별 주의점을 화면 순서대로 짚는 가이드 (네이버판과 별도 원고)

## 제목

네이버 스마트스토어 상품 올리는 순서 — 등록 화면 항목별 완전 정리

## 본문

처음 상품을 등록할 때 가장 도움이 되는 건 "화면에 나오는 순서대로" 정리된 자료입니다. 스마트스토어 등록 폼을 위에서 아래로 훑으며, 각 항목에서 무엇을 조심해야 하는지 정리했습니다.

### 항목별 핵심

**카테고리** — 감으로 고르지 말고 네이버쇼핑에서 유사 상품을 검색해 상위 노출 상품들의 카테고리를 따라가는 것이 기본입니다.

**상품명** — 길이 제한이 있고, ★ 같은 특수문자와 "최저가" 같은 광고성 표현은 제재 사유입니다. 다른 브랜드 이름을 넣는 것도 위험합니다.

**판매가** — 위탁판매라면 도매가에 최소구매수량을 곱한 금액이 진짜 원가입니다. 수수료와 배송비까지 반영해 거꾸로 계산해야 적자를 피합니다.

**재고수량** — 묶음으로 팔 경우 도매처 재고를 묶음 수량으로 나눈 값을 넣어야 품절 사고가 없습니다.

**옵션** — 조합이 많으면 수기 입력보다 엑셀 일괄등록이 정확합니다.

**상품이미지** — 대표 1장과 추가 9장. 흰 배경, 1000×1000 픽셀이 표준입니다.

**상세설명** — 공급사 상세 이미지 사용이 허용된 상품은 HTML 붙여넣기가 가장 빠른 방법입니다.

**주요정보** — 원산지·제조사와 함께 KC 인증 대상 여부를 반드시 확인합니다.

**배송·반품** — 반품 배송비는 실비 기준으로. 낮게 잡으면 반품 건마다 적자입니다.

**태그** — 상품명에 이미 들어간 단어는 태그로서 효력이 없습니다. 새로운 연관 키워드만 넣습니다.

**판매자 상품코드** — 도매처 상품번호를 넣어두면 발주가 빨라집니다.

### 전 항목을 한 번에 만드는 방법

도매꾹 링크를 입력하면 위 항목 전체가 등록 폼 순서대로 자동 생성되는 무료 도구가 있습니다. 각 항목 옆 복사 버튼으로 옮겨 붙이면 등록이 끝납니다.

auto-seller.co.kr (무료, 회원가입 없음)
