# [7/17 쓰레드] 4개 — 08(예약)·12·19·22시

## ① 08시 — 블로그 분해 (12단계 요약)

스마트스토어 등록, 순서 몰라서 헤매는 분들.
화면 순서 그대로 외우세요:
카테고리→상품명→가격→재고→옵션→이미지→상세→주요정보→배송→반품→태그→코드.
12개. 이 순서대로만 채우면 됩니다.

## ② 12시 — 기능 팁

태그에 상품명 키워드 또 넣으면 효과 없는 거 아셨나요?
스마트스토어는 상품명과 중복된 태그를 무효 처리합니다.
태그 10개면 상품명에 없는 키워드 10개를 넣어야 손해가 없습니다.

## ③ 19시 — 공감 한 줄

등록 화면 빈칸 하나 채울 때마다 검색을 한 번씩 했다.
상품 하나 올리는 데 저녁이 사라졌다.
이게 사업인가, 데이터 입력 알바인가.

## ④ 22시 — 사실 팁 (질문 유도)

판매가 정할 때 도매가에 그냥 30% 얹으면 위험합니다.
수수료 + 배송비 + 최소구매수량(묶음 원가)까지 계산해야
"팔수록 손해"를 피합니다. 역산 공식 궁금하신 분? (댓글)
