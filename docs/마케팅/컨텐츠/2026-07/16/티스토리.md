# [7/16 티스토리] 발행 14시 | 마크다운 그대로 붙여넣기

> **종류:** C 정보성 — 유형① 오토셀러 소개
> **요약:** 등록 12개 항목을 무료 자동화하는 방법으로 풀어낸 서비스 소개 (네이버판과 별도 원고)

## 제목

스마트스토어 상품등록 자동화, 무료로 하는 방법 (도매꾹 위탁판매)

## 본문

위탁판매의 병목은 소싱이 아니라 등록입니다.
상품 하나를 올리려면 카테고리 선택부터 상품명, 가격 책정, 이미지 편집, 옵션 입력, 태그까지 — 항목이 12개나 되고, 각 항목마다 규칙이 따로 있습니다.

이 글에서는 그 12개 항목을 무료로 자동화하는 방법을 소개합니다.


### 준비물은 도매꾹 링크 하나

오토셀러(auto-seller.co.kr)라는 웹 도구에 도매꾹 상품 URL을 입력하면, 스마트스토어 등록 폼과 동일한 순서의 "등록 정보 시트"가 생성됩니다.

시트에 포함되는 것:

- **카테고리 후보 3개** — 네이버쇼핑 상위 20개 상품의 카테고리를 분석한 결과
- **상품명 추천 + 검사** — 글자수, 특수문자, 홍보성 문구, 지식재산권 위험 단어를 실시간 판정
- **추천 판매가** — 최소구매수량(MOQ)을 반영한 묶음 원가에서 역산, 손익분기 가격 병기
- **옵션 조합** — 스마트스토어 일괄등록용 엑셀(.xlsx) 파일로 다운로드
- **이미지 편집** — 배경 제거, 배경 교체, 워터마크를 클릭으로 처리하고 ZIP 저장
- **상세설명 HTML** — 복사해서 에디터에 붙여넣기
- **KC 인증 경고** — 전기·어린이·식품·화장품·의료 해당 가능성을 배지로 표시
- **태그 후보 10개** — 상품명과 중복돼 효과 없는 태그는 자동 제외


### 함정 방지 기능

등록보다 앞 단계의 사고도 막아줍니다.
공급사가 이미지 사용을 허용하지 않은 상품은 조회 단계에서 차단되고, MOQ가 2 이상인 상품은 1+1 묶음 구성과 재계산된 원가를 안내받습니다.


### 비용과 개인정보

현재 무료이고 회원가입이 없습니다.
이미지 처리는 브라우저 내부에서 이루어져 서버에 업로드되지 않습니다.


### 어떤 사람에게 맞고, 안 맞나

**맞는 경우** — 도매꾹 기반 위탁판매를 하거나 시작하려는 사람. 등록 수를 늘리는 게 과제인 초보~중급 셀러. 이미지 편집 도구가 없는 사람.

**안 맞는 경우** — 직접 촬영·자체 브랜딩 중심 셀러(등록 시트의 자동 추출 이점이 줄어듭니다.
다만 이미지 도구 5종은 독립 사용 가능). 도매꾹 외 소싱처만 쓰는 경우.


### 함께 쓰면 좋은 순서

[이미지: 키워드 분석 → 도매꾹 검색 → 원링크 흐름 화면]

1. 키워드 분석에서 검색수 대비 상품 수가 빈 키워드 확인
2. 그 키워드로 도매꾹 검색 → 후보 클릭
3. 원링크 시트로 등록 준비 완료

소싱 판단부터 등록 준비까지 한 흐름으로 이어지는 구조라, 도구를 오가며 흐름이 끊기지 않습니다.

등록 작업에 저녁 시간을 쓰고 있다면 한 번 시험해볼 만합니다: auto-seller.co.kr
