# [7/16 숏츠] 원링크 풀 시연 — 링크 하나 넣었더니 등록 정보가 다 나옴

> **종류:** A 문제해결 — 원링크 전체 플로우 시연
> **요약:** 링크 붙여넣기→시트 생성→누끼→전체 복사까지 30초 화면녹화 시연

> 포맷: 화면녹화 + 자막 + BGM (무음성) | 길이: 30~40초 | 업로드 18시

## 촬영 순서 (화면녹화)

1. 도매꾹 상품 페이지 → URL 복사 (3초)
2. auto-seller.co.kr 원링크에 붙여넣기 → 조회 (3초)
3. 등록 시트 스크롤 — 카테고리·상품명·판매가·옵션 순으로 훑기 (10초)
4. 이미지 클릭 → 배경 제거 → 완성 (8초)
5. 시트 [전체 복사] 클릭 (3초)

## 자막 타임라인

| 초 | 자막 |
|----|------|
| 0~3 | 상품 등록에 2시간 걸리던 사람입니다 |
| 3~6 | 도매꾹 링크를 복사해서 |
| 6~10 | 여기에 붙여넣으면 |
| 10~18 | 카테고리, 상품명, 판매가, 옵션까지 자동으로 나옵니다 |
| 18~26 | 사진 배경 제거도 클릭 한 번 |
| 26~32 | 등록 화면 순서 그대로라 복붙만 하면 끝 |
| 32~38 | 무료, 가입 없음. 오토셀러 검색 |

## 설명란

도매꾹 링크 하나로 스마트스토어 등록 준비 끝. 무료·무가입 — auto-seller.co.kr
