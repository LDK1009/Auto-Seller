## 훅 (0~3초)

자막: **"요즘 스마트스토어 부업 | **이 정도로 쉬워졌어요** | 타이머 켜고 재봤습니다"** — 스톱워치 00:00 → 스타트 (훅 유형: 예비층용 — 진입장벽 하락 소구)

## 시연 + 타이머 (3~24초)

1. 도매꾹 상품 링크 복사 → 원링크 붙여넣기 (실시간)
2. 시트 생성 — 카테고리·상품명·판매가 스크롤 (핵심 칸 크롭 줌)
3. 이미지 배경 제거 클릭 → 완성
4. [전체 복사] 클릭 → ⏱ 정지

| 초 | 자막 |
|----|------|
| 3~7 | 상품 하나 골라서 눌러볼게요 |
| 7~12 | 카테고리가 벌써 정해져 있어요 |
| 12~17 | 상품명도 검사까지 끝난 상태예요 |
| 17~21 | 판매가는 마진까지 계산돼 있고요 |
| 21~24 | 태그 복사해서 붙여넣으면 끝이에요 |

> 자막 규칙: 첫 줄 = 액션 구간, 이후 줄 = 정차역과 1:1 매칭 (정차역 수 + 1 = 자막 수 — 빌더가 자동 스냅)
