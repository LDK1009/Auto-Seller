## 훅 (0~3초)

## 시연 + 타이머 (3~22초)

1. 규정 검사에 이미지 30장 업로드 → 자동 판정
2. 정차역 3곳 (판정 집계·개별 판정 사유·변환 전송 버튼)

| 초 | 자막 |
|----|------|
| 3~9 | 30장 한꺼번에 올릴게요 |
| 9~14 | 적합·주의가 바로 갈리고요 |
| 14~18 | 왜 걸렸는지 사유도 보여요 |
| 18~22 | 걸린 건 변환으로 넘기면 돼요 |

> 자막 규칙: 자막 4 = 정차역 3 + 1
