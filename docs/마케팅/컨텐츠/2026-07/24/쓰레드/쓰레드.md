# 7/24 쓰레드 — 댓글 유도형 3개

발행: 10시 · 15시 · 21시
형식: 문제 한 줄 → 영상 첨부 → 유도어 댓글 요청
**댓글 오면 전부 답장** (대댓글이 도달을 만든다)

---

## ① 10시 — 상페

**영상:** `24/숏츠/상세페이지 없어서 등록 못 한다면.mp4`

```
상세페이지 못 만들어서 등록 미루는 분들 계실까요?

새로 만드는 게 아니라, 도매처 이미지를 마켓 규격에 맞게
자르는 것만으로 되는 경우가 많더라고요.

궁금한 스친은 좋아요 + 댓글에 "상페" 남겨주세요!
```

**대댓글 준비**
- "어떻게 자르나요?" → "높이 제한에 맞춰 자동으로요. 프로필 링크에서 바로 되실 거예요"
- "저작권은요?" → "공급사가 이미지 사용 허용한 상품인지 먼저 봐야 해요. 그것도 자동으로 걸러줍니다"

---

## ② 15시 — 규격검사

**영상:** `24/숏츠/이미지 30장 규격 검사, 한 장씩 보면 하루 간다.mp4`

```
대표이미지 규격 안 맞으면 등록이 막히는데,
30장을 한 장씩 열어서 확인하고 계신가요?

한 번에 검사해서 안 맞는 것만 골라줍니다.

궁금한 스친은 좋아요 + 댓글에 "규격검사" 남겨주세요!
```

**대댓글 준비**
- "뭘 검사해요?" → "해상도, 비율, 용량이요. 기준에 안 맞는 것만 표시돼요"
- "고치는 것도 되나요?" → "네, 검사 후 바로 변환으로 넘어갈 수 있어요"

---

## ③ 21시 — 시즌 (답 얻는 게 목적)

**영상:** `24/숏츠/시즌 상품 등록 준비, 이 시간이면 끝.mp4`

```
8월에 팔 상품, 지금 준비하시는 분 있을까요?

시즌 상품은 타이밍 놓치면 이미 경쟁이 끝나 있더라고요.

다들 몇 주 전부터 준비하세요?
궁금한 스친은 좋아요 + 댓글에 "시즌" 남겨주세요!
```

**대댓글 준비**
- 답변 오면 → "저는 한 달 전이라고 들었는데 실제로는 더 빠르네요. 알려주셔서 감사해요!"
- **수집 목적:** 시즌 준비 시점 → 콘텐츠 캘린더·기능 우선순위에 반영
