## ① 10시 — 상페

**영상:** `docs/마케팅/영상/데모/split-basic.mp4`

```
상세 이미지 때문에 등록 미뤄둔 상품, 있으시죠?

저도 이거 새로 만드는 건 줄 알았는데
도매처 상세 잘라 쓰는 거더라고요.

높이만 맞춰서 자르면 되는데
그거 자동으로 해주는 거 만들었어요.

필요하신 분 댓글에 "상페" 남겨주세요!
```

**댓글 오면**
- "어떻게 자르는데요?" → "높이 제한에 맞춰서 알아서 잘라줘요. 번호도 붙여서 묶어주고요"
- "저작권 괜찮아요?" → "공급사가 이미지 쓰라고 허용한 상품인지 먼저 봐야 해요. 그것도 같이 확인돼요"

## ② 15시 — 교차 소싱 #1 (손선풍기) ⭐ 신규 시리즈

**이미지:** 손선풍기 키워드 분석 캡처 (검색 68,900 · 경쟁 "기회")
> 첨부 캡처: `docs/마케팅/영상/데모/` 옆 소싱 캡처 폴더 (발행 전 확정) — 하단 안내문구 구 기준이면 개발 반영 후 사용

```
여름 상품 뭐 떼올지 고민이면.

검색 1등은 제습기예요. 월 45만.
근데 가전은 반품·불량 CS가 지옥이라 초보한텐 안 맞아요.

저는 손선풍기 봐요.
검색 6만9천에 경쟁도 아직 여유 있거든요.

검색량만 보면 낚여요.
감당되는 상품인지가 먼저예요.

"소싱" 남기면 다음 상품도 같이 봐요.
```

**댓글 오면**
- "이거 어디서 봐요?" → "키워드 분석에서요. 검색량이랑 경쟁도 같이 떠요"
- "제습기는 왜 안 돼요?" → "가전은 반품·초기불량 CS가 많아서 초보한텐 부담이 커요"

> 시리즈 기준: [MARKETING.md 정기 시리즈](../../../MARKETING.md) · 상품 데이터 [소싱후보-교차선정.md](../../../소재/소싱후보-교차선정.md)
