# [7/24 쓰레드] 5개 — 10·12·15·19·22시

## ① 10시 — 블로그 분해 · 연작 (1/4)

**본문 (훅):**
상품 등록 실수엔 두 종류가 있어요.
고치면 되는 것, 고치는 순간 더 손해인 것.
후자 12가지를 정리했습니다. (스레드로 이어집니다)

**댓글 1:**
"고치면 더 손해"인 실수 2계열
가격 — 수수료 미반영·도서산간 누락·역산 안 함 (주문은 옛 가격 확정)
노출 — 잘못된 카테고리·금지어 상품명·아무 태그 (수정 시 검색 초기화)

**댓글 2:**
공통점은 하나 — 전부 "등록 후"엔 못 돌려요.
그래서 점검은 등록 버튼 앞에서 끝나야 합니다.

**댓글 3 (CTA):**
12항 전체 점검표랑 자동으로 채우는 방법은
프로필 링크에 있어요.

## ③ 15시 — 공감 한 줄

**본문:**
첫 상품 등록하던 날,
자정 넘어 등록 버튼 누르면서 생각했죠.
"이걸 상품마다 한다고?"

## ④ 19시 — 사실 팁 + 질문 (설문 활용 가능)

**본문:**
등록하고 나서 후회한 실수, 뭐가 제일 아팠나요?

**설문 항목:** 가격 계산 실수 / 카테고리 잘못 선택 / 상품명 금지어 / 이미지 규격 반려

**댓글 (팁):**
어떤 답이든 공통 해법은 같아요.
점검을 기억력에 맡기지 말고 공정에 박아 넣을 것.
링크 넣으면 경고까지 떠주는 도구면 실수 자체가 어렵습니다.

## ⑤ 22시 — 공감 반전 (마무리)

**본문:**
등록이 빨라지니까 오히려 등록을 덜 하게 됐어요.
아무거나 올릴 시간에 고르게 되더라고요.
노동이 줄면 판단이 늘어납니다.
