## ① 10시 — 상페

**영상:** `24/숏츠/상세페이지 없어서 등록 못 한다면.mp4`

```
상세페이지 만들 줄 몰라서 등록 미루고 계신 분?

저도 이거 새로 만드는 건 줄 알았는데
도매처 이미지 잘라서 쓰는 거더라고요.

높이만 맞춰서 자르면 되는데
그거 자동으로 해주는 거 만들었어요.

필요하신 분 댓글에 "상페" 남겨주세요!
```

**댓글 오면**
- "어떻게 자르는데요?" → "높이 제한에 맞춰서 알아서 잘라줘요. 번호도 붙여서 묶어주고요"
- "저작권 괜찮아요?" → "공급사가 이미지 쓰라고 허용한 상품인지 먼저 봐야 해요. 그것도 같이 확인돼요"

## ② 15시 — 규격검사

**영상:** `24/숏츠/이미지 30장 규격 검사, 한 장씩 보면 하루 간다.mp4`

```
이미지 30장을 한 장씩 열어서
크기 맞나 확인하고 계시진 않죠?

저는 그거 보고 만들었어요.
한 번에 검사해서 안 맞는 것만 표시해줍니다.

댓글에 "규격" 남겨주시면 알려드릴게요
```

**댓글 오면**
- "뭘 검사해요?" → "해상도랑 비율, 용량이요. 기준 안 맞는 것만 빨갛게 떠요"
- "고치는 것도 되나요?" → "네 바로 변환으로 넘어가요"
