# [7/24 티스토리 2편차] 발행 14시 | 마크다운 그대로 붙여넣기
## 제목
디자인 프로그램 없이 상세페이지 완성하기 — 분할과 워터마크 2단계

## 본문
상세페이지 때문에 외주를 알아보다가 견적을 보고 닫은 적이 있다면, 이 글이 대안이 됩니다.
위탁판매의 상세페이지는 만드는 게 아니라 가공하는 것에 가깝습니다.


### 전제 — 재료는 이미 있다
공급사 상세 이미지 사용이 허용된 상품이라면, 재료는 확보된 상태입니다.
남은 문제는 두 가지뿐입니다.

1. 세로로 너무 길어서 마켓 규격에 안 맞는다
2. 그대로 쓰면 다른 스토어와 완전히 똑같다


### 1단계 — 규격 분할
마켓은 상세 이미지 장당 세로 길이에 제한을 둡니다.
수천 픽셀짜리 원본을 그대로 올리면 거부되거나 압축으로 화질이 무너집니다.

분할 도구에 원본을 올리고 규격 프리셋을 고르면, 제한 높이에 맞춰 잘린 이미지 묶음이 나옵니다.

https://www.auto-seller.co.kr/marketing/image-split.png

- 글자 잘리는 위치는 미리보기에서 조정
- 결과물은 ZIP 일괄 다운로드
- 마켓 에디터에 순서대로 업로드하면 끝


### 2단계 — 워터마크로 차별화 + 도용 억제
같은 공급사를 쓰는 스토어가 많을수록, 최소한의 식별 요소가 필요합니다.
스토어명 워터마크를 일괄 삽입하면 두 가지가 해결됩니다.

https://www.auto-seller.co.kr/marketing/watermark.png

- 내 상세페이지라는 식별 (그대로 복붙한 스토어와 구분)
- 이미지 도용 시 출처가 남는 억제 효과

위치·투명도를 조절해 상품 정보를 가리지 않게 넣는 것이 요령입니다.


### 전체 동선 요약
```
공급사 이미지 확보 (사용 허용 확인)
→ 분할 (마켓 규격 프리셋)
→ 워터마크 (스토어명 일괄)
→ ZIP 다운로드 → 마켓 업로드
```

디자인 감각도, 유료 프로그램도, 외주도 없는 동선입니다.


### 마무리
상세페이지가 등록을 막는 병목이었다면, 오늘 그 병목은 두 단계 가공으로 끝납니다.

https://www.auto-seller.co.kr/ (무료, 회원가입 없음)
