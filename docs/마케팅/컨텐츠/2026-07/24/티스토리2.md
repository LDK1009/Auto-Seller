# [7/24 티스토리 2편차] 발행 19시 | 마크다운 그대로 붙여넣기

> **종류:** A 문제해결 — 상세페이지 조립기
> **요약:** 디자인 없이 상세페이지를 완성하는 선택→병합→분할 절차 (네이버판과 별도 원고)

## 제목

디자인 프로그램 없이 상세페이지 완성하기 — 선택, 병합, 분할 3단계

## 본문

상세페이지가 없어서 등록을 못 하는 경우는 생각보다 많습니다. 포토샵 진입장벽 때문에 상품 준비가 끝나고도 멈추는 겁니다.

이미지 사용이 허용된 위탁 상품이라면, 제작 대신 조립으로 해결됩니다.

### 1단계 — 재료 선택

상품 링크를 조회하면 공급사 상세 이미지가 목록으로 나옵니다. 전부 쓸 필요 없습니다 — 중복 홍보 컷, 타 채널 안내 같은 조각은 빼고 필요한 것만 체크합니다.

### 2단계 — 병합과 정규화

선택한 조각들이 세로로 이어 붙고, 폭이 860px 기준으로 통일됩니다. 원본마다 폭이 달라 생기는 계단 현상이 사라집니다.

### 3단계 — 분할과 출력

에디터에는 이미지 높이 상한이 있어 긴 통이미지는 업로드가 거절됩니다. 조립기가 상한(2만px)에 맞춰 자동으로 잘라줍니다. 출력은 두 가지:

- 파일 다운로드 — 이미지 업로드 방식으로 등록할 때
- HTML 복사 — 에디터의 HTML 모드에 붙여넣을 때 (가장 빠름)

붙여넣기 전 미리보기로 실제 스크롤 화면을 확인할 수 있습니다.

### 정리

상세페이지의 병목은 디자인 실력이 아니라 도구였습니다. 무료로 열려 있습니다: auto-seller.co.kr (회원가입 없음)
