## 제목
쇼핑몰 상품 올리기 전 최종 점검표 — 되돌리기 어려운 실수 12가지

## 본문
상품 등록의 실수는 두 종류입니다.
고치면 되는 실수와, 고치는 순간 더 손해인 실수.
후자 12가지를 점검표로 만들었습니다.


### 왜 "등록 전"인가
등록 후 수정은 공짜가 아닙니다.

- 상품명·카테고리 수정 → 검색 반영이 밀리거나 초기화
- 가격 수정 → 이미 들어온 주문은 옛 가격으로 확정
- 이미지 교체 → 심사 재검토 대상

그래서 점검은 등록 버튼 앞에서 끝나야 합니다.
