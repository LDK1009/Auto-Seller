# [7/24 숏츠 2편차] 발행 18시 — 원링크 여름용품 실측

> 시나리오: 24-2 (원링크 풀 플로우 — 휴대용선풍기 검색)

## 훅 (0~3초)

자막: **"시즌 상품은 속도전 | **등록 준비가 느리면 늦어요** | 타이머 켜고 재봤습니다"** — 스톱워치 스타트

## 시연 + 타이머 (3~24초)

1. 원링크에 "휴대용선풍기" 검색 → 상품 선택 → 시트 생성
2. 정차역 4곳 (카테고리·상품명·판매가·검색설정)

| 초 | 자막 |
|----|------|
| 3~9 | 여름 상품 하나 골라볼게요 |
| 9~13 | 카테고리 바로 잡혔고요 |
| 13~17 | 상품명 검사도 끝났어요 |
| 17~21 | 판매가 계산도 돼 있고요 |
| 21~24 | 태그 복사하면 등록 준비 끝 |

> 자막 규칙: 자막 5 = 정차역 4 + 1

## 결과 카드 (24~30초)

**"등록 준비, [실측: mm:ss]"** → "링크는 프로필에 있어요" / "재보고 싶은 작업, 댓글로"
