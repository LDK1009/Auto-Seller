# [7/27 티스토리] 발행 9시 | 마크다운 그대로 붙여넣기
## 제목
퇴근 후 스마트스토어 4개월 — 부업에서 제일 힘들었던 건 의외의 곳에 있었다

## 본문
퇴근 후 스토어를 운영한 지 몇 달이 지났습니다.
시작 전 걱정했던 것들과 실제로 힘들었던 것은 완전히 달랐습니다.
그 간극을 기록해둡니다.


### 걱정했던 것들 (그런데 별거 아니었던)
- **사업자등록** — 반나절이면 끝나는 절차였습니다
- **세금** — 부업 규모에선 과세유형 선택만 알면 됐습니다
- **CS** — 생각보다 문의가 적고, 템플릿으로 대응 가능했습니다

시작을 막던 공포의 대부분은 절차 문제였고, 절차는 한 번 겪으면 끝났습니다.


### 실제로 힘들었던 것
**반복 작업의 무한함.**

상품 하나 올리는 데 들어가는 손질 — 이미지, 상품명, 가격 계산, 태그.
이게 상품마다, 매번, 똑같이 반복된다는 사실이 제일 무거웠습니다.

백 번을 해도 백한 번째가 빨라지지 않는 일.
실력이 안 쌓이는 노동은 사람을 지치게 합니다.


### 두 번째로 힘들었던 것
**판단할 힘이 안 남는 것.**

반복 작업에 저녁을 다 쓰면, 정작 중요한 "뭘 팔지"는 지친 머리로 대충 정하게 됩니다.
아무거나 올리고, 안 팔리고, 회의감이 오는 순환.
부업을 접는 사람들은 대부분 이 순환에서 이탈합니다.


### 순환을 끊은 방법
노동을 도구로 치환했습니다.

![링크 하나로 등록 준비](https://www.auto-seller.co.kr/marketing/domeggook-import-sheet-living.png)

- 링크를 넣으면 등록 정보가 준비됨
- 이미지는 일괄 처리
- 계산은 자동 역산

남은 저녁 시간에 키워드 숫자를 보며 상품을 고르기 시작했고,

![키워드 숫자 확인](https://www.auto-seller.co.kr/marketing/keyword-stats.png)

그때부터 부업이 "버티는 일"에서 "굴러가는 일"로 바뀌었습니다.


### 시작 전의 나에게
걱정하던 건 대부분 일어나지 않고,
진짜 적은 반복 작업이라는 것.
그리고 그건 의지가 아니라 도구로 이기는 상대라는 것.
