## 영상 제목

> 시나리오: 27-2 (원링크 풀 플로우 — 샤워기헤드 검색)

## 훅 (0~3초)

자막: **"오늘 저녁 등록할 상품 | **준비는 이 시간이면 됩니다** | 타이머 켜고 재봤습니다"** — 스톱워치 스타트

## 시연 + 타이머 (3~24초)

1. 원링크에 "샤워기헤드" 검색 → 상품 선택 → 시트 생성
2. 정차역 4곳 (카테고리·상품명·판매가·검색설정)

| 초 | 자막 |
|----|------|
| 3~9 | 욕실용품 하나 골라볼게요 |
| 9~13 | 카테고리 자동으로 잡혔고요 |
| 13~17 | 상품명 검사 끝났어요 |
| 17~21 | 판매가 마진 계산돼 있고요 |
| 21~24 | 복사해서 붙이면 끝이에요 |

> 자막 규칙: 자막 5 = 정차역 4 + 1

## 결과 카드 (24~30초)

**"등록 준비, [실측: mm:ss]"** → "링크는 프로필에 있어요" / "재보고 싶은 작업, 댓글로"
