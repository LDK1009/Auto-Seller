# [7/27 숏츠 3편차] 발행 21시 — 누끼 + 배경 교체 변주 실측

## 영상 제목

배경 지운 다음이 진짜 고민, 뭘로 채울까

> 시나리오: 27-3 (배경 제거 — 업로드 → 자동 누끼 → 배경 교체(단색/검색 이미지) → 저장)

## 훅 (0~3초)

자막: **"배경 지운 다음이 진짜 고민 | **색으로 채울까요** | 타이머 켜고 재봤습니다"** — 스톱워치 스타트

## 시연 + 타이머 (3~24초)

1. 누끼 도구에 이미지 업로드 → 자동 배경 제거
2. 정차역 3곳 (제거 완료·배경 교체 선택·최종 결과)

| 초 | 자막 |
|----|------|
| 3~9 | 배경부터 지워볼게요 |
| 9~14 | 흰색으로 갈아끼울 수도 있고 |
| 14~19 | 검색해서 찾은 배경도 돼요 |
| 19~24 | 갈아끼운 채로 저장하면 끝 |

> 자막 규칙: 자막 4 = 정차역 3 + 1

## 결과 카드 (24~30초)

**"배경 교체, [실측: mm:ss]"** → "링크는 프로필에 있어요" / "재보고 싶은 작업, 댓글로"
