# [7/27 숏츠] 통화 자막극 2 — "상품명은 뭐라고 지어야 되는데?"

> 포맷: 채팅 UI 자막극 + 화면녹화 (무음성) | 길이: 40초 | 업로드 18시 | 7/20 자막극 1의 후속편

## 말풍선 대본 (0~25초)

```
친구: 야 그 도구 덕에 사진은 해결했는데
친구: 상품명은 뭐라고 지어야 되냐
친구: "예쁜 감성 캠핑 랜턴"이라고 썼는데 안 팔림
나: 검색하는 사람이 "예쁜"으로 검색하겠냐
나: 검색되는 단어로 지어야지
친구: 그걸 내가 어떻게 알아
나: 그것도 만들어놨는데
친구: ??
나: 상품명 쓰면 실시간으로 검사해주고
나: 아예 추천 조합도 나와
친구: 너 뭐냐 진짜
```

## 마무리 화면녹화 (25~38초)

상품명 검사기 — 나쁜 상품명 입력 → 경고 칩 점등 → 추천 상품명 등장. 자막: "친구 때문에 만든 기능 2탄. 무료입니다 — auto-seller.co.kr"

## 설명란

상품명 실시간 검사 + 추천 조합 — auto-seller.co.kr
