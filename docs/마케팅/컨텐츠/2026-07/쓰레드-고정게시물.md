# 쓰레드 고정 게시물 (프로필 랜딩용) — 후보 6종, 대표 필터 후 1개 고정

> 규칙: 게시물·댓글 링크 금지 → 모든 유입은 프로필 링크(auto-seller.co.kr) 경유.
> 첨부 이미지 권장: 원링크 등록 시트 스크린샷 1장 (말보다 화면).
> 프로필 바이오와 세트로 운용 (하단 바이오 후보 참조).

## 후보 ① 개발자 서사형 (추천)

```
셀러는 아닌데, 셀러의 야근을 없애는 사람입니다.

친구가 상품 등록하다 새벽 2시가 됐다길래
도매꾹 링크만 넣으면 등록 준비가 끝나는 도구를 만들었어요.

카테고리, 상품명, 가격, 이미지 편집, 태그까지 —
등록 화면 순서 그대로 나옵니다.

무료고, 가입도 없습니다.
셀러의 시간은 등록이 아니라 "뭘 팔지"에 쓰여야 하니까요.

이 계정에서는 기능 실측 영상과
틈새 키워드 데이터를 올립니다.

써보는 건 프로필 링크에서. 🔗
```

## 후보 ② 가치 제안형 (팔로우 이유 중심)

```
이 계정을 팔로우하면 얻는 것:

① 매주 틈새 키워드 — 검색은 많은데 파는 사람 적은 것만 실측
② 등록 함정 정보 — MOQ, 이미지 사용권, KC 인증
③ 타이머 실측 — "이 작업 몇 초 걸리나" 직접 재서 공개

저는 위탁 셀러의 반복작업을 없애는
무료 도구(오토셀러)를 만드는 개발자입니다.

도매꾹 링크 하나로 등록 준비가 끝납니다.
무료·무가입 — 프로필 링크에서 바로. 🔗
```

## 후보 ③ 문제 공감형 (B축)

```
"부업하려고 잠 줄였는데, 야근이 하나 더 생겼다"

상품 하나 올리는 데 저녁이 통째로 사라지는 분들을 위해
등록 반복작업을 없애는 도구를 만들었습니다.

링크 하나 넣으면 —
배경 지워진 이미지, 계산된 판매가, 카테고리, 태그까지.

무료입니다. 가입도 없습니다.
프로필 링크에서 링크 하나만 넣어보세요. 🔗
```

## 후보 ④ 실측 컨셉 연동형 (숏츠 시리즈와 통일)

```
상품 등록, 타이머 켜고 재는 계정입니다. ⏱

누끼 30장, 등록 폼 12칸, 카테고리 결정 —
"몇 초 걸리나" 전부 실측해서 올립니다.

재는 도구는 제가 만든 오토셀러.
도매꾹 링크 하나로 등록 준비가 끝나는 무료 도구입니다.

직접 재보고 싶으면 프로필 링크에서. 🔗
재봤으면 하는 작업은 댓글로.
```

## 후보 ⑤ 미니멀형

```
도매꾹 링크 하나 → 스마트스토어 등록 준비 끝.

무료. 무가입. 무설치.
만든 사람이 직접 운영하는 계정입니다.

기능 실측과 틈새 키워드 데이터를 올립니다.
프로필 링크에서 바로 써보세요. 🔗
```

## 후보 ⑥ 선언형 (브랜드 슬로건 결합)

```
온라인셀러를
반복작업에서
해방시킵니다.

이 세 줄을 진짜로 만들려고 도구를 만들었습니다.

등록 화면 빈칸 12개를 링크 하나로 채우고,
사진 배경 수십 장을 클릭 한 번에 지웁니다.

무료·무가입.
지금 프로필 링크에서 확인할 수 있습니다. 🔗

매주: 틈새 키워드 데이터 · 기능 실측 · 등록 함정 정보
```

## 프로필 바이오 후보 (고정글과 세트, 150자 내)

- A: `위탁 셀러의 반복작업을 없애는 무료 도구, 오토셀러 만드는 개발자 ⏱ 등록 실측·틈새 키워드 데이터`
- B: `도매꾹 링크 하나 → 등록 준비 끝 | 무료·무가입 | 매주 틈새 키워드 실측`
- C: `상품 등록에 저녁을 쓰지 마세요 | 오토셀러 개발자 | 실측 데이터 계정`

## 운용 규칙

- 고정글은 1개만, 교체는 반응 데이터 보고 (첫 4주는 유지)
- 슬로건 3행(후보 ⑥) 사용 시 줄바꿈 변경 금지 (브랜드 규칙)
- 링크는 어떤 게시물·댓글에도 직접 첨부 금지 — "프로필 링크" 문구로만 유도
- 금지 체크 4항 동일 적용 (수치 약속·평생 무료 표현 없음 확인됨)
