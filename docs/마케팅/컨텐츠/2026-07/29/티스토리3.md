# [7/29 티스토리 3편차] 발행 19시 | 마크다운 그대로 붙여넣기

## 제목

셀러의 세금 캘린더 — 분기마다 10분, 부가세 예측 루틴 만들기

## 본문

세금 스트레스의 근원은 세액이 아니라 불확실성입니다.
"얼마 나올지 모른다"가 사람을 갉아먹지, 예고된 지출은 그냥 지출입니다.
불확실성을 없애는 분기 10분 루틴을 소개합니다.


### 부가세 흐름 이해 30초

셀러가 받는 판매대금에는 부가세가 섞여 있습니다.
그 돈은 내 매출이 아니라 보관 중인 세금입니다.

```
납부세액 = 매출에 붙은 세액 − 매입에서 공제받는 세액
```

이 구조를 모르면 "번 돈"을 다 쓰고 신고 시즌에 당황하게 됩니다.


### 분기 10분 루틴

**1분 — 매출 집계 확인**
마켓 정산 내역에서 분기 매출 합계를 가져옵니다.

**2분 — 매입 집계 확인**
세금계산서 수취분(도매 발주, 부자재 등)을 합칩니다.

**5분 — 계산기 입력**
과세유형 선택, 매출·매입 입력, 예상 세액 확인.

![부가세 계산기](https://www.auto-seller.co.kr/marketing/vat-calculator.png)

**2분 — 세금 통장 이체**
예상 세액만큼 별도 통장으로 옮겨둡니다.
이 2분이 루틴의 핵심입니다 — 계산만 하고 돈을 안 빼두면 의미가 없습니다.


### 루틴이 주는 것

- 신고 시즌의 목돈 충격 제거 (이미 통장에 있음)
- 실질 마진 감각 (세후 기준으로 상품을 보게 됨)
- 과세유형 전환 대비 (매출 추이를 분기마다 보게 됨)


### 판매가 단계에서 미리 반영하기

한 걸음 더 가면, 판매가 역산 때부터 세금을 감안해 마진을 보수적으로 잡는 습관입니다.

![마진 역산](https://www.auto-seller.co.kr/marketing/margin-calculator.png)

세전 순이익에 취하지 않는 것 — 오래 하는 셀러들의 공통 습관입니다.


### 마무리

세금은 관리 대상이지 공포 대상이 아닙니다.
분기 10분, 계산기 한 번, 이체 한 번.
그거면 셀러의 세금 문제 대부분이 "이미 처리된 일"이 됩니다.

https://www.auto-seller.co.kr/ (무료, 회원가입 없음)
