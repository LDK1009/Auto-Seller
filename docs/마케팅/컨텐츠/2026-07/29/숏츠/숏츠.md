# [7/29 숏츠 1편차] 발행 12시 — 과세유형 비교 계산 실측

## 영상 제목

간이과세 vs 일반과세, 세액 직접 비교

> 시나리오: 29-1 (부가세 계산기 — 간이/일반 두 유형으로 같은 값 계산 비교)

## 훅 (0~3초)

자막: **"간이과세 vs 일반과세 | **세액 차이 직접 비교해봐요** | 타이머 켜고 재봤습니다"** — 스톱워치 스타트

## 시연 + 타이머 (3~22초)

1. 부가세 계산기 — 간이 선택 후 계산 → 일반으로 전환 재계산
2. 정차역 3곳 (간이 결과·일반 결과·차이 비교)

| 초 | 자막 |
|----|------|
| 3~8 | 같은 매출로 비교해볼게요 |
| 8~13 | 간이과세 예상 세액이고요 |
| 13~18 | 일반과세로 바꿔서 다시 |
| 18~22 | 차이가 한눈에 보이죠 |

> 자막 규칙: 자막 4 = 정차역 3 + 1

## 결과 카드 (22~28초)

**"유형 비교, [실측: mm:ss]"** → "링크는 프로필에 있어요" / "재보고 싶은 작업, 댓글로"
