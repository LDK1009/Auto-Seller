# [7/29 숏츠 3편차] 발행 21시 — 묶음(MOQ) 마진 계산 변주 실측

## 영상 제목

최소 3개짜리 상품, 낱개로 올리면 손해

> 시나리오: 29-3 (마진 계산기 — MOQ 3 묶음 조건으로 원가 계산 변주)

## 훅 (0~3초)

자막: **"최소 3개짜리 상품 | **낱개 가격으로 올리면 손해예요** | 타이머 켜고 재봤습니다"** — 스톱워치 스타트

## 시연 + 타이머 (3~22초)

1. 마진 계산기 — 묶음 조건(도매가 × 3 + 배송비)으로 입력
2. 정차역 3곳 (묶음 원가 입력·목표 마진·묶음 판매가 결과)

| 초 | 자막 |
|----|------|
| 3~8 | 최소수량 3개 상품이에요 |
| 8~13 | 원가를 3개 기준으로 넣고요 |
| 13~18 | 목표 마진 고르면 |
| 18~22 | 묶음 판매가가 역산돼요 |

> 자막 규칙: 자막 4 = 정차역 3 + 1

## 결과 카드 (22~28초)

**"묶음 계산, [실측: mm:ss]"** → "링크는 프로필에 있어요" / "재보고 싶은 작업, 댓글로"
