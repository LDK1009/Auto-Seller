## ① 10시 — 최소수량 ⭐ (반응 있었던 소재)

**영상:** `29/숏츠/최소 3개짜리 상품, 낱개로 올리면 손해.mp4`

```
"최소 3개"의 뜻을
첫 주문 정산서 보고 알게 되는 것만큼
비싼 수업료가 없더라고요.

낱개 값으로 올리면 팔수록 손해인 상품, 등록 전에 걸러줍니다.

궁금한 스친은 좋아요 + 댓글에 "최소수량" 남겨주세요!
```

**대댓글 준비**
- 경험담 오면 → 공감 + "얼마나 손해 보셨어요?" (구체 사례 수집)
- **이 문장은 대표가 직접 써서 반응 있었던 것** — 그대로 살림

## ③ 21시 — 퇴근 후 (공감형)

```

잠 줄여서 야근 하나 더 하는 기분이라는 얘기,
```
