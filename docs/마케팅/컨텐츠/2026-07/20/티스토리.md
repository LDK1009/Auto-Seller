# [7/20 티스토리] 발행 9시 | 마크다운 그대로 붙여넣기
## 제목
무재고 위탁판매, 해볼 만한가 — 광고에서 말해주지 않는 부분까지

## 본문
"재고 없이 시작하는 온라인 판매"라는 문구는 매력적입니다.
절반은 맞고, 절반은 설명이 생략돼 있습니다.
생략된 부분까지 포함해서 구조를 뜯어봅니다.


### 광고가 말하는 것 — 낮은 진입 비용
사실입니다.
재고를 사놓지 않으니 매입 자금이 필요 없고, 실패 비용이 작습니다.
사업자등록과 통신판매업 신고만 하면 판매 자격은 갖춰집니다.


### 광고가 생략하는 것 1 — 노동의 총량
물건을 안 산다고 일이 없는 게 아닙니다.
상품 하나를 올리는 데 이미지 편집, 카테고리 탐색, 상품명 작성, 가격 계산, 태그 선정이 전부 들어갑니다.
이 반복이 무재고 판매의 실제 비용입니다.


### 광고가 생략하는 것 2 — 경쟁의 구조
같은 도매처를 쓰는 셀러들과 같은 상품을 팔게 됩니다.
차별화 지점은 셋뿐입니다.

| 차별화 지점 | 방법 |
|------------|------|
| 이미지 | 배경 교체·규격 정리로 원본과 다르게 |
| 상품명·태그 | 검색 데이터 기반으로 노출 각도를 다르게 |
| 구성·가격 | 묶음 구성과 마진 역산으로 손해 없는 가격 |


### 광고가 생략하는 것 3 — 품질 통제 불가
상품을 직접 확인하지 않고 파는 구조라, 공급사의 실수가 내 스토어 리뷰로 돌아옵니다.
공급사 선택 기준(배송 속도·이미지 제공·최소구매수량)을 갖고 들어가야 합니다.

### 그래서, 해볼 만한가
돈의 리스크는 작고 시간의 리스크는 큽니다.
그리고 시간 리스크는 도구로 줄일 수 있는 영역입니다.

등록 준비(이미지·카테고리·상품명·가격·태그)를 자동으로 만들어주는 무료 도구로 노동 총량을 먼저 줄여놓고 시작하면, 남는 힘을 상품 선정에 쓸 수 있습니다.
