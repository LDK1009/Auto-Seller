# [7/20 티스토리] 발행 14시 | 마크다운 그대로 붙여넣기

> **종류:** C 정보성 — 유형⑧ 선택 가이드
> **요약:** 위탁판매 광고가 말하는 것 vs 생략하는 것 구도의 판단 가이드 (네이버판과 별도 원고)

## 제목

무재고 위탁판매, 해볼 만한가 — 광고에서 말해주지 않는 부분까지

## 본문

부업 검색을 하다 보면 위탁판매 홍보를 반드시 만나게 됩니다. 대부분 장점만 나열돼 있어서, 결정에 필요한 나머지 절반을 채워봅니다.

### 광고가 말하는 것 (틀린 말은 아님)

- 재고를 사두지 않으므로 악성 재고 위험이 없다
- 시작 자금이 거의 들지 않는다 (도매꾹처럼 개인 구매 가능한 도매처도 있다)
- 컴퓨터만 있으면 시간과 장소를 가리지 않는다
- 접었을 때 손실이 작다

### 광고가 생략하는 것

**첫째, 마진 폭이 좁습니다.** 도매가와 판매가 사이에서 플랫폼 수수료와 배송비가 빠져나가면 남는 건 생각보다 적습니다. 계산 없이 가격을 정하면 적자 판매가 됩니다.

**둘째, 진입장벽이 낮다는 건 경쟁자도 많다는 뜻입니다.** 동일한 도매 상품을 수십 명이 팝니다. 차별화 지점은 아이템 선정 능력과 등록 퀄리티뿐입니다.

**셋째, 노동이 반복적입니다.** 매출은 등록 상품 수에 비례하는 경향이 있는데, 한 개 등록에 이미지 손질과 정보 입력으로 몇 시간이 듭니다. 이 구간에서 대부분 지칩니다.

**넷째, 초반엔 조용합니다.** 등록하자마자 팔리는 일은 드뭅니다. 쌓일 때까지 버티는 기간이 존재합니다.

### 판단 기준

배우는 비용이 낮은 온라인 사업 입문을 원한다면 합리적인 선택입니다. 반대로 단기간 고수익을 기대한다면 구조상 맞지 않고, 그런 약속을 내거는 유료 강의는 걸러야 합니다.

### 그만두는 사람들의 실제 이유

[이미지: 등록 소요 시간 비교 화면]

위탁판매 이탈자의 사유를 관찰해보면 "안 팔려서"보다 "지쳐서"가 많습니다. 구체적으로는 등록 반복작업의 피로가 쌓인 상태에서 초반 무판매 구간을 만나면, 노력 대비 보상이 없다고 느껴 접게 됩니다.

거꾸로 말하면 버티는 사람의 조건도 둘입니다: ① 등록 1건의 비용을 낮춰서 피로 누적을 막고 ② 무판매 구간이 정상이라는 걸 알고 시작하는 것. 이 글의 단점 3번과 4번이 바로 그 두 지점입니다.

### 판단을 위한 마지막 질문

"한 달에 얼마 벌 수 있나요?"는 답이 없는 질문입니다. 변수(카테고리·등록 수·가격 전략)가 사람마다 다르니까요. 대신 답이 있는 질문으로 바꾸면: "내가 등록 1건에 쓰는 비용을 얼마까지 낮출 수 있나?" — 이건 시작 전에 검증 가능하고, 이 값이 낮을수록 생존 확률이 올라갑니다.

반복 노동 문제는 자동화 도구로 상당 부분 해소됩니다. 도매꾹 링크 입력만으로 이미지 편집과 등록 정보 생성이 끝나는 무료 도구를 소개합니다: auto-seller.co.kr
