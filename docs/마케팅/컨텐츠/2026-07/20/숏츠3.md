# [7/20 숏츠 3편차] 발행 21시 — 마진 계산기 실측

> 시나리오: 20-3 (마진 계산기 — 원가 입력 → 판매가 역산)

## 훅 (0~3초)

자막: **"팔수록 손해라는 말 | **계산 안 하고 팔아서 그래요** | 타이머 켜고 재봤습니다"** — 스톱워치 스타트

## 시연 + 타이머 (3~22초)

1. 마진 계산기 진입 → 원가·배송비 입력
2. 정차역 3곳 (수수료 반영·목표 마진 선택·판매가 결과)

| 초 | 자막 |
|----|------|
| 3~8 | 원가랑 배송비만 넣을게요 |
| 8~13 | 수수료는 알아서 반영돼요 |
| 13~18 | 목표 마진을 고르면 |
| 18~22 | 판매가가 역산돼서 나와요 |

> 자막 규칙: 자막 4 = 정차역 3 + 1
