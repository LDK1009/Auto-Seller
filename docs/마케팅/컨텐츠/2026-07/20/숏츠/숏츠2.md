# [7/20 숏츠 2편차] 발행 18시 — 원링크 주방용품 실측

## 영상 제목

도매꾹 링크 하나로 스마트스토어 등록 준비 몇 초

> 시나리오: 20-2 (원링크 풀 플로우 — 주방수납 검색)

## 훅 (0~3초)

자막: **"스마트스토어 등록 준비 | **링크 하나면 끝나는 시대** | 타이머 켜고 재봤습니다"** — 스톱워치 스타트

## 시연 + 타이머 (3~24초)

1. 원링크에 "주방수납" 검색 → 첫 상품 선택
2. 등록 시트 생성 → 정차역 4곳 (카테고리·상품명·판매가·검색설정)

| 초 | 자막 |
|----|------|
| 3~9 | 상품 하나 골라서 눌러볼게요 |
| 9~13 | 카테고리는 이미 정해져 있고요 |
| 13~17 | 상품명은 검사까지 끝났어요 |
| 17~21 | 판매가엔 마진이 계산돼 있어요 |
| 21~24 | 태그는 복사만 하면 돼요 |

> 자막 규칙: 첫 줄 = 액션 구간, 이후 = 정차역 1:1 (정차역 4 + 1 = 자막 5)

## 결과 카드 (24~30초)

**"등록 준비, [실측: mm:ss]"** → "링크는 프로필에 있어요" / "재보고 싶은 작업, 댓글로"

## 설명란 (네이버 클립·릴스·숏츠 공통 — 영상별 1줄 + 고정 꼬리말)

도매꾹 링크 하나로 등록 준비, 타이머 켜고 직접 재봤어요.

오토셀러는 도매꾹 링크 하나로 스마트스토어 등록 준비를 자동으로 해주는 무료 도구예요.
가입도 필요 없어요. 링크는 프로필에 있습니다.
