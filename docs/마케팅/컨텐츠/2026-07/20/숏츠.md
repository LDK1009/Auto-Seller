# [7/20 숏츠] 통화 자막극 1 — "누끼 100장을 퇴근 후에 언제 다 따요?"

> 포맷: 채팅/통화 UI 자막극 (무음성 — 말풍선 애니메이션 + 마지막에 화면녹화) | 길이: 40초 | 업로드 18시

## 구성

- 0~25초: 말풍선 대화 (MARKETING.md A 예시 대본 축약판)
- 25~38초: 실제 화면녹화 — 링크 입력 → 배경 제거 완성

## 말풍선 대본 (축약)

```
친구: 나 부업으로 스마트스토어 시작함
친구: 근데 사진 배경 지우다 새벽 2시 됨
친구: 부업이 아니라 야근 하나 더 생긴 기분
나: 그 상품 도매꾹 링크 보내봐
나: (링크 전송) 여기에 넣어봐
친구: ?? 배경 지워진 게 바로 나오는데?
친구: 이거 뭐 설치해야 돼?
나: 아니. 가입도 없어
친구: 나만 쓰면 안 되냐
나: 이미 다 풀어놨는데? auto-seller.co.kr
```

## 마무리 화면녹화 (25~38초)

원링크에 링크 붙여넣기 → 이미지 배경 제거 클릭 → 완성본. 자막: "친구한테 만들어준 그 도구, 무료입니다"

## 설명란

친구 부탁으로 만들었다가 무료로 풀었습니다 — auto-seller.co.kr
