# [7/20 숏츠 1편차] 발행 12시 — 규정 검사→규격 변환 실측

> 시나리오: 20 (완성 — `npm run episode -- 20`)

## 훅 (0~3초)

자막: **"등록하다 이미지 반려? | **올리기 전에 걸러냅니다** | 타이머 켜고 재봤습니다"** — 스톱워치 스타트

## 시연 + 타이머 (3~24초)

1. 규정 검사에 이미지 20장 업로드 → 자동 판정 (적합/주의 집계)
2. [규격 변환으로 보내기] → 규격 맞추기로 이동 (검사 이미지 이어받기)
3. 1000×1000 프리셋 확인 → [규격 변환] → 전부 완료 → ⏱ 정지

| 초 | 자막 |
|----|------|
| 3~9 | 이미지 20장, 검사부터 할게요 |
| 9~15 | 안 맞는 게 바로 표시돼요 |
| 15~20 | 1000×1000으로 맞출게요 |
| 20~24 | 일괄 변환, 전부 끝났어요 |

> 자막 규칙: 첫 줄 = 액션 구간, 이후 줄 = 정차역과 1:1 매칭 (정차역 수 + 1 = 자막 수 — 빌더가 자동 스냅)
> 정차역 3곳: ①판정 집계 ②1000×1000 프리셋 ③완료 집계

## 결과 카드 (24~30초)

**"20장 검사+변환, [실측: mm:ss]"** (대형 숫자·정중앙) → "링크는 프로필에 있어요" / "재보고 싶은 작업, 댓글로"

## 설명란

대표이미지 규정 검사→규격 변환 실측 — auto-seller.co.kr
