## 제목

스마트스토어 카테고리 선택 기준 — 상위 20개가 이미 답을 알고 있다

## 본문

카테고리를 "느낌상 여기겠지"로 고르는 순간, 노출 게임의 절반을 접고 들어갑니다.
정답을 추측하지 않고 조회하는 방법이 있습니다.


### 카테고리가 노출을 좌우하는 구조

네이버쇼핑 검색은 키워드와 카테고리의 정합성을 봅니다.
"캠핑의자"를 검색하는 사람에게는 캠핑 카테고리의 상품을 우선 보여주는 식입니다.
내 상품이 다른 카테고리에 있으면, 품질과 무관하게 매칭에서 밀립니다.


### 잘못 고른 대가

- 검색 상위 후보에서 제외
- 카테고리별 수수료 차이로 마진 계산 오차
- 등록 후 변경 시 검색 반영 재시작

셋 다 "등록 후에 알게 되는" 비용이라 더 아픕니다.


### 답은 상위 상품에 있다

같은 키워드로 이미 팔리고 있는 상위 상품들의 카테고리 — 그것이 알고리즘이 인정한 정답지입니다.

수동 확인 절차:

1. 키워드로 네이버쇼핑 검색
2. 상위 상품 20개의 카테고리 경로 수집
3. 최빈 경로 채택

논리는 간단하지만 상품마다 반복하기엔 무겁습니다.


### 조회를 자동으로

도매 링크를 붙여넣으면 상위 판매 상품들의 카테고리 분포를 분석해 추천 경로와 근거(상위 20개 중 몇 개 사용)를 보여주는 도구가 있습니다.

![카테고리 추천과 근거 수치](https://www.auto-seller.co.kr/marketing/domeggook-import-sheet-camping.png)

근거 수치가 압도적이면 바로 채택, 갈리면 상위 상품을 직접 열어 확인 — 판단 시간이 몇 초로 줄어듭니다.


### 정리

카테고리 선택은 창의성의 영역이 아닙니다.
이미 검증된 답을 조회해서 따라가는 영역입니다.
추측을 조회로 바꾸는 것, 그게 전부입니다.
