# [7/25 티스토리] 발행 9시 | 마크다운 그대로 붙여넣기

## 제목

쇼핑몰 상품명 작성 규칙 — 노출 잘 되는 이름과 제재당하는 이름의 차이

## 본문

같은 상품인데 어떤 스토어는 검색 첫 페이지에 있고, 어떤 스토어는 안 보입니다.
차이의 상당 부분이 상품명에서 갈립니다.
노출되는 이름과 제재당하는 이름의 경계를 규칙으로 정리합니다.


### 제재당하는 이름의 패턴

| 패턴 | 예 | 왜 걸리나 |
|------|-----|----------|
| 최상급·보장 표현 | 최고, 1위, 100% 보장 | 검증 불가 → 과장 광고 |
| 효능 암시 | 치료, 개선, 다이어트 효과 | 카테고리별 금지어 |
| 기호 남용 | ★특가★, 【무료배송】 | 가독성·검색 매칭 저하 |
| 키워드 나열 | 랜턴 캠핑랜턴 LED랜턴 랜턴추천 | 중복·어뷰징 분류 |
| 글자수 초과 | 수식어 가득한 장문 | 잘림 + 품질 점수 하락 |


### 노출되는 이름의 구조

핵심은 검색어와의 자연스러운 일치입니다.

```
[수식(사실만)] + [핵심 키워드] + [속성·규격] + [수량·구성]
```

- 수식은 사실만: "접이식", "무선", "대용량" (측정 가능한 것)
- 핵심 키워드는 앞쪽: 검색 매칭 가중치
- 속성·규격: 구매 결정 정보이자 롱테일 검색어
- 수량·구성: 묶음 판매면 필수


### 실전에서 지키는 법

규칙을 아는 것과 매번 지키는 건 다릅니다.
상품 수가 늘수록 검사가 밀리기 때문입니다.

도매 링크를 넣으면 금지어·글자수 검사를 통과한 상품명을 제안해주는 도구로 시작점을 잡는 방식이 실용적입니다.

![상품명 자동 제안·검사](https://www.auto-seller.co.kr/marketing/domeggook-import-sheet.png)

제안안에서 속성 단어만 상품에 맞게 바꾸면, 규칙 위반 없이 변주가 됩니다.


### 마지막 점검 3초

발행 전 스스로에게 세 질문만 합니다.

1. 근거 못 대는 단어가 있는가
2. 같은 키워드가 두 번 나오는가
3. 이 이름 그대로 검색할 사람이 있는가

셋 다 통과하면 올릴 자격이 있는 이름입니다.
