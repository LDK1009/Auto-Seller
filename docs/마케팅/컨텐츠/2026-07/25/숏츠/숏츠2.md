# [7/25 숏츠 2편차] 발행 18시 — 카테고리 추천 중심 실측

## 영상 제목

카테고리 잘못 고르면 검색에서 사라진다

> 시나리오: 25-2 (원링크 — 카테고리 추천·근거 수치 정차 중심, 욕실용품 검색어)

## 훅 (0~3초)

자막: **"카테고리 잘못 고르면 | **검색에서 그냥 사라져요** | 타이머 켜고 재봤습니다"** — 스톱워치 스타트

## 시연 + 타이머 (3~22초)

1. 원링크에 "샤워기헤드" 검색 → 상품 선택 → 시트 생성
2. 정차역 3곳 (카테고리 추천 경로·근거 수치(상위 20개 중 N개)·검색설정)

| 초 | 자막 |
|----|------|
| 3~9 | 상품 하나 골라볼게요 |
| 9~14 | 카테고리가 추천돼 있죠 |
| 14~18 | 상위 상품들 근거 수치도 있어요 |
| 18~22 | 추측 말고 조회로 정하면 돼요 |

> 자막 규칙: 자막 4 = 정차역 3 + 1

## 결과 카드 (22~28초)

**"카테고리 확정, [실측: mm:ss]"** → "링크는 프로필에 있어요" / "재보고 싶은 작업, 댓글로"

## 설명란 (네이버 클립·릴스·숏츠 공통 — 영상별 1줄 + 고정 꼬리말)

상위 상품 기반 카테고리 추천, 타이머 켜고 직접 재봤어요.

오토셀러는 도매꾹 링크 하나로 스마트스토어 등록 준비를 자동으로 해주는 무료 도구예요.
가입도 필요 없어요. 링크는 프로필에 있습니다.
