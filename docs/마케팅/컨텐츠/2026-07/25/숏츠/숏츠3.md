## 훅 (0~3초)

자막: **"내 이미지 도용당하기 전에 | **표시부터 해두세요** | 타이머 켜고 재봤습니다"** — 스톱워치 스타트

## 시연 + 타이머 (3~22초)

1. 워터마크에 이미지 업로드 → 텍스트 입력
2. 정차역 3곳 (워터마크 설정·미리보기·일괄 완료)

| 초 | 자막 |
|----|------|
| 3~8 | 이미지 여러 장 올릴게요 |
| 8~13 | 스토어명 넣고 위치 정하고요 |
| 13~18 | 미리보기로 확인하면 |
| 18~22 | 전부 일괄로 박혀서 나와요 |

> 자막 규칙: 자막 4 = 정차역 3 + 1

## 결과 카드 (22~28초)

**"워터마크, [실측: mm:ss]"** → "링크는 프로필에 있어요" / "재보고 싶은 작업, 댓글로"
