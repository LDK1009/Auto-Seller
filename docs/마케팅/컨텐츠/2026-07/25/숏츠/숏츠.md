# [7/25 숏츠 1편차] 발행 12시 — 상품명 검사 중심 실측

## 영상 제목

상품명 짓다 30분, 검사까지 끝난 게 나온다

> 시나리오: 25-1 (원링크 — 상품명 제안·검사 결과 정차 중심, 문구 검색어)

## 훅 (0~3초)

자막: **"상품명 짓다 30분 | **검사까지 끝난 게 나옵니다** | 타이머 켜고 재봤습니다"** — 스톱워치 스타트

## 시연 + 타이머 (3~22초)

1. 원링크에 "데스크정리함" 검색 → 상품 선택 → 시트 생성
2. 정차역 3곳 (상품명 제안·검사 통과 표시·추천 키워드)

| 초 | 자막 |
|----|------|
| 3~9 | 상품 하나 불러올게요 |
| 9~14 | 상품명이 제안돼 있어요 |
| 14~18 | 금지어 검사도 통과 상태고요 |
| 18~22 | 키워드 후보까지 골라주네요 |

> 자막 규칙: 자막 4 = 정차역 3 + 1

## 결과 카드 (22~28초)

**"상품명 완성, [실측: mm:ss]"** → "링크는 프로필에 있어요" / "재보고 싶은 작업, 댓글로"

## 설명란 (네이버 클립·릴스·숏츠 공통 — 영상별 1줄 + 고정 꼬리말)

금지어 검사 끝난 상품명, 타이머 켜고 직접 재봤어요.

오토셀러는 도매꾹 링크 하나로 스마트스토어 등록 준비를 자동으로 해주는 무료 도구예요.
가입도 필요 없어요. 링크는 프로필에 있습니다.
