# [7/25 쓰레드] 5개 — 10·12·15·19·22시

## ① 10시 — 블로그 분해 · 연작 (1/4)

**본문 (훅):**
상품명 때문에 제재당하는 단어들, 의외로 다들 씁니다.
"최고", "1위", "100% 보장" — 전부 위험군이에요.
걸리는 유형 정리했습니다. (스레드로 이어집니다)

**댓글 1:**
걸리는 4형: 최상급·보장 표현 / 효능 암시 / 기호 남용(★【】) / 키워드 나열.
공통점은 "근거를 못 대는 말"이라는 거예요.

**댓글 2:**
안전한 뼈대는 이거 하나면 됩니다.
수식(사실만) + 핵심 키워드 + 속성·규격 + 수량.
"접이식 캠핑의자 경량 알루미늄 2개 세트" 같은 식.

**댓글 3 (CTA):**
금지어·글자수 검사를 자동으로 하는 방법까지는
프로필 링크에 정리해뒀어요.

## ② 12시 — 기능 팁 + 스크린샷

**본문:**
카테고리 고민될 땐 내 감 말고
그 키워드 상위 상품들이 실제로 등록된 카테고리를 보세요.
링크 넣으면 상위 20개 분포로 추천해주는 도구도 있어요.

**첨부:** domeggook-import-sheet-camping.png (카테고리 추천 화면)

## ③ 15시 — 공감 한 줄

**본문:**
상품명 30분 고민해서 지었는데
제재 안내 한 통에 5분 만에 바꾸던 날,
잘 짓는 것보다 안 걸리는 게 먼저구나 싶었어요.

## ④ 19시 — 사실 팁 + 질문 (설문 활용 가능)

**본문:**
상품명 지을 때 제일 오래 걸리는 구간이 어디세요?

**설문 항목:** 키워드 고르기 / 금지어 피하기 / 글자수 맞추기 / 그냥 다 어려움

**댓글 (팁):**
뭘 골랐든 공통 지름길은 "검사 끝난 제안에서 시작하기"예요.
백지에서 짓는 것과 통과된 안을 다듬는 건 난이도가 다릅니다.

## ⑤ 22시 — 공감 반전 (마무리)
