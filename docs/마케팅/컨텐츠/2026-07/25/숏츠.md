# [7/25 숏츠] 타이머 실측 #10 — 상품명, 짓고 검사받는 데 몇 초?

> **종류:** A 문제해결 — 타이머 실측 챌린지 (상품명 검사기)
> **요약:** 나쁜 상품명 입력→경고 칩 점등→수정→점수 등급 통과까지 실측
> 제작(PC): 크롬 세로 창 + 웹 스톱워치 | 25~30초 | 18시

## 훅 (0~3초)

자막: **"상품명 30분 고민하던 일, 타이머 켜고 재봤습니다"** — 스톱워치 스타트

## 시연 + 타이머 (3~24초)

1. "★특가★ 캠핑랜턴 랜턴 최저가" 입력 → 경고 칩 즉시 점등 (크롭 줌)
2. 단어 수정할 때마다 칩이 초록으로 전환
3. 추천 상품명 조합 확인 → 점수 등급 통과 → ⏱ 정지

| 초 | 자막 |
|----|------|
| 3~9 | 쓰는 즉시 걸리는 데 불이 들어오고 |
| 9~15 | 특수문자·홍보문구·브랜드 위험어까지 |
| 15~20 | 고칠 때마다 점수가 올라갑니다 |
| 20~24 | 추천 조합도 자동 |

## 결과 카드 (24~30초)

**"상품명 완성, [실측: mm:ss]"** → "무료·무가입 — 오토셀러" / "재보고 싶은 작업, 댓글로"
