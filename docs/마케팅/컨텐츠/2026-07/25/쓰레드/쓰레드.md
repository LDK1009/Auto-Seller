# [7/25 쓰레드] 5개 — 10·12·15·19·22시 (홀수날: 댓글 연작 3 + 설문 1 + 캔버스 1)

## ① 10시 — 댓글 연작 (1/3)

**본문 (훅):**
상품명 때문에 제재당하는 단어들, 의외로 다들 써요.
"최고", "1위", "100% 보장" — 전부 위험군. (이어서)

**댓글 1:**
걸리는 4형: 최상급·보장 표현 / 효능 암시 / 기호 남용(★【】) / 키워드 나열.
공통점은 "근거를 못 대는 말"이라는 거예요.

**댓글 2:**
안전한 뼈대는 하나면 돼요.
수식(사실만) + 핵심 키워드 + 속성·규격 + 수량.
예: 접이식 캠핑의자 경량 알루미늄 2개 세트.

**댓글 3 (CTA):**
금지어·글자수 검사를 자동으로 하는 방법은
프로필 링크에 정리해뒀어요.

## ② 12시 — 댓글 연작 (1/2)

**본문 (훅):**
카테고리 고민될 땐 내 감 말고
그 키워드 상위 상품들이 실제로 등록된 카테고리를 보세요. (이어서)

**이미지 (Ctrl+클릭 → 파일 열어 첨부):** [카테고리 추천 화면](../../../../../../public/marketing/domeggook-import-sheet-camping.png)

**댓글 1:**
링크 넣으면 상위 20개 분포로 추천해주고
근거 수치까지 나와요.
카테고리는 취향이 아니라 데이터 문제거든요.

**댓글 2 (CTA):**
잘못 고르면 검색에서 통째로 빠질 수 있어요.
조회로 정하는 법은 프로필 링크에.

## ③ 15시 — 댓글 연작 (1/2)

**본문 (훅):**
상품명 30분 고민해서 지었는데
제재 안내 한 통에 5분 만에 바꾸던 날. (이어서)

**댓글 1:**
그때 알았어요 — 잘 짓는 것보다 안 걸리는 게 먼저구나.
상품명은 광고 카피가 아니더라고요.
멋진 말은 상세페이지에서, 상품명은 검색될 사실만.

**댓글 2 (CTA):**
검사 끝난 상품명 제안에서 시작하는 법은
프로필 링크에.

## ④ 19시 — 설문

**본문:**
상품명 지을 때 제일 오래 걸리는 구간이 어디세요?

**설문 항목:** 키워드 고르기 / 금지어 피하기 / 글자수 맞추기 / 그냥 다 어려움

**댓글 (팁):**
뭘 골랐든 공통 지름길은 "검사 끝난 제안에서 시작하기"예요.
백지에서 짓는 것과 통과된 안을 다듬는 건 난이도가 달라요.

## ⑤ 22시 — 캔버스 (본문 텍스트 카드)

**본문 (캔버스 카드):**
[텍스트 카드 · 배경색]
안 걸리는 상품명 뼈대
수식(사실만) + 핵심 키워드 + 속성·규격 + 수량
예: 접이식 캠핑의자 경량 알루미늄 2개 세트
피할 것: 최상급·보장 / 효능 암시 / 기호 남용 / 키워드 나열
[/카드]
