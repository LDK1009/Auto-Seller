# 7/25 쓰레드 — 댓글 유도형 3개

발행: 10시 · 15시 · 21시

---

## ① 10시 — 워터마크

**영상:** `25/숏츠/내 상품 이미지 도용 막는 법 (워터마크 일괄).mp4`

```
공들여 만든 상세 이미지, 그대로 퍼가는 사람들 있잖아요.

여러 장에 한 번에 워터마크 넣는 거 만들었어요.
문구든 로고든 위치만 잡으면 끝이에요.

궁금한 스친은 좋아요 + 댓글에 "워터마크" 남겨주세요!
```

**대댓글 준비**
- "몇 장까지요?" → "제한 없이 한 번에 올리시면 순서대로 처리돼요"
- "투명도 조절도 돼요?" → "네, 위치랑 크기도요"

---

## ② 15시 — 상품명

**영상:** `25/숏츠/상품명 짓다 30분, 검사까지 끝난 게 나온다.mp4`

```
상품명 100자 채우는 데 30분씩 걸리시나요?

금지어 들어갔는지, 글자수 넘었는지까지 검사된 상태로 나오게 만들었어요.

궁금한 스친은 좋아요 + 댓글에 "상품명" 남겨주세요!
```

**대댓글 준비**
- "금지어가 뭐예요?" → "홍보문구나 지재권 위험한 단어들이요. 실시간으로 표시돼요"
- "AI로 만드나요?" → "지금은 상품 정보 조합 + 검사 방식이에요"

---

## ③ 21시 — 카테고리 (답 얻는 게 목적)

**영상:** `25/숏츠/카테고리 잘못 고르면 검색에서 사라진다.mp4`

```
카테고리 잘못 고르면 검색에서 아예 안 뜨더라고요.

근데 애매한 상품일수록 어디 넣어야 할지 모르겠고요.
다들 어떻게 정하세요?

궁금한 스친은 좋아요 + 댓글에 "카테고리" 남겨주세요!
```

**대댓글 준비**
- 답변 오면 → 방법 물어보기 ("경쟁사 보고 정하시는 편인가요?")
- **수집 목적:** 카테고리 선정 방식 → 추천 로직 개선 근거
