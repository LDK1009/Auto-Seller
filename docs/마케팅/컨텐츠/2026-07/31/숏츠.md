# [7/31 숏츠] 타이머 실측 #16 — 상세페이지 완성까지 몇 초?

> **종류:** A 문제해결 — 타이머 실측 챌린지 (상세 조립·분할·HTML 복사)
> **요약:** 상세 이미지 선택→병합·분할→HTML 복사→에디터 붙여넣기까지 실측
> 제작(PC): 크롬 세로 창 + 웹 스톱워치 | 25~30초 | 18시

## 훅 (0~3초)

자막: **"상세페이지 만들기, 타이머 켜고 재봤습니다"** — 긴 상세 원본 스크롤 + 스톱워치 스타트

## 시연 + 타이머 (3~24초)

1. 상세 이미지 목록에서 쓸 조각만 체크 (크롭 줌)
2. 세로 병합 + 높이 제한 자동 분할
3. [HTML 복사] → 스마트스토어 [HTML 작성]에 붙여넣기
4. 상세설명 완성 → ⏱ 정지

| 초 | 자막 |
|----|------|
| 3~9 | 쓸 이미지만 고르면 |
| 9~15 | 병합·분할은 자동 |
| 15~20 | HTML 복사해서 |
| 20~24 | 붙여넣으면 상세 완성 |

## 결과 카드 (24~30초)

**"상세페이지, [실측: mm:ss]"** → "무료·무가입 — 오토셀러" / "8월엔 악조건 챌린지 — 재볼 작업 댓글로"
