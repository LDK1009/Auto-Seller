# [7/31 블로그 3편차] 발행 20시
## 제목
부업 한 달차의 솔직한 기록 — 남은 것과 버린 것

## 본문
한 달 전, 반신반의로 위탁판매를 시작했습니다.
월말이라 정산 대신 기록을 해봅니다.
돈 얘기는 빼고 — 한 달간 남은 것과 버린 것에 대해서.

---

### 버린 것 1 — "대박 아이템" 환상
시작 전엔 숨은 대박 상품을 찾는 게임인 줄 알았습니다.
한 달 해보니 이건 발견의 게임이 아니라 절차의 게임이었습니다.
검색량 보고, 경쟁 보고, 마진 계산하고 — 절차를 도는 사람이 이기는 구조.

### 버린 것 2 — 밤샘 작업
초반엔 등록 하나에 저녁을 다 썼습니다.
지금은 링크 붙여넣고 확인·복사하는 몇 분으로 끝납니다.

![등록 준비 자동화](https://www.auto-seller.co.kr/marketing/domeggook-import-sheet.png)

노동을 버리니 판단할 시간이 생겼고, 판단이 쌓이니 보는 눈이 달라졌습니다.

### 버린 것 3 — 조회수 확인 중독
등록 직후 순위를 하루 열 번 검색하던 습관.
초반 침묵이 기본값이라는 걸 알고 나서 끊었습니다.
확인은 주 단위로, 판단은 월 단위로 — 그래야 데이터가 말할 시간이 생깁니다.

### 남은 것 1 — 확인 절차
KC 경고 확인, 상품명 검사, 이미지 규정 검사, 마진 역산.
이 네 칸의 체크리스트가 한 달의 가장 큰 자산입니다.
절차가 있으니 겁이 줄고, 겁이 줄으니 계속하게 됩니다.

![체크 절차의 도구들](https://www.auto-seller.co.kr/marketing/image-check.png)

### 남은 것 2 — 숫자 보는 습관
키워드 검색량, 경쟁강도, 역산 마진.
숫자를 보고 고르는 습관이 생기니 실패도 데이터가 됩니다.

![키워드 숫자](https://www.auto-seller.co.kr/marketing/keyword-stats.png)

### 남은 것 3 — 다음 달 계획
한 달을 돌아보니 다음 달에 뭘 다르게 할지가 보입니다.
반응 있던 카테고리에 등록을 몰고, 조용한 키워드는 접고.
회고가 되는 부업 — 이게 지속 가능하다는 감각의 정체인 것 같습니다.
