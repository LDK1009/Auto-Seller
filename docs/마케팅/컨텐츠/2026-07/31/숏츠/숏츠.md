# [7/31 숏츠 1편차] 발행 12시 — 원링크 풀 플로우 총집편 실측

## 영상 제목

상품 등록 준비 전 과정, 처음부터 끝까지

> 시나리오: 31-1 (원링크 — 검색부터 전 섹션 훑기까지 풀 코스, 생활잡화 검색어)

## 훅 (0~3초)

자막: **"상품 등록 준비 전 과정 | **처음부터 끝까지 재봤습니다** | 타이머 스타트"** — 스톱워치 스타트

## 시연 + 타이머 (3~26초)

1. 원링크에 "빨래바구니" 검색 → 상품 선택 → 시트 생성
2. 정차역 5곳 (상품 정보·카테고리·상품명·판매가·검색설정)

| 초 | 자막 |
|----|------|
| 3~9 | 검색부터 시작할게요 |
| 9~13 | 도매가랑 조건 확인되고요 |
| 13~16 | 카테고리 잡혔어요 |
| 16~19 | 상품명 검사 통과 |
| 19~23 | 판매가 마진 계산 완료 |
| 23~26 | 태그까지, 전 과정 끝 |

> 자막 규칙: 자막 6 = 정차역 5 + 1

## 결과 카드 (26~32초)

**"전 과정, [실측: mm:ss]"** → "링크는 프로필에 있어요" / "재보고 싶은 작업, 댓글로"
