# [7/31 티스토리] 발행 14시 | ⚠️ 각 도구 현재 상태 재확인 | 마크다운 그대로 붙여넣기

> **종류:** C 정보성 — 유형③ TOP5 리스트
> **요약:** 조사→소싱→등록→분석 워크플로 순서로 무료 도구 5선 배치 (네이버판과 별도 원고)

## 제목

온라인 셀러 필수 무료 도구 5선 — 조사부터 등록·분석까지 (직접 사용 후기)

## 본문

유료 셀러 솔루션은 월 구독료가 만만치 않습니다.
그런데 초보 단계에서 필요한 기능 대부분은 무료 조합으로 해결됩니다.
실사용 기준으로 다섯 개를 추립니다.


### ① 네이버 검색광고 — 키워드 도구

검색량 원본 데이터가 여기서 나옵니다.
광고주 대상 화면이라 UI가 셀러 친화적이진 않지만, 데이터 신뢰도는 원천 소스답게 확실합니다.
광고 계정 개설이 선행 조건.


### ② 네이버 데이터랩 — 쇼핑인사이트

분야별 검색 추이와 인구통계를 무료로 보여주는 공식 서비스. 한계는 키워드 단위가 아닌 카테고리 단위 조회라는 점입니다.


### ③ 오토셀러 (이해관계 고지: 필자가 개발)

①②의 데이터를 셀러 시점으로 재구성한 도구입니다.
키워드 틈새 판정과 13종 차트, 그리고 도매꾹 링크 기반 등록 자동화(분류 추천·이름 검사·가격 역산·옵션 엑셀·이미지 편집·태그)가 한 흐름으로 이어집니다.
무료·비가입이며 이미지가 외부로 전송되지 않는 구조입니다.
직접 만든 도구를 목록에 올리는 만큼, 나머지 넷과 비교해보고 판단하시길 권합니다.


### ④ 스마트스토어 판매자센터 — 통계

판매 시작 후의 필수품. 유입 경로와 전환 데이터로 "왜 팔렸는지"를 복기할 수 있습니다.
판매 전 시장조사 기능은 없다는 것만 유의.


### ⑤ 도매꾹

도구라기보다 소싱 인프라. 개인 구매가 열려 있어 사업자 발급 전에 시장 테스트가 가능합니다.
상품별 최소구매수량과 이미지 사용 조건 확인은 습관화해야 합니다.


### 추천 워크플로

②또는③으로 시장 파악 → ⑤에서 상품 확보 → ③으로 등록 → ④로 성과 복기. 이 사이클 전체에 비용이 들지 않습니다.

auto-seller.co.kr (무료, 회원가입 없음)


### 유료 솔루션과의 경계선

[이미지: 무료 워크플로 흐름도]

이 무료 스택의 적용 범위를 정직하게 그으면: 단일 마켓(스마트스토어) 중심, 등록 수 수백 개 이하, 1인 운영까지입니다.
그 너머 — 멀티 마켓 동시 운영, 대량 재고 연동, 팀 단위 권한 관리 — 는 유료 솔루션의 영역이 맞습니다.

중요한 건 순서입니다.
유료 솔루션의 월 구독료는 "팔리는 구조가 검증된 뒤"에는 투자지만, 검증 전에는 고정비입니다.
무료 스택으로 검증을 끝내고 규모가 요구할 때 넘어가면, 도구 비용이 항상 매출 뒤에 옵니다.


### 이 목록의 갱신 원칙

도구는 바뀝니다.
무료였던 게 유료가 되고, 없던 기능이 생깁니다.
이 목록은 실사용 기준으로 반기마다 재검증할 예정이고, 달라진 게 있으면 글을 수정하겠습니다.
목록형 글에서 중요한 건 목록 자체보다 "지금도 맞는가"이니까요.
