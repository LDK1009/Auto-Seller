# [7/31 티스토리] 발행 9시 | 마크다운 그대로 붙여넣기
## 제목
온라인 셀러 무료 도구 지도 — 조사부터 등록·세금까지 한 흐름으로

## 본문
셀러 도구 추천 글은 많지만, 대부분 "좋은 도구 나열"에 그칩니다.
실무에서 중요한 건 나열이 아니라 연결 — 작업 흐름 순서로 도구 지도를 그립니다.


### 작업 흐름과 도구 매핑
| 단계 | 할 일 | 도구 |
|------|-------|------|
| 조사 | 수요·경쟁 숫자 확인 | 키워드 분석 |
| 소싱 | 도매 상품 탐색·조건 확인 | 도매꾹 검색 |
| 등록 준비 | 카테고리·상품명·가격·태그 | 원링크 (링크 붙여넣기) |
| 이미지 | 누끼·규격·검사·분할·워터마크 | 이미지 도구 5종 |
| 계산 | 마진·광고·세금 | 계산기 3종 |


### 각 단계 핵심 화면
**조사 — 키워드 분석**
검색량·상품 수·경쟁강도가 한 번에.

**등록 준비 — 원링크**

https://www.auto-seller.co.kr/marketing/domeggook-import-sheet-living.png

**이미지 — 검사와 변환**
반려 사유 사전 판정 → 걸린 것만 일괄 변환.

https://www.auto-seller.co.kr/marketing/image-check.png

**계산 — 역산과 세금**

https://www.auto-seller.co.kr/marketing/vat-calculator.png


### "연결"이 왜 기준인가
도구가 흩어져 있으면 파일 다운로드 → 업로드 → 복사 → 붙여넣기의 왕복이 생깁니다.
왕복이 곧 부업의 피로입니다.
위 지도의 도구들은 한 서비스 안에서 이어져 있어 왕복이 없습니다 — 전부 무료·무가입·브라우저 처리.


### 사용 우선순위 제안
처음이라면 전부 쓸 필요 없습니다.

1. 원링크 (등록 준비 자동화 체감이 제일 큼)
2. 키워드 분석 (소싱 기준이 생김)
3. 이미지 검사·변환 (반려 스트레스 제거)

세 개가 익으면 나머지는 필요할 때 자연히 붙습니다.
