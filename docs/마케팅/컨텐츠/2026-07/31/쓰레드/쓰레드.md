※ 월말 — 7월 성과 회고 + 8월 방향 확인용 질문 포함

## ① 10시 — 누끼 ⭐ (설문 1위 소재)

**영상:** `31/숏츠/이미지 여러 장 배경 제거, 저녁이 사라지던 그 작업.mp4`

```
상품 20개 올리려면 배경 지우는 것만 몇 시간이더라고요.
포토샵으로 하나씩 따다가 새벽 됐다는 얘기, 여러 번 들었어요.

한 번에 다 되게 만들어봤어요.

궁금한 스친은 좋아요 + 댓글에 "누끼" 남겨주세요!
```

**대댓글 준비**
- "몇 장까지요?" → "한 번에 여러 장 올려두면 순서대로 처리돼요"
- "화질 깨지나요?" → "원본 해상도 유지돼요"

## ③ 21시 — 8월 방향 질문 ⭐ (제품 우선순위 결정용)

**영상:** `31/숏츠/상품 등록 준비 전 과정, 처음부터 끝까지.mp4`

```
7월 한 달 동안 셀러분들 얘기 들으면서
이미지 작업이 제일 오래 걸린다는 걸 알게 됐어요.

8월엔 뭘 더 만들면 도움이 될까요?
```
