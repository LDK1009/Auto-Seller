## ② 15시 — 교차 소싱 #4 (환절기 가습기) ⭐ 시리즈

**이미지:** 가습기 키워드 분석 캡처 (검색 30,600·경쟁 "해볼만") — 발행 임박 시 촬영

```
7월 말인데 벌써 8월 준비 얘기예요.

여름 상품은 지금 떼면 늦어요. 이미 경쟁 끝나 있거든요.
시즌 상품은 검색 오르기 한 달 전에 움직여야 해요.

저는 지금 환절기 상품 봐요.
가습기 같은 거요. 8월 말부터 검색 오르기 시작하거든요.

여름 막차 타지 말고, 다음 시즌을 미리 잡으세요.

"소싱" 남기면 8월 후보 같이 봐요.
```

**댓글 오면**
- "벌써 가습기요?" → "검색 오르기 시작할 때 준비해야 피크에 팔아요. 피크엔 이미 경쟁 끝나 있어요"
- "여름 상품은 아예 안 돼요?" → "재고 소진용이면 몰라도, 신규로 떼긴 늦었어요"

> 데이터: 가습기 검색 30,600·경쟁 해볼만(19.17) / 미니가습기 4,700·해볼만(30.87, 소형이라 위탁 부담 적음).
> 발행 전 검색 트렌드로 "8월 상승" 재확인 권장 (환절기 상품은 8월 하순부터 오름).
