# [7/31 블로그] 발행 10시
## 제목
초보 위탁 셀러가 실제로 쓰는 무료 도구 모음 (2026년 기준)

## 본문
위탁판매를 시작하면 도구 검색부터 하게 됩니다.
문제는 대부분 "무료인 줄 알았는데 핵심 기능은 유료"라는 것.
설치·가입 없이 브라우저에서 바로 쓰는 무료 도구를 작업 단계별로 정리합니다.

---

### 1. 아이템 조사 — 키워드 분석
검색량·등록 상품 수·경쟁강도를 한 화면에서 조회합니다.
아이템 선정을 감이 아니라 숫자로 하는 출발점입니다.

https://www.auto-seller.co.kr/marketing/keyword-stats.png

### 2. 소싱 — 도매꾹 검색
도매 상품을 인기순으로 훑고, 최소구매수량·배송비 조건을 확인합니다.

https://www.auto-seller.co.kr/marketing/domeggook-search.png

### 3. 등록 준비 — 원링크
도매꾹 링크를 붙여넣으면 카테고리·상품명(검사 완료)·판매가(마진 역산)·태그 후보까지 자동 생성됩니다.
KC 인증 대상 가능성 경고까지 포함 — 등록 준비의 중심 도구입니다.

https://www.auto-seller.co.kr/marketing/domeggook-import-sheet.png

### 4. 이미지 가공 — 누끼·규격·검사·분할·워터마크
- 배경 제거: 여러 장 일괄, 배경 교체 가능
- 규격 맞추기: 1000×1000 등 프리셋 일괄 변환
- 규정 검사: 반려 사유 사전 판정
- 상세 분할: 긴 상세 이미지를 마켓 규격으로 절단
- 워터마크: 도용 억제용 스토어명 일괄 삽입

전부 브라우저 내 처리라 이미지가 서버로 나가지 않습니다.

https://www.auto-seller.co.kr/marketing/image-check.png

### 5. 계산 — 마진·광고 손익·부가세
판매가 역산, 손익분기 ROAS, 예상 부가세까지 계산기 세 종.
"팔수록 손해" 구조를 등록 전에 차단합니다.

https://www.auto-seller.co.kr/marketing/margin-calculator.png

---

### 정리 — 도구 선택의 기준
셀러 도구는 개별 성능보다 연결이 중요합니다.
조사 → 소싱 → 등록 준비 → 이미지 → 계산이 한 흐름으로 이어지면 파일 왕복과 복붙 노동이 사라집니다.
위 도구들은 한 서비스 안에서 전부 무료·무가입으로 이어집니다.

**https://www.auto-seller.co.kr/ (무료·무가입)**
