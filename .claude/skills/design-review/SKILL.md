# 오토셀러 디자인 리뷰 (MUI/Emotion 스택용)

리뷰 대상: **$ARGUMENTS** (미지정 시 최근 변경된 UI 파일)

StyleSeed의 ss-review를 우리 스택에 맞게 번안한 스킬이다.
판단 기준 문서를 먼저 참조할 것:
- `docs/BRAND.md` 7장 (디자인 원칙 6개) · 5장 (UI 문구)
- `docs/design/DESIGN-LANGUAGE.md` (세부 규칙 — 특히 §3 텍스트 위계, §12 그림자, §18 금지 규칙, §24 인터랙션, §26 투명도)
- `src/shared/theme/theme.ts` (우리 토큰의 단일 진실)

## 체크리스트

### 1. 토큰 준수 (하드코딩 금지)
- [ ] hex 색상 하드코딩 없음 — `theme.palette.*` 토큰 사용 (체커보드 패턴 등 문서화된 예외만 허용)
- [ ] 간격은 `theme.spacing()` — 임의 px 금지
- [ ] 그림자·라운드는 테마 토큰 — MUI 기본 elevation 남용 금지 (원칙: 얇은 보더 + 최소 그림자)
- [ ] 서체는 Pretendard 스택 상속 — fontFamily 재정의 금지

### 2. Emotion/MUI 컨벤션 (프로젝트 규칙)
- [ ] styled 컴포넌트는 파일 하단 모음, PascalCase
- [ ] 조건부 prop은 `$` prefix + `styled(컴포넌트, transientOptions)` (DOM 전파 방지)
- [ ] `styled(MUI컴포넌트)`에 `$` prop 쓸 때 transientOptions 누락 여부
- [ ] 컴포넌트 파일당 1개, props 타입 명시

### 3. 텍스트 위계 (DESIGN-LANGUAGE §3)
- [ ] 화면당 위계가 3단계 이상 구분되는가 (제목 크고 무겁게 / 본문 / 보조는 작고 연하게)
- [ ] 같은 크기·같은 굵기의 텍스트가 벽처럼 나열되지 않는가
- [ ] 숫자 표기: 콤마·단위·tabular 정렬 (§2 숫자 규칙)

### 4. 레이아웃·화면 구성 (BRAND 7장)
- [ ] **화면당 주 CTA 1개** — contained 버튼이 화면에 2개 이상이면 위반 의심
- [ ] 도구 화면은 밀도, 안내 화면은 여백 — 균질 밀도 금지
- [ ] 카드 내부 구조 (§8): 제목-값-보조 순서, 내부 구분 과다 금지

### 5. 모션 (BRAND 7장 원칙 4)
- [ ] 상태 변화 피드백에만 모션 — 장식 모션 금지
- [ ] 150~300ms 범위, 진입 stagger는 1회
- [ ] `prefers-reduced-motion` 존중 (framer-motion 사용 시)

### 6. 접근성
- [ ] 인터랙티브 요소 터치 타겟 ≥ 44×44
- [ ] 아이콘 버튼에 `aria-label`
- [ ] 텍스트 대비 WCAG AA (본문 4.5:1)
- [ ] 색상만으로 상태를 구분하지 않음 (라벨·아이콘 병행)

### 7. UI 문구 (BRAND 5장)
- [ ] 버튼: 동사형 명령 3~8자 / 진행형 "~중…"
- [ ] 토스트: "~가 완료되었습니다" / 에러: 원인+다음 행동
- [ ] 이모지·느낌표 남용 없음

## 출력 형식

1. **위반 목록** — `파일:라인` + 위반 규칙(§ 번호) + 심각도(🔴 원칙 위반 / 🟡 개선 권장)
2. **수정안** — 각 위반의 구체적 코드 수정 방향
3. **총평** — 화면이 "AI가 만든 티"에서 벗어났는지 한 줄 판정

수정까지 요청받은 경우에만 코드를 고친다. 기본은 리뷰 보고만.
