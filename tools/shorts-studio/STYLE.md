## 2. 녹화 (코드 강제 — recorder·humanize)

- **모바일 뷰 414×896** (DPR 2 캡처) — 시청자 폰 화면 재현
- 로드 후 **2.2초 전체 화면 파악** → 액션 → 종료 **2초 버퍼**. 로딩 공백은 자동 트림
- **통스크롤 금지** — 강조 대상마다 `showSection()` 정차 (스크롤 → 정착 → 1.8~2.2초 머묾). 정차역이 줌·자막의 기준점
- 타이핑 글자당 70ms, 모든 대기에 ±15~30% 지터 (기계적 균일함 금지)
- 가짜 커서: 550ms easing 이동 + 클릭 리플

## 3. 영상 구성 (코드 강제 — TimerShort)

```
0~3초    훅 — 풀스크린 타이포 (팝 등장, **단어** = 형광펜)
3초~     시연 — 폰 카드 + 타이머 + 캡션. 기본 전체 화면, 정차역마다 1.9배 줌인(0.8초 전환)
끝 5초   엔딩 — 화면 위 반투명 오버레이 + 실측 스탬프(-6° 쾅) + ✓리캡 스태거 + 소형 CTA
```
- 엔딩은 **별도 카드로 화면을 끊지 않음** — 마지막 화면이 비쳐 보이는 오버레이
- BGM 볼륨 0.16 (은은하게), 완료 효과음은 엔딩 진입 시

## 4. 문체 (대본 작성 규칙 — 숏츠.md)

- **전부 구어체 해요체**: "복사하면 끝" ❌ → "복사만 하면 돼요" ⭕
- 자막 화면당 1문장, **22자 이내**
- 훅: 1~2줄, 핵심 단어에 `**형광펜**` 마크업, 셀러 전문용어를 첫 줄에 금지 (예비층 훅 4:1 규칙)
- **광고체 금지어**: "지금 바로", "무료로 만나보세요", "혁신적인", "최고의", 느낌표 연발
- CTA는 크리에이터 톤 고정: "링크는 프로필에 있어요" / 댓글 유도: "재보고 싶은 작업은 댓글로 알려주세요"
- 시간 수치는 **촬영 실측값만** (금지 체크)

## 5. 시나리오 작성 규칙 (scenarios/*.ts)

- 흐름 공식: 진입(전체 파악) → 액션 1~2개 → **정차역 3~5개** (`showSection`) → 자연 종료
- 정차역 = 그 편의 자막 개수와 일치시킬 것 (자막-장면 싱크)
- 한 편에 기능 하나만 — 30초 안에 2개 기능 욱여넣기 금지
- 실서비스 조작만 (목업·합성 화면 금지 — 신뢰 원칙)

## 6. 검수 체크 (발행 전)

- [ ] 훅 3초 안에 무슨 영상인지 파악되나
- [ ] 줌인 구간마다 대응 자막이 있나
- [ ] 광고체 금지어 없나 / 전부 해요체인가
- [ ] 실측 시간 = 실제 녹화 경과인가
- [ ] 엔딩 리캡이 실제 보여준 것과 일치하나
